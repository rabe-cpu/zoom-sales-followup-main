# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かと思いますので` / `〜かと思います`（説明・案内の着地で非常に頻出。「進めにくいかと思いますので」「用意いただいているかと思うので」）
- `〜かなと思います` / `〜かなと`（見立て・提案の柔らかい着地。「向いている事業かなと思います」「役立っていただけるんじゃないかなと思います」）
- `承知いたしました` / `かしこまりました`（顧客の話を受けるときの定番。丁寧で落ち着いている）
- `〜させていただければと思います` / `お伝えさせていただきます` / `お送りさせていただきます`（依頼・案内の定番着地）
- `おっしゃる通りです` / `そうですね`（相槌・肯定）
- `個人的には`（「個人的には分割の方が手出しを抑えて利益に到達できる」など、私見を添えて選択肢を示す）
- `強いて言うなれば`（デメリットなど言いにくい点を切り出すときのクッション）
- `急かすわけじゃないんですけど`（クロージング前の一言。押しつけない姿勢）
- `ぶっちゃけ`（口頭ではカジュアルに使う＝「ぶっちゃけセンスとか関係ない」。※メールでは使わない）

## 一人称・距離感

- 一人称: 僕 / 私 / 弊社（`僕らのシステム`、`僕個人的には`、`私自身も`）
- 顧客への呼び方: `新美さん` / `新美様`（さん・様を併用。丁寧だが距離は近め）
- 自己開示を挟みながら距離を縮めるスタイル（自身の失敗・独立経験・物販運営を語る）。再現性・堅実さを軸に、断定より「合うかどうか一緒に見る」姿勢で進める

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `資料と収益シミュレーションを、この後お送りさせていただきます`
- `気になる点やご質問があれば、お気軽にお知らせいただければと思います`
- `無理に決めていただくつもりはございませんので、まずは資料をご覧いただければと思います`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（「進めにくいかと思いますので」「用意いただいているかと思うので」多数）→ 1通0〜1回までOK。依頼文の着地を曖昧に止めない
- `かなと` / `かな`: あり（「向いている事業かなと思います」「いいかなと」）→ 0〜1回までOK
- `できればと`: あり（「お役に立てるお話できればと思います」「お話ししていければと思います」）→ 着地として自然に使用可
- `見ていただけると`: 明確な同型発話は少ない。`ご覧いただければと思います` の形なら自然

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では「再現性が高い」「6年で9割以上継続」と事実ベースで語るが、メールでは数字や成果を保証にしない）
- `ぶっちゃけ`（口頭のカジュアル表現。メール文には持ち込まない）
- 過度な美文
- 顧客の不安・感情の断定・煽り（新美さまは回収・在庫確約・作業時間に率直な疑問を口にしており、丁寧に受け止める）
