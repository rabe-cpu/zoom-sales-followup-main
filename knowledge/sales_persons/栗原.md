# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（相槌・受け止めで非常に頻出。確認の締め）
- `ありがとうございます`（お礼・相槌として頻出。`貴重なお時間にありがとうございます`）
- `〜していければと思います` / `〜してまいりたいと思います`（案内・進行の定番）
- `じゃあ` / `で、えっと`（場面転換の接続）
- `一応`（説明にひと言添えるときのクッション。`一応過去の平均で`、`一応ここまでが`）
- `逆に`（`逆に言うと`、`逆に田村さん時間はどれぐらい`）
- `まあ`（やわらかくするクッション）
- `端的に言うと` / `ぶっちゃけ`（結論を軽く出すとき。`もう端的に田村さんにおすすめなのは分割です`）
- `〜という形です` / `〜という形`（説明の着地）
- `ご安心いただければと思います` / `安心いただければ`（不安をほどく締め）

## 一人称・距離感

- 一人称: 私 / 僕 / 僕ら（`私自身は思います`、`僕らのシステム`、`僕らのやりたい売り方`）、改まると 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `承知いたしました`（受け止め）
- `〜していければと思います`（次の案内へつなぐ）
- `一応〇〇という形です`（説明の着地にクッションを置く）
- `ご安心いただければと思います`（サポート・不安への受け止め）
- 締め: `よろしくお願いします` / `ありがとうございました`

## 余白表現の出現

- `かと`: あり（`見やすいかと思います`、`失礼かと思うので`、`ないかと思いますけれども`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`平均以上で収益出るんじゃないかなとは私自身は思います`、`おすすめかなぁとは思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お役に立てるお話ができればと思います`、`お伺いしていければと思います`）→ 進行・提案の着地で少量OK
- `見ていただけると`: 単独での明確な出現は確認できず → 使わない。資料案内は `ご覧いただけますと助かります` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `誰でも収益を作りやすい`、`費用対効果は50倍以上`、`平均以上で収益出る` と語る場面があるが、いずれも過去平均・個人見解の文脈。メールでは `過去の平均では` `〜という方もいらっしゃいます` 程度に留め、保証表現にしない）
- 審査通過の断定（`審査があり、通過しないと取り組めない` 旨を本人も説明。メールでも断定しない）
- 過度な美文
- 顧客感情の断定
