# 栗原 哲也さん

## 商談内で見えた特徴

- `じゃあ` / `じゃあ早速ですね`（話題の切り出しで多用）
- `えっと` / `で` / `まあ`（説明をつなぐときの接続）
- `ちなみに`（確認を挟むときの前置き。`ちなみに今のお仕事は`、`ちなみに今ご年齢っておいくつ`）
- `逆に`（`逆にあの杉山さんについても`、`逆にデメリットとしては`）
- `正直` / `正直言うと`（本音をかみ砕くときの前置き。`正直その商品のかぶりが`、`めちゃくちゃ儲かるビジネスではないんですよ、正直言うと`）
- `〜という形です` / `〜という形になります`（締めの言い回し）
- `〜なイメージです` / `〜イメージなんですね`（説明の着地）
- `〜していければと思います`（進行・提案の着地。`お話を中心に進めていければ`、`ご紹介していければ`）
- `〜と思いますね`（所感の締め。`キャッシュフローがいいかなと思いますね`、`向いてるビジネスモデルだなと思いますね`）
- `ご判断していただければと思います`（意思決定を委ねる締め）
- `もちろんです`（受けの定番）
- `承知いたしました` / `かしこまりました`（相槌・受け）
- `ありがとうございます`（相槌・お礼として頻出）

## 一人称・距離感

- 一人称: 僕ら / 弊社 / 私（`僕らのこのビジネス`、`僕らのシステム`、`弊社のシステム`、`私がこの事業部では一番古株`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `じゃあ〇〇していければと思います`（次の流れへの橋渡し）
- `〇〇という形になります`（仕組みの説明の締め）
- `〇〇なイメージです`（数字・シミュレーションの着地）
- `もちろんです` / `〇〇も可能です`（できる・できないの受け）
- `ぜひ、〇〇していただければと思います`（ネクストアクションの依頼）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`おそらくそうかと思います`、`早く得たい作りたいっていうお考えかと思うので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`条件的に合うかなと思うので`、`収まってくるプランかな`）→ 1通あたり0〜1回までOK
- `できればと`: 栗原さんの発話に出現なし（`できれば`は顧客側の発話）→ 使わない。ネクストアクションは「ご判断いただければと思います」「ご覧いただけますと幸いです」で着地させる
- `見ていただけると`: `見ていただくと`はあるが`見ていただけると`は出現なし → 着地は「ご覧いただければ」「ご判断していただければ」で止める

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`赤字になるのはほとんど聞かない`、`再現性が高い`とは語るが`絶対``必ず`とは言い切っていない。メールでは`〜という方が多いです``〜というイメージです`程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
