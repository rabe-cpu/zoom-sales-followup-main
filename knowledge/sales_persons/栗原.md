# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かと思います` / `〜かと思うので`（口癖。複数回。「見やすいかと思います」「失礼かと思うので」「進めにくいかと思うので」など、やわらかい断定回避で多用）
- `一応`（前置きの定番。「一応前回」「一応弊社」「一応ご質問いただいた」）
- `早速ですね` / `じゃあ早速`（本題への切り出し）
- `改めまして`（名乗り直しの導入）
- `〜していければと思います` / `お伝えしていければと思います`（説明の着地）
- `ぶっちゃけ`（ざっくばらんに要点を出すときのカジュアル語）
- `だから` / `なんで`（理由から結論へつなぐ接続）
- `ちなみに`（話題を軽く足すとき）
- `承知いたしました` / `かしこまりました`（受け止め・相槌として非常に頻出）
- `ご安心いただければと思います` / `安心してください`（不安をほどくときの定番）

## 一人称・距離感

- 一人称: 私 / 僕（「私も先ほど自己紹介したように」「僕らのビジネス」）、改まると 弊社。私と僕が混在する
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `〜かと思います`（やわらかい提案・見立ての着地）
- `一応〇〇です`（情報を控えめに添える）
- `〜していければと思います`（次の流れの提示）
- `ご安心いただければと思います`（サポート・不安への受け止め）
- 依頼: `ご確認いただけますと幸いです` / `ご返信いただけると幸いです` / `教えていただければと幸いです`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（「〜かと思います」を実発話で多用）→ 1通あたり0〜1回まで、見立て・軽い提案の箇所で使う
- `かなと`: あり（「最後のチャンスかなと思って」「たぶん15%ぐらいかな」）→ 1通あたり0〜1回までOK
- `できればと`: 単独の明確な出現なし → ネクストアクションは「ご確認いただけますと幸いです」「ご返信いただけると幸いです」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では「絶対うまくいくな」「めちゃくちゃたまります」など勢いのある表現があるが、メールでは `〜という方が多いです` `〜が見込みやすくなります` 程度に留め、収益保証・成果保証にしない）
- 節税・経費・確定申告まわりの断定的アドバイス（商談では雑談的に触れているが、メールには残さない）
- 過度な美文
- 顧客感情の断定
