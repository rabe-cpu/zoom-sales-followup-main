# 栗原 哲也さん

事業部の創業メンバーで一番の古株。システムに一番詳しく、自身もネットショップのプレイヤー。落ち着いて相手の状況を丁寧に受け止めてから説明に入るタイプ。

## 商談内で見えた特徴

- `承知いたしました`（相槌・受け止めで非常に頻出。顧客の話を受けてから次へ進む）
- `かしこまりました`（依頼・条件を受け止めるときの丁寧な相槌）
- `左様でございます`（肯定の丁寧表現）
- `〜イメージであってますかね？` / `〜という感じですかね？` / `理解いただけましたかね？`（認識合わせの確認）
- `じゃあ` / `一旦` / `改めて` / `ちなみに` / `逆に（言うと）`（段落の切り替え）
- `まあ`（やわらげの口癖。多用するのでメールでは削る）
- `〜と思いますので` / `〜と思ですけれども`（提案・説明の着地）
- `お話進めていければと思います` / `ご覧いただければと思います`（依頼の着地）
- `すごく状況が伝わってきました` / `すごくピッタリだなと感じました`（共感の受け止め。1文で止める）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのネットショップのやり方`、`僕らみたいな個人`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん` / `〇〇さま`（商談中は基本さん付け、書面はさま）

## メール反映の定型

- `本日はお時間をいただきありがとうございました`（お礼）
- `〇〇というイメージであってますかね` → 書面では `〇〇と受け取りました` に置き換える
- `一旦〇〇して` / `改めて〇〇します`（段落のつなぎ）
- `〇〇できればと思います`（提案の着地）
- `承知いたしました` の受け止めの温度を、書面では `おっしゃっていた〇〇、しっかり受け止めております` に変換
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`見やすいかと思うので`、`進めにくいかと思いますので`、`取っていただいたかと思で`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`ちょうどいいかなと`、`お役に立てるお話ができればなと`）→ 1通あたり0〜1回までOK。`かと` と合わせて1通2回までに抑える
- `できればと`: `〜できればと思います` の形で出現あり → 提案・軽い相談の着地でのみ少量可。依頼・期限連絡では途中で止めず `いただけますと助かります` で着地させる
- `見ていただけると`: 単独の明確な出現なし → `ご覧いただけますと助かります` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `誰がやってもちゃんと売り上げ上がる`、`収益が出ると確証している` と語る場面があるが、メールでは保証表現にせず `過去のデータでは〜という方が多いです` 程度に留める）
- `必ず成果が出ます` / `安心して稼げます` / `誰でも簡単に`
- 過度な美文、顧客感情の断定
- キャンペーン・審査・返金保証を煽り文句として書かない（事実として触れるに留める）
