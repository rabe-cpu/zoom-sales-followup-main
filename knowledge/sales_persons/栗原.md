# 栗原 哲也さん

## 商談内で見えた特徴

- `〜という形です` / `〜という形になります`（説明の締めで頻出）
- `要するに` / `要は`（要点を言い換える接続）
- `分かりやすく言えば` / `端的に言うと`（かみ砕くときの前置き）
- `承知いたしました` / `かしこまりました`（受けの定番。丁寧）
- `ご案内させていただきます` / `お伝えさせていただきます`（丁寧な進行）
- `全然大丈夫です` / `全然大丈夫でございます`（不安をほどく定番）
- `気持ちはめちゃくちゃ分かります`（共感。自身の失敗経験に基づく）
- `さすがです`（顧客の着眼を持ち上げる）
- `ぶっちゃけどうでしたか`（率直な本音を引き出すカジュアル質問）
- `〜んですよ`（説明を口語的に断定で締める）
- `ありがとうございます`（相槌・お礼として頻出）
- `ねえ` / `〜ですもんね`（共感の相槌）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕もお金ない中でやった`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 自己開示型：自身の独立失敗・借金・無在庫で立て直した経歴を先に語り、距離を縮める

## メール反映の定型

- `要は〇〇という形です`（仕組みをかみ砕く）
- `分かりやすく言えば、〇〇です`
- `〇〇について、しっかりとご案内させていただきます`
- `そこは全然大丈夫です`（不安への受け止め）
- `〜かと思います`（やわらかい提案・見立て）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`失礼かと思いますので`、`お話ししにくいかと思います`）→ 1通あたり0〜1回まで、見立て・提案の場面でOK
- `かなと`: あり（`ご質問しやすいのかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: 近い表現あり（`ご案内できればと思います`）→ ネクストアクションの着地で自然な範囲のみ
- `見ていただけると`: 単独の明確な出現なし → `ご覧いただいて〜` の着地形に寄せる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗しにくい` `八割うまくいってる` `より確実に` と語る場面があるが、メールでは `〜という方が多いです` 程度に留め、保証表現にしない）
- `絶対〇〇できます` の断定
- 過度な美文
- 顧客感情の断定
