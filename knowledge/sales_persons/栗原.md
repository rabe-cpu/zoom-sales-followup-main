# 栗原さん（栗原 哲也）

## 商談内で見えた特徴

- `かと思うので` / `かと思いますが`（実発話にあり）
- `できればと思います` / `お伝えできればと思います`（実発話にあり）
- `かなと思います` / `妥当かなあと`（実発話にあり）
- `ご安心ください` / `ご安心いただいて大丈夫`
- `承知いたしました` / `かしこまりました`
- `ぜひ` / `全然` / `もちろんです`
- `改めて`
- `さすがです` / `すごいですね`（顧客の発言を前向きに受け止める相づち）

## 一人称・距離感

- 一人称: 僕／私（両方使用。自分の経験談では `僕`、案内では `私`）
- 自社の言い方: `弊社` / `僕ら`
- 顧客への呼び方: `森さん`（さん付け。商談では `さま` ではなく `さん` 寄りだが、メールでは `さま` に統一）
- 温度感: 明るく前向き。顧客の行動や決断を素直にほめる。創業時からの古株で、サービスに一番詳しいという自負がある。

## メール反映の定型

- `ご不明点が出てきましたら、お気軽にご連絡ください`
- `承知いたしました`
- `ぜひ一度ご覧いただけますと幸いです`
- `ご安心いただける範囲で、一つずつ確認させてください`
- `改めて本日はありがとうございました`

## 余白表現の出現

- `かと`: あり → 1通あたり0〜1回（依頼文の着地は止めない）
- `かなと`: あり → 限定的に1回まで
- `できればと`: あり → ネクストアクションで止めず着地させる
- `見ていただけると`: 実発話に明確な根拠なし → 使わない

## 禁止候補

- `伝わってまいりました`
- 成果保証・収益保証に聞こえる断定（`必ず稼げます` 等）
- 顧客が言っていない不安・感情の断定
- 審査・信販に関する断定
