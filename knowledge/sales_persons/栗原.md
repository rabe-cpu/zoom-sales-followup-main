# 栗原 哲也さん

## 商談内で見えた特徴

- `お世話になります。今日もよろしくお願いします`（冒頭の入り）
- `承知いたしました` / `かしこまりました`（受けの定番。多用）
- `ちょっとお待ちください` / `ちょっと確認させていただきます` / `確認してまいります`（その場で分からない時に必ず確認へ回す）
- `〜という形ですね` / `〜という形になるかと思います`（締めの言い回し）
- `〜かなと思いますね` / `〜かと思います`（見立てを述べるときの着地）
- `一応`（前置きでよく使う。断定を避けるクッション）
- `おっしゃる通り`（顧客の見立てを肯定して受ける）
- `多分`（手元に確証がない時に正直に付ける）
- `〜させていただければと思います` / `〜お伝えできればと思うので`（依頼・提案の柔らかい着地）
- `隠すことでもちろんないので、すべて包み隠さずお伝えさせていただければと思います`（透明性を前面に出す姿勢）
- `リアルなままをお伝えできればと思うので`（誠実さの表明）
- `しっかりね、ご契約前にご相談いただけて良かったです`（顧客の慎重さを歓迎する受け）
- `引き続きよろしくお願いします`（締め）

## 一人称・距離感

- 一人称: 僕 / 私（`僕が今個人でやってるショップ`、`私の手元にある情報`）、弊社（`弊社の方で`）
- 顧客への呼び方: `〇〇さん`（商談中はさん付け。メールでは `さま`）

## メール反映の定型

- `お世話になっております。株式会社NEXT（総合物販システム＿アクセス）の栗原でございます`
- `承知いたしました`（受け止め）
- `〜という形になるかと思います`（説明の着地）
- `一応、〜`（断定を避けるクッション）
- `おっしゃる通り、〜`（顧客の見立てを肯定）
- `包み隠さずお伝えできればと思います`（透明性）
- `ちょっと社内で確認のうえ、改めてお伝えします`（その場で確約しない誠実さ）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`スケジュール感かなと思いますね`、`一年ぐらいの利益で売れるぐらいかなと思いますね`）→ 1通あたり0〜1回までOK
- `かと`: あり（`一緒に改善を進めていくっていう形になるかと思います`、`改善要素はあると思いますね`）→ 発話準拠で少量OK
- `できればと`: あり（`リアルなままをお伝えできればと思うので`）→ 依頼の柔らかい着地として少量OK
- `見ていただけると`: 単独での明確な出現は確認できず → 使わない。ネクストアクションは「ご確認いただけますと助かります」で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`必ず売れます` `絶対稼げます` は不可。商談でも `やり方さえ間違ってなければ` `改善要素はあると思う` と条件付きで語っている。メールでも `〜という方が多いです` `条件次第で変わります` に留める）
- 審査・アカウント停止・健全性を「絶対大丈夫」と断定しない（商談でも `過失がなければ停止まではほぼ行かない` と条件付き）
- 過度な美文・顧客感情の断定
