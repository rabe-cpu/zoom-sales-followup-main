# 栗原 哲也さん

## 商談内で見えた特徴

- 挨拶: `どうもお世話になります` / `今日もよろしくお願いします`
- 相槌・つなぎ: `まあ` / `あの` / `ね` を自然に挟む
- 確認: `大丈夫ですか？` / `本当にその判断で〇〇さん大丈夫ですか？`
- `かなと` 系の柔らかい判断（`合いそうではあるかなと思います`、`ベストかなとは思います`）
- 柔らかい主張: `これは本当に今が一番いいプランなんで` / `もったいないな` / `ぜひ`
- 相手の判断を尊重する言い方: `絶対やってくださいというわけではもちろんなく、その判断は私は尊重したい`
- 締め: `ご検討いただければと思います` / `かしこまりました` / `ありがとうございました`

## 一人称・距離感

- 一人称: 私（`私自身`、`私自体`、`私は尊重したい`）
- 顧客への呼び方: `〇〇さん`（本文メールでは `〇〇さま` に寄せる）

## メール反映の定型

- `今日もよろしくお願いします` の温度感を冒頭の御礼につなげる
- `ここまで何度も真剣にご検討いただき、ありがとうございました`
- `〇〇さんの今のご状況には本当にぴったりだと思います`
- 相手の判断を尊重する一文: `無理におすすめするわけではなく、〇〇さまのご判断を尊重したい`
- 締め: `ご検討いただければと思います`

## 余白表現の出現

- `かなと`: あり（`合いそうではあるかなと思います`、`ベストかなとは思います`）→ 1通あたり0〜1回までOK
- `かと`: 直接出現は確認できず → 使わない
- `できればと`: 直接出現は確認できず → 使わない。ネクストアクションは `ご検討いただければと思います` で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益保証につながる断定
- 過度な美文
- 顧客感情の断定
