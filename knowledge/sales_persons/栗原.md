# 栗原 哲也さん

## 商談内で見えた特徴

- `〜という形で` / `〜という形ですね` / `〜という形になります`（説明の着地で頻出）
- `〜かなと思います` / `〜かなと`（`いいなと思ってます`、`おすすめだと思います`、`選択肢に入ってくるかなと`、`出せるんじゃないかなと思います`）→ 実発話にあり
- `〜かと思います`（`担当させていただいたかと思うですけど`）→ 実発話にあり
- `そうですね` / `はい` / `あの` / `まあ` / `ちょっと`（相槌・つなぎで多用）
- `〜っていうイメージ` / `そんなイメージですね`（説明の締め）
- `〜させていただく`（丁寧な進行。`ご案内してまいりたい`、`お伝えさせていただく`）
- 確認表現: `イメージつきましたかね`、`予算内に収まりそうでしたか`、`大丈夫そうでしょうか`
- 不安対応: `ご安心いただければなと`、`慎重になるお気持ちはすごくわかります`、`遠慮なくご質問何なりと`
- 経験の共有で距離を縮める（`私も輸出やってるんですよ`、`僕もヤフーショッピングやってて、アカウント潰れちゃって` と自己開示）

## 一人称・距離感

- 一人称: 僕ら / 僕 / 私 / 弊社
- 顧客への呼び方: `大里さん`（さん付けが基本。様は書面向け）
- 相手の経験・慎重さを否定せず、`確かにそうですよね`、`おっしゃる通りで` と一度受け止めてから話を進める
- 経験者には `ご理解いただいていると思うので` と敬意を示し、根掘り葉掘り聞きすぎない配慮を明言する

## メール反映の定型

- `〜という形でお送りさせていただきます`
- `ぜひ中身をご覧いただいて、〜いただければと思います`
- `ご不明点があれば、メールでもお電話でも構いませんので、遠慮なくご質問ください`
- `また次回お話しできること楽しみにしております`
- 締め: `本日は貴重なお時間をいただきありがとうございました。引き続きよろしくお願いいたします。`

## 余白表現の出現

- `かと`: あり（`担当させていただいたかと思うですけど`）→ 1通0〜1回までOK
- `かなと` / `かな`: あり（`おすすめだと思います`、`いいなと思ってます`、`〜かなと思います`）→ 0〜1回までOK。ただし依頼文の着地は曖昧に止めない
- `できればと`: あり（`ご案内してまいりたい`、`お話しできればと`）→ 着地として自然に使用可
- `見ていただけると`: `ご覧いただければと思います` の形で使用 → `ご覧いただけますと助かります` 等の着地ならOK

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `うまくいく自信がある`、`ほぼノーリスク`、`お金の損はほぼない` と語るが、メールでは成果・回収・返金を保証表現にしない）
- 過度な美文
- 顧客の不安の断定・煽り（大里さまは過去のスクール・ツールで繰り返しつまずいた経験から慎重。不安は否定せず受け止める）
- 「9月限定」「今月中」等の期限は事実として案内してよいが、急かす圧の強い言い回しにしない
