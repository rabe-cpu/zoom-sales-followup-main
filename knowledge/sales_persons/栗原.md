# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かなと思います`（説明の着地で頻出。`大丈夫かなと思います`、`参考になるかなと思います`、`理想じゃないかなって思います`）
- `〜かと思います` / `〜という形になるかと思いますので`（締めの言い回し）
- `〜していただければと思います` / `〜いただけるといいと思います`（依頼の着地）
- `逆に`（`逆に前回のタイミングじゃなくて今回の方がよかった`）
- `一旦` / `改めて` / `実は` / `ちなみに`（話題の切り替え・補足）
- `まあ`（やわらげの前置き）
- `大丈夫そうですか` / `どうしましょう？どっちにしますか`（意思確認の投げかけ）
- `ぜひですね` / `一緒に〜`（伴走・巻き込みの温度づくり）
- 温度の高い共感：`めちゃくちゃ嬉しくて`、`すごく覚えてて`、`一緒に素敵な夢を見れてるみたいな感覚`

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕の方で`、`僕らが想定している`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん`（商談中）。メールでは `〇〇さま`

## メール反映の定型

- `〇〇かなと思っています` / `〇〇かなと思います`（提案・見立ての着地）
- `〇〇していただければと思います`（依頼の着地。途中で止めない）
- `逆に〇〇`（視点の切り替え）
- `一緒に〇〇していければと思います`（伴走の温度）
- 締め: `よろしくお願いいたします` / `楽しみにしております`

## 余白表現の出現

- `かなと`: あり（`大丈夫かなと思います`、`参考になるかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`本格的っていう形になるかと思いますので`）→ 1通あたり0〜1回までOK、依頼の着地は曖昧にしない
- `できればと`: 明確な出現なし → ネクストアクションは「〜いただければと思います」「お聞きいただければと思います」で着地させる
- `見ていただけると`: 明確な単独出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `必ず収益出る` `ほぼリスクはない` と語る場面があるが、メールでは `過去の平均の目安`『作業時間の取り方次第』に留め、保証表現にしない）
- 収益額・回収時期の断定
- 過度な美文・顧客感情の断定
