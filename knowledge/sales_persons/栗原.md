# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（相槌・区切りで多用）
- `しっかりと`（`しっかりとお伺いさせていただいて`、`しっかりとお話ししていければ`）
- `〜していければと思います` / `〜していければなと思います`
- `ちなみに`
- `実際に`
- `逆に`
- `そうですよね` / `本当に感じますよね`（共感の相槌）
- `ご検討ありがとうございます`
- `引き続き〜ご連絡させていただきます`
- `〜なんですよ`（説明・根拠提示のとき）
- `ざっくり`（概算を伝えるとき）
- 相手の負担・体調への配慮（`ご負担にならないように`、`30分とか45分ぐらいの目安で`）

## 一人称・距離感

- 一人称: 僕／私（併用。くだけた説明では「僕ら」、経歴や会社の話では「私」）
- 顧客への呼び方: `〇〇さん`

## メール反映の定型

- `後ほどお送りしておくので`
- `またタイミングでご検討できそうであれば、ご連絡いただければと思います`
- `しっかりとご検討いただきありがとうございます`
- `引き続きよろしくお願いいたします`
- 共感をはさんでから本題へ戻す（`そうですよね` → 確認・整理）

## 余白表現の出現

- `かなと`: あり → 1通あたり0〜1回までOK（`お話ししていければなと思います`）
- `かと`: 限定的に出現（`失礼かと思うので`）→ 文末で多用しない
- `できればと`: あり → ネクストアクションでは「ご連絡いただければと思います」「お送りいたします」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益断定（`必ず増えます` 等）
- 顧客の健康状態・資金事情の断定や言及（商談内に出た機微情報は顧客送付文に出さない）
- 過度な美文、顧客感情の断定
