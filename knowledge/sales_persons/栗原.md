# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（受け止めの定番）
- `〜かと思います` / `〜かと思いますので`（判断・提案の柔らかい着地。実発話で頻出）
- `〜させていただければと思います` / `お伺いできればと思います`（依頼・確認の丁寧な置き方）
- `〜という形になります` / `〜という形ですね`（仕組み説明の締め）
- `一応` / `あくまで平均として`（誇張を避ける前置き）
- `ご安心ください`（録画・不安対応）
- `正直ベースで` / `正直お伝えすると`（率直さを大事にする）
- `誇大広告をしたくなくて`（成果を盛らない姿勢を自分の言葉で明言）
- `ちなみに` / `逆に` / `で`（会話のつなぎ）

## 一人称・距離感

- 一人称: 僕 / 私 / わたくし / 弊社
- 顧客への呼び方: `〇〇さん` 中心（`〇〇さま` も可）
- 距離感: 自己紹介を厚めに開示し、相手の状況を丁寧に聞いてから提案へ入る。無理に契約へ押し込まず、合わない場合は「準備が整ってから」「別の合う手段」を勧める誠実型。

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `〜のあたりを一緒に整理できればと思います`
- `あくまで平均としてお伝えしますと`（数字を出すときの前置き）
- `無理のない範囲で` / `準備が整ってから`
- `気になる点が出てきましたら、こちらのメールにご返信いただけますでしょうか`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お伝えできるかと思います`、`難しいかと思います` など複数回）→ 1通あたり0〜1回まで自然に使える
- `かなと`: 限定的 → 文末で多用しない
- `できればと`: あり（`収益イメージをしっかりとできればと思います`）→ ネクストアクションでは「と思います」「お送りいたします」で着地させ、文を途中で止めない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- `必ず稼げます` / `確実に収益が出ます`（本人は誇大広告を明確に避けている。成果保証は本人の姿勢と逆行）
- 過度な美文、顧客感情の断定
- 顧客の債務・詐欺被害など機微情報を本文にそのまま書くこと（本人は正直に扱うが、メールでは配慮して抽象化する）
