# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（合意・受け止めの締めで非常に頻出）
- `ありがとうございます`（相槌・お礼として頻出）
- `さすがです` / `さすが`（顧客の理解の速さ・鋭い質問を受け止めるときの相槌）
- `おっしゃる通りです` / `おっしゃる通りですね`（顧客の理解を肯定する相槌）
- `ちょっと踏み込んでお伝えすると` / `ちょっと〇〇さんに踏み込んで`（説明を一段深くする切り出し）
- `逆に言うと`（利点を言い換えるときの接続）
- `一応`（前置き・条件提示のクッション）
- `だから` / `なんで`（理由から結論へつなぐ接続）
- `〜という形で(すね)` / `〜というところ`（説明の着地）
- `〜みたいな感じで(すね)` / `イメージとしては` / `〜イメージになります`（説明の締め）
- `ご安心ください`（不安をほどくときの定番）
- `しっかりと`（サポート・対応を約束するときに多用）
- `共存共栄でお互いに協力しながら`（伴走姿勢を伝える言い回し）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らとしては`、`僕らが定期的に`）、改まると 弊社 / 私
- 顧客への呼び方: `金谷さん` / `カネヤさん`（商談中は基本さん付け）

## メール反映の定型

- `〇〇いただきありがとうございます`（お礼を先に置く）
- `承知いたしました`（受け止め）
- `ちょっと踏み込んでお伝えすると、〇〇です`（一段深い説明の切り出し）
- `〇〇という形で(すね)`（説明の着地）
- `〜イメージになります`（説明の締め）
- `ご安心ください`（不安への受け止め）
- `しっかりとサポートさせていただきます`（伴走の約束）
- 締め: `何卒よろしくお願いします` / `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`再現性が高いかなと思います`、`最初の一ヶ月ぐらいで思ってもらえればいいかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: 栗原さん本人の明確な単独出現は確認できず（顧客側の発話にはあり）→ 使わない
- `できればと`: あり（`ちょっと踏み込んだお話もできればと思ってた`、`お伝えしていければなと思います`）→ 1通あたり0〜1回まで、冒頭の温度感や軽い提案でのみOK
- `見ていただけると`: 出現なし → 使わない。ネクストアクションは「ご確認いただければと思います」「いただければと思います」で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`平均以上の収益を出していただけるように` と語る場面はあるが、メールでは保証表現にせず `しっかりサポートさせていただきます` 程度に留める）
- 過度な美文
- 顧客感情の断定
