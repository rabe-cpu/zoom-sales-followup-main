# 栗原さん

## 商談内で見えた特徴

- `承知いたしました`（受けの定番）
- `ぜひぜひ`
- `あの`、`ええ`（自然なつなぎ、多め）
- `手前味噌ですが`
- `ご安心ください` / `安心いただきたい部分`
- `遠慮なく` / `気兼ねなく`
- `さすがです` / `理解力がすごい`（顧客の理解や姿勢を素直に持ち上げる）
- `よかった。よかったです`（安心の受け）

## 一人称・距離感

- 一人称: 私・僕（場面で使い分け。実体験を語るときは `僕ら` も出る）
- 顧客への呼び方: 商談中は `佐野さん`。メール宛名は house style に合わせ `〇〇さま`
- 距離感: 自分の失敗談・実体験も開示して並走する。上から説明せず「一緒に整理する」姿勢

## メール反映の定型

- `承知いたしました` / `ご安心いただければと思います`
- `ぜひぜひ、そのあたりしっかりお伝えできればと思います`
- `遠慮なくご質問いただければと思います`
- `お役に立てるお話ができればと思います`
- `また来週、そういったお話ができればと思います`

## 余白表現の出現

- `かと`: あり（実発話多数: `見やすいかと思います` `失礼かと思いますので` `お役に立てるお話できるかと思います`）→ 1通あたり0〜1回
- `かなと`: あり（実発話: `安心いただいて大丈夫かなと思います` `おすすめかなと思う`）→ 1通あたり0〜1回、着地を曖昧にしない範囲で
- `できればと`: あり（実発話: `お話できればと思います` `ご調整できればと思います`）→ ネクストアクションで止めず着地させる
- `見ていただけると`: 実発話になし → 使わない

## 禁止候補

- `伝わってまいりました`
- `必ず成果が出ます` / `安心して稼げます`（サポート・実績を語る担当だが、保証表現には寄せない）
- 顧客の感情・不安の断定
- 過度な美文・整いすぎた敬語
