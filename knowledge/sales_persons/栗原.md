# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました`（締め・受け止めで頻出。依頼や日程確定のあとに置く）
- `もちろんです` / `もちろん、はい`（顧客の懸念を正面から受け止める相槌）
- `おっしゃる通りです` / `おっしゃる通りですね`（顧客の指摘に同意して返す）
- `正直なところをお伝えすると`（融資・実績など踏み込んだ話に入る前置き）
- `〜っていうプラン` / `〜っていう形`（説明の着地）
- `ぜひ、一緒に頑張っていきましょう` / `一緒にタッグ組んでやっていきます`（前向きな合意導線）
- `惜しみなくサポートしていく` / `専属担当が無制限でサポート`（安心導線の定番）
- `お気遣いありがとうございます` / `本当に真剣にご検討いただいて`（顧客の姿勢へのお礼）
- `あの`（発話のつなぎとして頻出。メールには持ち込まない）

## 一人称・距離感

- 一人称: 僕ら / 弊社 / 私（`僕らが大事にしているのは`、`弊社は`、`私としては`）
- 顧客への呼び方: `神田さん`（商談中は基本さん付け。文字起こしに `患者さん` と出る箇所はASR誤認で、実際は `神田さん`）

## メール反映の定型

- `正直なところをお伝えすると、〇〇です`（踏み込んだ説明の前置き。誠実さを出す）
- `もちろんです`（懸念を受け止める短い相槌）
- `おっしゃる通りで、〇〇です`（顧客の指摘に同意してから補足）
- `専属担当が無制限でサポートいたしますので、〇〇です`（安心導線）
- `ぜひ一緒に取り組めればと思います`（前向きな合意導線。押しつけにしない）
- 締め: `よろしくお願いいたします` / `いつでもメール・お電話でご連絡ください`

## 余白表現の出現

- `かと`: あり（`奥様の説得も必要かと思いますが`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`その半分ぐらいでは取り組めるかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: 明確な出現なし → ネクストアクションは「ご連絡いただけますと幸いです」「ご確認いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし。ただし `後でゆっくりとご覧いただければと思います` はあり → 案内は「ご覧いただければと思います」で着地させ、「見ていただけると」は使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`必ず儲かる` `絶対成功` は不可。商談では返金保証・黒字化5ヶ月目・8割達成などデータで話すが、メールでは `〜という方が多いです` `〜という実績があります` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定（神田さん本人が慎重・懐疑を口にしているため、その範囲を超えて「安心されていた」等と断定しない）
