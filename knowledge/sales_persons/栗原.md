# 栗原 哲也さん

## 商談内で見えた特徴

- `〜いただければと思います`（依頼・案内の定番の着地。`保管していただければと思います`、`ご確認いただければと思います`、`頼っていただければと思います`。非常に頻出）
- `〜かなと思います` / `〜かと思います`（見立て・提案の柔らかい締め。`対応できるかなと思ってます`、`お得かなと思いますね`、`個人でいいのかなと思いました`、`郵便ポストに入っているかと思います`）
- `そうですよね。そうですよね。`（顧客の不安に寄り添うときの相槌の重ね）
- `あの` / `えっと` / `ちょっと`（つなぎのフィラー。多用）
- `ご安心いただければと思います` / `安心いただいて大丈夫です`（不安への受け止め）
- `遠慮なくご連絡ください` / `遠慮なく頼っていただければ`（相談導線の締め）
- `かしこまりました` / `承知いたしました` / `左様でございます`（丁寧な受け）
- `〜させていただきます` / `〜させていただいた`（謙譲での案内）
- `ぜひ` / `一緒に頑張っていければと思います`（伴走・前向きな締め）

## 一人称・距離感

- 一人称: 私（改まった案内）／ 僕・僕ら（自己開示・共感の場面。`僕も実は`、`僕らのビジネス`）、会社は 弊社
- 顧客への呼び方: `佐野さん`（商談中は基本さん付け）

## メール反映の定型

- `〇〇していただければと思います`（依頼・案内の着地。押しつけにしない）
- `〇〇かなと思います`（見立て・提案の柔らかい締め）
- `ご安心いただければと思います`（不安への受け止め）
- `不明点があれば、お電話でもメールでも遠慮なくご連絡ください`（相談導線）
- `ぜひ一緒に進めていければと思います`（伴走の締め）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`難しいかと思います`、`入っているかと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`対応できるかなと思ってます`、`お得かなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: 明確な単独出現は確認できず → ネクストアクションは「いただけますと助かります」「ご確認いただければと思います」で着地させる
- `見ていただけると`: 明確な出現は確認できず → 使わない。案内は「ご確認いただければと思います」で止める

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では収益シミュレーションや継続率を語るが、メールでは `〜という方が多いです` 程度に留め、`必ず`・`確実に`の保証表現にしない）
- 過度な美文
- 顧客感情の断定
