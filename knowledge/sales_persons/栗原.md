# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（最頻出。顧客の発言を受け止める定番の相槌・切り返し）
- `かしこまりました`（フォーマル寄りの受け止め。日程調整の場面で使用）
- `〜かと思うので` / `〜かと思います`（説明や提案の着地。複数回）
- `〜できればと思います`（依頼・案内の柔らかい着地。`しっかりとお伝えできればと思います`、`進めていければと思います`）
- `〜していただければと思います` / `確認していただければと思います`（ネクストアクションの定番）
- `ぜひ`（提案・案内を後押しするときの前置き。`ぜひご紹介してまいりたい`、`ぜひあのメールでお送りする`）
- `〜なんですよ`（仕組み・メリットをかみ砕くときの説明調）
- `いえいえ`（顧客の遠慮・謝罪を受け流すときの相槌）
- `もちろんです` / `全然大丈夫です`（許可・安心を返すとき）
- `正直` / `正直な話`（本音ベースで話すときの前置き。デメリットも率直に伝える）
- `個人的には`（おすすめを控えめに添えるとき。`個人的にはベーシックの方がおすすめです`）

## 一人称・距離感

- 一人称: 私 / 僕ら / 弊社（`私はアメックスカード二枚持っている`、`僕らのシステム`、`弊社で`）。自分の実体験を語るときは「私」、サービス主体を語るときは「僕ら」「弊社」
- 顧客への呼び方: `山口さん`（商談中は基本さん付け）
- 自己開示が多め（自身の経歴・EC実績・旅行の話など）で距離を縮めるスタイル

## メール反映の定型

- `承知いたしました。〇〇かと思います`（受け止め → 着地）
- `〇〇できればと思います`（案内・依頼の柔らかい着地）
- `ぜひ〇〇していただければと思います`（次アクションの後押し）
- `個人的には〇〇かなと思います`（おすすめを控えめに添える）
- `正直、〇〇です`（デメリットや本音も率直に伝える誠実さ。メールでは保証表現にしない）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`〜かと思うので`、`〜かと思います` を複数回）→ 1通あたり0〜1回までOK
- `かなと`: あり（`スムーズに行くんじゃないかなと思います`、`やりくりしやすいんじゃないかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`、`進めていければと思います`）→ 案内・依頼の着地で少量OK
- `見ていただけると` / `見ていただければと`: あり（`確認していただければと思います`、`見ていただいて`）→ 少量OK

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `確実に利益が出やすい`、`八割うまくいっている`、`全然取れます` と語る場面があるが、メールでは保証表現にしない。`〜という方が多いです`、`平均では〜ほど` 程度に留める）
- 過度な美文
- 顧客感情の断定
- 旅行・マイル・自己実績の自慢が前に出すぎる表現（商談では距離を縮める雑談だが、メールでは顧客の判断材料を優先する）
