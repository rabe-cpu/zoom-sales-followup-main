# 栗原さん

## 商談内で見えた特徴

- `じゃあ`（段落・話題の切り替え）
- `一応`
- `逆に`
- `なので`
- `ちょっと`
- `ぜひぜひ`
- `承知いたしました` / `かしこまりました`
- `遠慮なく受けていただければ`
- 自己開示・ストーリーで距離を縮める（自身の独立失敗〜再起の体験談）

## 一人称・距離感

- 一人称: 私 / 僕ら（自社を指すときは `弊社`）
- 顧客への呼び方: `〇〇さま`
- 相手を立てつつ、砕けすぎない丁寧さ。事実確認を細かく挟む。

## メール反映の定型

- `〜させていただきます`
- `〜いただければと思います`
- `ぜひ確認していただければと思います`
- `承知いたしました`
- `全然〜大丈夫です`（急がせない・許容の姿勢）
- `気になるところ・ご不明点が出てきましたら`

## 余白表現の出現

- `かと`: あり（`進めにくいかと思いますので`、`失礼かと思うので`、`ご覧いただいたかと思いますけれど`）→ 1通あたり0〜1回まで
- `かなと`: 発話に明確な形なし → ゼロ
- `できればと`: 発話に明確な形なし → 使わず着地形（`〜いただければと思います`）に寄せる
- `見ていただけると`: 発話になし → ゼロ

## 禁止候補

- `必ず成果が出ます` / `絶対`（本人も商談中「絶対とは言ってはいけない」と自制）
- `伝わってまいりました`
- 押し付け・急かす依頼文（本人が「今日決めてください、というわけでは」と急かさない姿勢）
