# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（相槌・受け止めで非常に頻出。依頼や確認を受けたときの定番）
- `ありがとうございます`（お礼・相槌で頻出）
- `そうですよね` / `そうですよね、そうですよね`（顧客への共感・受け止め。かなり多い）
- `よかった。よかったです`（顧客が理解・前進したときの素直な反応）
- `〜いただければと思います`（依頼・案内の定番の着地）
- `お送りさせていただきますので`（送付物の案内）
- `ご確認ください`（資料確認の依頼）
- `まあ` / `あの` / `ですね`（話の緩衝・つなぎ）
- `逆に` / `逆を返すと`（視点の切り替え）
- `ぶっちゃけ`（率直に事実を伝えるときに一度使用。多用はしない）
- 説明を押し切らず、`〜と思うので、〜考えていただけるといいんじゃないかなと思います` と顧客の判断に委ねる締め方

## 一人称・距離感

- 一人称: 僕ら / 僕（`僕らのシステム`、`僕らはえ狙ってます`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 誠実さを前面に出す（`うまくいった事例ばっかり言うのは誠実ではないなと思ってるので`、平均値ベースで説明する姿勢）

## メール反映の定型

- `本日はありがとうございました` / `承知いたしました`（受け止め）
- `〜いただければと思います`（依頼の着地）
- `資料をお送りさせていただきますので、ご確認ください`（送付物案内）
- `〜という感じですかね` / `〜ですよね`（やわらかい確認）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`失礼かと思いますので`、`イメージ湧くかと思いますので`、`聞くことはないかと思ですけれども`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`考えていただけるといいんじゃないかなと思います`、`分割の方が始めやすいかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お役に立てるお話できればと思います`、`お伝えできればと思います`）→ 案内・提案の着地で自然に使える
- `見ていただけると`: 単独での明確な出現は確認できず → 使わない（`ご覧いただけますと` などで着地させる）

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では再現性の高さを語るが、`あくまで平均`、`うまくいった事例ばっかり言うのは誠実ではない` と自制している。メールでも `〜という方が多いです`、`平均では` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 募集枠・分割終了などの煽り表現は、社内フィードバックの検討材料としては扱ってよいが、顧客送付メールでは急かす形で使わない
