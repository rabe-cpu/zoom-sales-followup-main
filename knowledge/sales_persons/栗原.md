# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（前置き・条件提示で多用。`一応条件もしっかりお伝えさせていただくと`）
- `おっしゃる通りです` / `さすが`（顧客の理解を受け止める相槌。非常に頻出）
- `もちろんです`（依頼・質問への即応）
- `ちなみに`（話題を差し込むときの接続。`ちなみにクレジットカードお持ちですか`）
- `せっかくなんで`（資料や画面を見せるときの切り出し）
- `逆に`（`逆にそういう方はお断りしてるんですよ`）
- `〜していただければと思います` / `〜していただければ大丈夫です`（依頼・案内の定番着地）
- `ぜひぜひ`（相手の質問や前向きな反応を歓迎するとき）
- `ご安心いただければと思います` / `安心いただいて大丈夫かなと思います`（不安をほどくとき）
- `お気持ちわかります`（不安の受け止め）
- `ありがとうございます`（相槌・お礼として頻出。`たくさんご質問いただいて本当に嬉しいです`）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らは正直`、`僕の方で`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 距離感: 温度高め。`一緒に頑張っていきましょ`、`一緒に習慣化できるように`と伴走を前面に出す

## メール反映の定型

- `一応〇〇だけお伝えしておきますと`（前置き）
- `〇〇していただければ大丈夫です`（不安への受け止め・案内の着地）
- `ご安心いただければと思います`（安心導線）
- `ぜひ遠慮なくご連絡いただければと思います`（相談導線）
- 締め: `よろしくお願いします` / `一緒に頑張っていければと思います`

## 余白表現の出現

- `かと`: あり（`ある程度大丈夫かと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`いいかなと思います`、`安心いただいて大丈夫かなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`しっかりお伝えできればと思います`、`一緒に頑張っていければと思います`）→ 1通あたり0〜1回までOK
- `見ていただけると`: 明確な出現なし → 使わない。`ご確認いただければと思います`／`ご覧いただけますと助かります`で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `ほとんどの確率でいける`、`絶対うまくいく` と語る場面があるが、メールでは `〜という方がほとんどです` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定（商談では顧客自身が `不安はある` と口にしているので、その範囲でのみ受け止める）
