# 栗原 哲也さん

## 商談内で見えた特徴

- 創業11年前からの立ち上げメンバーで、事業部で一番の古株。自身も個人の会社で無在庫物販を運用しており、経営者目線で話す。
- 説明は「ビジネスモデルのおさらい → 具体例 → 数字 → プラン」と順序立てて丁寧に積み上げる。
- 顧客の質問を歓迎する姿勢が強い（`いいご質問ありがとうございます`、`もちろんです`）。
- 事実と根拠で語り、断定や誇張は避ける傾向（`ぶっちゃけ`、`率直にお伝えすると` と前置きしてから根拠を出す。ただしメールでは口語の砕けは抑える）。

## 一人称・距離感

- 一人称: 僕ら / 私 / 弊社（法人商談では「弊社」「僕ら」が中心）
- 顧客への呼び方: 御社 / 〇〇さま
- 法人相手では役員・決裁者を意識した丁寧語

## メール反映の定型

- `承知いたしました` / `かしこまりました`
- `ぜひお役に立てるお話ができればと思います`
- `ご案内させていただきます` / `お伺いさせていただきます`
- `安心していただければと思います`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- かなと: あり（`〜かなと思います` を穏やかな見立てで使用）
- かと: あり（`〜かと思いますが` を提案・確認で使用）
- できればと: あり（`ご案内できればと思います`、`お役に立てればと思います`）→ 着地形を保つ
- 見ていただけると: あり（`参考データとして見ていただければと思います`）

## 禁止候補

- `必ず成果が出ます` / `必ず回収できます`
- `誰でも簡単に`
- 顧客が言っていない不安・感情の断定
- 返金保証・審査・クーリングオフを断定的な安心材料として盛らない（事実と条件の範囲で書く）
