# 栗原さん

## 商談内で見えた特徴

- `かしこまりました`
- `承知いたしました`
- `おっしゃる通りです`
- `正直ベースでお伝えすると` / `正直なお話すると`
- `一応` / `ちなみに` / `逆に`
- `ぜひ`
- `ご安心いただければと思います`

## 一人称・距離感

- 一人称: 僕ら / 弊社 / 私（場面で使い分け）
- 顧客への呼び方: `〇〇さん` / `〇〇さま`
- 距離感: 創業時からの最古参として、率直に事実を伝えつつ相談相手として寄り添う温度感

## メール反映の定型

- `〜いただければと思います`
- `お手元でゆっくりご覧いただけますと幸いです`
- `一つずつ確認させてください`
- `気兼ねなくお知らせください`
- `ご安心いただければと思います`

## 余白表現の出現

- `かと`: あり（例：「少し失礼かと思で」）→ 1通あたり0〜1回
- `かなと`: 限定的
- `できればと`: あり（例：「お役に立てるお話ができればと」）→ ネクストアクションで止めず着地させる

## 禁止候補

- `伝わってまいりました`
- 過度な美文・整いすぎた敬語
- `必ず成果が出ます` などの成果保証表現
