# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（確認・受け止めの口癖。非常に頻出）
- `かしこまりました`（依頼を受けたときの言い回し）
- `ありがとうございます`（相槌・お礼として頻出）
- `一応`（数字やプランを出すときの前置き。`一応弊社では`、`一応過去のデータで`）
- `まあ`（やわらげる接続）/ `ちょっと`（提案・依頼のクッション）
- `じゃあ` / `なので` / `だから` / `逆に`（段落間の自然な接続）
- `〜んですよ` / `〜じゃないですか`（仕組みをかみ砕く口語）
- `ご安心ください` / `全然サポートしているので`（不安をほどく定番）
- `〜という形になります` / `〜というイメージです`（説明の着地）
- `手前味噌ですが`（自己開示のクッション）

## 一人称・距離感

- 一人称: 僕ら / 僕（`僕らのビジネス`、`僕らの売り方`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 温度感: カジュアルで距離が近い。年齢や経歴の自己開示を挟み、相手を立てる。63歳の顧客に対しても「若く見える」と自然に持ち上げる。

## メール反映の定型

- `承知いたしました` / `かしこまりました`（受け止め）
- `〇〇という形になります`（説明の締め）
- `〇〇なイメージを持っていただければ大丈夫です`（不安への受け止め）
- `ご安心ください` / `何でも聞いていただければと思います`（相談導線）
- 依頼: `ご覧いただけますと助かります` / `ご確認いただけますでしょうか` / `〜いただければと思います`
- 締め: `よろしくお願いいたします` / `楽しみにしております`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思うので`、`失礼かと思いますので`、`本業にしていきたいというお考えかと思ですけれども`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`最後のチャンスかなと思って`、`大事になってくるかなと思いますので`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伺いできればなと思います`、`ご案内できればと思ですけれども`）→ 冒頭の温度感や軽い提案でのみ少量。依頼文の着地は曖昧にしない
- `見ていただけると`: 明確な出現なし → 使わない。依頼は「ご覧いただけますと助かります」で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗しにくい`、`確実に出る` と語る場面があるが、メールでは `〜という方が多いです`、`平均のデータでは` に留め、保証表現にしない）
- `めちゃくちゃ`（商談では `めちゃくちゃ嬉しい` `めちゃくちゃリスクない` と口語で多用するが、送付メールでは砕けすぎるため使わない）
- 過度な美文
- 顧客感情の断定
