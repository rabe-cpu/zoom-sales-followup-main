# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かと思います`（口癖。複数回。`お話ししにくいかと思うので`、`失礼かと思いますので`、`お役に立てるお話ができるかと思います`、`大丈夫かと思います`）
- `〜かなと思います`（`お伝えしていければなと思います`、`おすすめだなと思います`）
- `できればと思います`（`日程のご調整をできればと思います`、`しっかりとお伝えできればと思います`）→ 余白表現として発話にあり
- `一応`（`一応弊社では`、`一応リスクヘッジとして`）
- `正直`（`正直そこまで必要ないんですよ`、`正直なこと言うと`）
- `ちなみに`（話題の切り出し）
- `〜になりますね` / `〜という形になります`（説明の着地）
- `〜させていただければと思います` / `〜させていただきます`（依頼・案内の定番）
- `承知いたしました` / `かしこまりました`（丁寧な受け）
- `ありがとうございます`（相槌・お礼として頻出）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らの売り方`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 自己開示が多く、経歴・失敗談・趣味まで話してラポールを作るタイプ

## メール反映の定型

- `〜かと思います`（柔らかい提案・見立ての着地）→ 発話準拠で1通1〜2回まで
- `〜させていただければと思います`（案内・依頼）
- `〜という形になります` / `〜になりますね`（仕組みの締め）
- `一応` `正直`（前置きの柔らかさ）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`失礼かと思います`、`大丈夫かと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`おすすめだなと思います`、`お伝えしていければなと`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`日程のご調整をできればと思います`）→ ネクストアクションの着地で自然に使える。ただし文を途中で止めない
- `見ていただけると`: 明確な出現なし → 使わない。`ご覧いただけますと助かります` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `8割ぐらいが目標どおり` と語るが、`あくまで平均` `全員ではない` と自分で補正している。メールでは `〜という方が多いです` `平均で〜を目指せます` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
