# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（相槌・受け止めの定番。非常に頻出）
- `ありがとうございます` / `ご質問ありがとうございます`（お礼・質問への受け）
- `〜と思うので` / `〜かと思います` / `〜かと思うんですけれど`（やわらかい見立ての着地）
- `〜いただければと思います` / `お伝えできればと思います` / `お伺いできればなと思います`（依頼・提案の着地）
- `安心してください`（不安への受け止め）
- `遠慮なくおっしゃってください`（質問を促すとき）
- `ぜひ`（後押し。`ぜひ受けていただきたい` `ぜひ真剣に`）
- `じゃあ` / `じゃあですね`（話題転換）
- `逆に`（切り返しの接続）
- `〜という形になってます` / `〜というイメージですね`（説明の着地）
- `すごく〜` / `本当に〜`（強調。共感時に出る）
- `〜ですよね` / `わかります`（共感の相槌）

## 一人称・距離感

- 一人称: 僕ら / 僕（`僕らのシステム` `僕らが今やってます`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `承知いたしました。ありがとうございます。`（受け止め）
- `〇〇かと思います`（やわらかい見立て。1通1回まで）
- `〇〇いただければと思います`（依頼の着地）
- `安心してください`（不安への受け）→ メールでは `一緒に確認しながら進めます` 等に寄せる
- `〜という形になってます` / `〜というイメージですね`（説明の締め）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`検討していただいたかと思うんですけれど` `探していらっしゃるかと思うので` など `かと思う` の完成形で使用）→ メールでは `〜かと思います` を1通0〜1回までOK。文末で途中終止する `〜かと。` は使わない
- `かなと`: 明確な単独出現は確認できず → 使わない
- `できればと`: `お伝えできればと思います` `ご案内できればと思います` の完成形で使用 → ネクストアクションは `〜いただければと思います` `〜いただけますと助かります` で着地させる。途中終止の `できればと。` は使わない
- `見ていただけると`: `見ていただければ` の形で使用 → `ご覧いただけますと助かります` で着地

## 禁止候補

- `伝わってまいりました`（商談では `伝わってきました` の口語は出るが、AI臭い硬い敬語 `伝わってまいりました` は使わない。営業所感は1通で重ねず、判断材料の説明へ進む）
- 成果保証・断定（商談では `ちゃんとやれば収益出る自信がある` `返金保証があるので損のリスクはほぼない` と語る場面があるが、顧客送付用メールでは保証・断定表現にしない。`〜という方が多いです` 程度に留める）
- `必ず成果が出ます` / `安心して稼げます` / `誰でも簡単に`
- 過度な美文、顧客感情の断定
