# 栗原 哲也さん

## 商談内で見えた特徴

- `ざっくり（と）` / `ざっくばらんに`（説明のおさらいや切り出しで多用）
- `わかりやすく言うと`（かみ砕くときの前置き）
- `いわゆる`（用語をやさしく置き換えるとき）
- `そもそも`（前提から入るとき）
- `〜という形です` / `〜みたいな`（締め・言い換え）
- `おさらいがてら`（前回内容の振り返り）
- `承知いたしました` / `かしこまりました`（丁寧な受け）
- `ありがとうございます` / `おっしゃる通りで`（相槌・受け止め、頻出）
- `確かに確かに`（共感の相槌）
- デメリットも正直に伝える姿勢（`デメリットを言うと、めちゃくちゃ儲かる人は少ない` のように、良い面だけでなく限界も先に開示する）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らのビジネス`）、改まると 私 / 弊社（`私自身も`、`弊社`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 距離感: 共感を厚めに置き、相手の仕事や状況を具体的に受け止めてから本題へ進む

## メール反映の定型

- `ざっくりおさらいすると、〇〇です`（前回の振り返り）
- `わかりやすく言うと、〇〇という形です`（かみ砕き）
- `〜いただければと思います`（依頼の着地）
- `お伺いできればと思います`（次回接点の依頼）
- 正直な限界提示：`大きく儲かる方は多くないですが、より確実に副収入を作りたい方には合います` のように、過度に煽らない
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `できればと`: あり（`お伺いできればなと思います`、`ご返事も含めてできればと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`少し失礼かと思って`）→ 発話に沿う範囲で0〜1回までOK
- `かなと`: あり（`お勧めできるビジネスじゃないかなと`）→ 1通あたり0〜1回までOK
- `見ていただけると`: 単独の明確な出現は確認できず → 使わない

## 禁止候補

- `誰でも簡単に`（商談では会社スローガンの引用として出るが、メールでは成果誘引・断定に近いため使わない）
- 成果保証・断定（`必ず儲かる` 等は使わない。実績値は「平均」「目安」として提示し、保証にしない）
- `伝わってまいりました`（栗原さんの発話に確認なし）
- 顧客の不安・感情の断定
- 不安を煽る言い回し（顧客自身が「不安を煽る営業は感謝されない」と語っており、その価値観に合わせる）
