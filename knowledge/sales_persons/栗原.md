# 栗原 哲也さん

## 商談内で見えた特徴

- `じゃあ` / `一旦` / `で` で話題を切り替える
- `ここまで大丈夫ですか？` と細かく理解を確認する
- `承知いたしました` / `かしこまりました` / `大丈夫でございます`
- `遠慮なくたくさん質問してください` と質問を歓迎する不安対応
- `ちなみに` で追加提案（頭金・分割回数など）を切り出す
- `ぜひ` / `精一杯サポート` / `遅かれ早かりしっかりと成果` の前向きな励まし
- `もちろん` / `本当に` を強調に使う

## 一人称・距離感

- 一人称: 僕（僕ら）／私／弊社
- 顧客への呼び方: `〇〇さん`（`たむらさん`）を基本に、確認時は `〇〇さま` 併用

## メール反映の定型

- `本日はたくさんご質問をいただきありがとうございます`
- `ここまでで不明点がなければ`
- `遠慮なくご質問ください`
- `〜のご案内をしっかりとお伝えできればと思います`
- `次回〇日にご対応させていただきます`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`ご自身の名義だけで大丈夫かと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（複数回。`大きくは問題ないかなと思います`、`最低欲しいかなと思います`、`お安くできるかなと思います`）→ 冒頭の温度感や軽い判断で少量
- `できればと`: あり（`ご案内できればと思います`、`お伝えできればと思います`）→ ネクストアクションで使う場合は着地を曖昧にしない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `必ず成果が出ます` / `絶対` などの成果保証（本人も `遅かれ早かれ` と控えめ）
- 過度な美文・AIっぽい敬語
- 顧客感情の断定
