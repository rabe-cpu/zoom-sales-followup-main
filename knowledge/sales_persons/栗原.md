# 栗原 哲也さん

## 商談内で見えた特徴

- `ちなみに`（話題を差し込むときの接続。頻出）
- `あとは` / `逆に`（補足・対比を足すときの接続）
- `一応`（前置きのクッション。`一応弊社のシステムは`、`一応目標は24時間なんで`）
- `補足として`（情報を追加するときの切り出し）
- `かしこまりました` / `承知いたしました`（受け・締めで非常に頻出）
- `よかったです。よかったです`（安心を返すときに重ねる相槌。温かい）
- `そうですよね`（共感の相槌）
- `〜させていただいて` / `〜させていただきます`（丁寧な行為提示）
- `ぶっちゃけ` / `全然` / `すごーい`（要点をかみ砕く／打ち解けた場面のくだけた表現）

## 一人称・距離感

- 一人称: 弊社 / 僕・僕ら（`僕らのシステム`、`僕も個人で月5,000,000ぐらい仕入れてるんで`、`僕の感覚ですけど`）、改まると 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。会話が乗ると `新さん` のように短縮も）
- 敬語は丁寧だが硬すぎず、経験者相手には事実ベースで端的に返す

## メール反映の定型

- `承知いたしました` / `かしこまりました`（受けの締め）
- `〜いただければと思います`（依頼の着地。`ご確認いただければと思います`）
- `〜いただきたいので`（次アクションの依頼）
- `よかったです`（安心の受け止め。ただし多用しない）
- `ちなみに` / `あとは` / `補足として`（段落間の自然な差し込み）
- 締め: `今後ともどうぞよろしくお願いします`

## 余白表現の出現

- `かと`: あり（`スーパー以内ぐらいかと思いますね`、`24時間は全然バッファーは余裕あるかと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`プレミアムの方が御社には合うかなと`）→ 1通あたり0〜1回までOK
- `できればと`: 単独での明確な出現は確認できず → ネクストアクションは「いただければと思います」「ご確認いただけますと助かります」で着地させる
- `見ていただけると`: 明確な出現なし（`ここで見てもらえれば` はあり）→ 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益断定（商談では平均をベースに「最悪これぐらいの方もいる」と幅で語る。メールでは `〜という方が多いです` 程度に留め、`稼げます` `必ず回収できます` のような保証表現にしない）
- 審査結果の断定（`審査が入る` という事実は述べるが、通過を約束しない）
- 過度な美文・顧客感情の断定
