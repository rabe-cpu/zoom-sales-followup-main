# 栗原 哲也さん

## 商談内で見えた特徴

- `じゃあ` / `早速`（本題への切り出しで多用）
- `一応`（前置き・保険をかけるときの接続）
- `なので`（結論・依頼につなぐ接続）
- `逆に言うと` / `要は`（要点を言い換えるときの接続）
- `ちなみに`（追加確認を差し込むときの接続）
- `〜という形になります` / `〜という形です`（締め・仕組み説明の着地）
- `〜のイメージですかね？` / `〜という認識で大丈夫ですかね？`（相手に確認を返す）
- `かしこまりました` / `わかりました`（受け止めの相槌。非常に頻出）
- `ご安心いただければと思います` / `遠慮なく頼っていただければ`（不安をほどく定番）
- `一緒に〇〇していきましょう` / `ちょっと頑張りましょう`（伴走を示す締め）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのビジネス`、`僕らにとっての`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん` / `〇〇さま`（商談中は基本さん付け、丁寧な場面はさま）
- 相手の状況（お子さん・お仕事終わり・体調）にひと言触れてから本題へ入る温度感がある

## メール反映の定型

- `じゃあ〇〇していければと思います`（本題・提案への移行）
- `〇〇という形になります`（手順・仕組みの着地）
- `〇〇していただければと思います`（依頼の基本形。着地させて止めない）
- `ご安心いただければと思います` / `遠慮なくご質問ください`（安心導線）
- `一緒に確認していきましょう` / `ちょっと頑張りましょう`（次アクションの伴走）
- 締め: `何卒よろしくお願いいたします` / `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`いいかと思います`、`不安なところもあるかと思いますが`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`当てられるかなと`、`できればなあと`）→ 1通あたり0〜1回まで、冒頭の温度感か軽い提案でのみ
- `できればと`: 明確な単独出現は確認できず → ネクストアクションは「いただけますと助かります」「ご返信いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → `ご覧いただけますと助かります` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では平均データや期限を示す場面があるが、メールでは `平均で〜という方が多いです`、`〜が目安です` 程度に留め、保証表現にしない）
- 審査・与信の通過を約束する表現（`必ず通ります` などは使わない。`申し込んで審査してみないと分からない` と本人も話しているため、確定的に書かない）
- 過度な美文・顧客感情の断定
