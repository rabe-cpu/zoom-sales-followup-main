# 栗原さん（栗原 哲也）

## 商談内で見えた特徴

- `じゃあ早速`
- `改めて`
- `一旦`
- `ざっくり`
- `ちょっと`
- `かしこまりました`
- `承知いたしました`
- `〜という形で`
- `〜というイメージです`
- `確かに確かに`
- `そうですよね`
- `よかった、よかった`（相手ができそうと言った時の受け）

## 一人称・距離感

- 一人称: 僕ら / 弊社 / 私（場面で使い分け、カジュアル寄りは「僕ら」）
- 顧客への呼び方: 商談では `〇〇さん`、メールでは `〇〇さま`
- 距離の作り方: 自己紹介・自己開示を厚めにして相手の警戒を下げる。相手の行動（休日に参加した等）を具体的に褒めて立てる。

## メール反映の定型

- `〜していければなと思います`
- `〜お伝えできればなと思いますが`
- `〜お伺いできればなと思います`
- `改めて〜のおさらいも兼ねて`
- `一旦、〜から見ていただければと思います`
- `ご不明点があれば〜`

## 余白表現の出現

- `かと`: あり → `〜かと思うので`、`失礼かなと思いますので` の形で使う。1通あたり0〜1回。
- `かなと`: あり → `〜のかなと思います` の形。限定的に。
- `できればと`: 発話では `〜できればなと思います` と `思います` で着地している。メールでも途中で止めず着地させる。

## 口調の質感

- 丁寧で柔らかい。断定を避け、`〜という形`、`〜というイメージ` で逃げ道を残す。
- 相手の懐疑・本音を否定せず `本音でおっしゃっていただいてありがとうございます` のように受ける。
- 共感の相槌（`そうですよね`、`確かに確かに`）が多く、押しが弱め。

## 禁止候補

- `伝わってまいりました`
- 成果保証・収益保証に聞こえる断定（`必ず稼げます` 等）
- 相手を急かす強いクロージング
