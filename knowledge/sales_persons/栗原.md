# 栗原さん

## 商談内で見えた特徴

- `承知いたしました`
- `という形です` / `という形になっています`
- `ご安心いただければと思います`
- `お役に立てるお話ができればなと`
- `お間違いないでしょうか`
- `一旦` / `ちなみに` / `逆に`

## 一人称・距離感

- 一人称: 僕ら / 弊社 / 私
- 顧客への呼び方: `〇〇さま`
- 事業部最古参・創業メンバー。仕組みや理由を分解して説明する落ち着いた口調。

## メール反映の定型

- `〜という形になっています`（仕組み・条件の説明）
- `ご確認いただければと思います`
- `お伝えできればと思います`
- `ご安心いただければと思います`
- `日程を調整できればと思います`

## 余白表現の出現

- `かと`: あり（`失礼かと`、`関係あるかと思います`、`問題ないかと思います`）→ 1通あたり0〜1回
- `かなと`: あり（`お役に立てるお話ができればなと`）→ 限定的
- `できればと`: あり（`お伝えできればと思うので`、`調整できればと`）→ 依頼文は着地させる

## 禁止候補

- `必ず収益が出ます` / `稼げます` のような成果・収益保証
- `伝わってまいりました`
- 顧客の不安を `大丈夫です` だけでまとめる断定
