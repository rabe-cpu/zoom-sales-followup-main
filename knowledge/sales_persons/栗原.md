# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（確認・受け止めで多用）
- `もちろんです。もちろんです。`（安心を返すときに繰り返す）
- `〜という形になっております` / `〜なってます`（仕組み・条件の説明）
- `〜かなと思います` / `〜と思います`（柔らかい判断・提案）
- `ぜひ` / `しっかり`（前向きな後押し）
- `じゃあ` / `で、` / `あとは` / `一旦` / `改めて` / `要するに`（話の切り替え・整理）
- `〜させていただく`（説明・案内）
- `ありがとうございます`（相槌・受け止め）

## 一人称・距離感

- 一人称: 僕（僕ら／僕らの）と私（私が／私も）を併用。会社は `弊社`
- 顧客への呼び方: `〇〇さん`（商談中は「八木さん」）。メールでは `〇〇さま`

## メール反映の定型

- `今日はしっかりお伺いしながら、合うかどうか一緒に整理できればと思います`
- `〜については、改めて資料をお送りさせていただきます`
- `ご不明な点が出てきましたら、お気軽にご連絡いただけますと幸いです`
- `〜という形になっております`
- 受け止め: `承知いたしました` / `かしこまりました`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`上のプランもありかなと思う`、`親和性あるかなと`）→ 1通あたり0〜1回までOK
- `かと`: 明確な多用は確認できず → 文末で多用しない
- `できればと`: `整理できればと思います` / `お話ししていければと思います` の形であり → ネクストアクションでは「〜と思います」「お送りします」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では「絶対売れない」等を商品説明で使うが、顧客送付メールでは成果保証・収益保証表現にしない）
- 過度な美文
- 顧客感情の断定
