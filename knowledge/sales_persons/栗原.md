# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（口癖。頻出。前置きや確認の切り出しで多用。`一応今日は`、`一応プランは`、`一応七日も空いてます`）
- `そうですね`（相槌・受け止めとして非常に頻出）
- `よかったです`（顧客の状況が整ったときの反応。`よかったです。よかったです。`と重ねることもある）
- `承知いたしました` / `かしこまりました`（依頼・確認を受けたときの締め。丁寧）
- `ちょっと`（やわらかい前置きのフィラー）
- `正直`（率直に伝えるときの前置き。`正直、仕入れのカードはどなた名義でも問題はないので`）
- `個人的には`（おすすめを添えるときの表現。`個人的にはこっちの方がおすすめかもしれないですね`）
- `ご注意いただければと思います` / `ご注意いただけるといいかなと思います`（注意喚起の定番）

## 一人称・距離感

- 一人称: 私 / 弊社（`私の方から`、`私がご案内した方`、`弊社ご参加してくださって`）。改まらない相槌では地の話し方も出る
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。`飯島さん`）

## メール反映の定型

- `一応〇〇させていただくと`（前置きして情報を足す）
- `正直、〇〇なので`（率直に判断材料を伝える）
- `個人的には〇〇かもしれないですね`（押しつけず、おすすめを添える）
- `そこだけご注意いただければと思います`（注意点をやわらかく1つ置く）
- `承知いたしました` / `かしこまりました`（受け止めの締め）
- 締め: `よろしくお願いいたします` / `ありがとうございます`
- 温度感: 顧客の判断や姿勢を素直に称える（`すごいですね`、`群馬の40代の成功例って感じですね`、`楽しみにしてるので`）。ただし成果保証にはしない

## 余白表現の出現

- `かなと`: あり（`ご注意いただけるといいかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`郵便受けで届くかと思うので`、`いろいろあるかと思うんですけれど`）→ 発話準拠で少量OK
- `いただければと`: あり（`ご注意いただければと思います`、`記入していただければと思います`）→ ネクストアクションの着地に使える
- `できればと`: 出現なし → 使わない
- `見ていただけると`: 出現なし → 使わない（`ご覧いただきたく`は使用あり）

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では顧客の将来を前向きに語る場面が多いが、`必ず`『稼げます』のような保証表現は使わない。`収益を上げている方多いので`程度に留める）
- 過度な美文
- 顧客感情の断定
