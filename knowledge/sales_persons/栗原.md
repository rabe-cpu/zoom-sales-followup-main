# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（進行・受け止めで非常に頻出。相手の話を受けてから次へ進む）
- `かしこまりました`（依頼・条件を受けた時の丁寧な受け）
- `一応`（`一応弊社のプランが`、`一応これが`、`一応今日この後の流れ` など前置きで多用。断定を和らげる）
- `ちなみに`（話題の切り出し）／`改めて`（説明の仕切り直し）／`逆に`（視点の切り替え）／`実は`（特典・背景の開示）
- `〜させていただきます` / `〜させていただければと思います`（案内・依頼の定番着地）
- `〜という形になります` / `〜という形です`（仕組み説明の着地）
- `〜イメージです`（収益・手残りの説明の締め）
- `気になった点はありますか` / `ご不安はなさそうですか`（都度の確認をこまめに挟む）
- `お気軽に` / `遠慮なく`（質問・相談の導線を軽くする）
- `ありがとうございます` / `詳しく教えていただいてありがとうございます`（相手の発言を受けたお礼が多い）

## 一人称・距離感

- 一人称: 僕 / 僕ら / 私（`僕の方で`、`僕らのシステム`、`私としては`）、弊社
- 顧客への呼び方: `樋口さん`（さん付け中心）
- 自身も経営者・現役ネットショップ運営者としての実体験を交え、対等な相談相手として進めるスタイル
- 顧客が懐疑的・慎重なときは反論せず `確かに` `おっしゃる通り` と一度受け止めてから判断材料に戻す

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `〜お伝えできればと思います` / `〜ご案内できればと思います`
- `お気軽にご質問いただければと思います` / `遠慮なくご質問いただければと思います`
- `ぜひ一度ご覧いただければと思います`
- `また来週お話しできるのを楽しみにしております`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思いますので`、`あったかと思いますけれども`、`投資しないといけないかと思うので`、`余裕があるかと思いますけれども`）→ 1通0〜1回までOK
- `かなと` / `かな`: あり（`失礼かなと思いますので`、`お役に立てる話ができるかなと思います`、`合いそうかなっていう`）→ 0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`、`お話をお伺いできればと思います`、`ご案内できればと思います`）→ 着地として自然に使用可。依頼文を途中で止めない
- `見ていただけると`: `ご覧いただければと思います` / `ご確認いただければと思います` の形で頻出 → `ご覧いただけますと幸いです` 等の着地ならOK

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では継続率・達成率などの数字を出すが、メールでは「必ず」「確実に儲かる」に変えない。むしろ樋口さまは「確実な話は信用できない」と明言しており、保証口調は逆効果）
- 審査・返金保証を「絶対」「無条件」と読める書き方（返金保証には出品条件・期間条件があるため断定しない）
- 過度な美文・顧客の不安の断定や煽り
