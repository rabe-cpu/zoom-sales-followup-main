# 栗原 哲也さん

## 商談内で見えた特徴

- `じゃあ` / `えっと`（切り出し・話題転換で頻出）
- `まあ`（やわらげの接続。多用）
- `ちなみに`（追加で聞くときの前置き。`ちなみにフランチャイズって〜`）
- `実は`（特典・新情報を出すときの前置き。`実はですね、今、期間限定で〜`）
- `なんで` / `だから`（理由から結論へつなぐ）
- `改めて`（`改めてご説明させていただくと`）
- `一応`（`一応今日お見せした資料は`）
- `〜という形です` / `〜という形になります`（締めの定番）
- `〜と思います` / `〜と思いますね`（所感・提案の着地）
- `かしこまりました` / `承知いたしました`（依頼受けの相槌）
- `おっしゃる通りですね`（顧客の理解を肯定するとき）

## 一人称・距離感

- 一人称: 私 / 僕・僕ら（`僕らのシステム`、`僕らも直営店で`）、改まると 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 自己開示が多め（創業メンバー・11年在籍、自身も個人でネットショップ経営という実体験を語る）。メールでは商談で触れた範囲に留め、盛らない。

## メール反映の定型

- `〇〇という形です` / `〇〇という形になります`（仕組み・条件の締め）
- `〇〇かなと思います` / `〇〇と思いますね`（提案の着地）
- `改めてご案内させていただきます`（資料送付の導線）
- `〇〇していただければと思います`（依頼の着地）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`進めにくいかと思うので`、`投資しなきゃいけないかと思ですけれども`、`あったかと思ですけれども`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`ご紹介できるかなと思うので`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`、`お役に立てるお話ができればと思います`、`ご提案ができればと思って`）→ 冒頭の温度感・軽い提案でのみ少量
- `見ていただけると`: 明確な出現なし（`見ていただきたくて`はあり）→ そのままは使わず、ネクストアクションは`ご覧いただけますと助かります`で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では`失敗がすごく少ない`、`再現性が高い`と語るが、メールでは`〜という方が多いです`程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 根拠のない`すごく` / `めちゃくちゃ`（商談では口頭で使うが、メールでは商談事実に沿う範囲だけにする）
