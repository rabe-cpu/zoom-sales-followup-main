# 栗原 哲也

株式会社NEXT（総合物販システム＿アクセス）事業部の営業担当。この事業部では一番の古株で、個人でも無在庫物販を実践しているプレイヤー。個別相談会（2回目接点）を担当することが多い。

初回登録日: 2026-07-27（かわさきゆきひろ様 個別相談会の文字起こしから抽出）

## 抽出した口調特徴（実発話ベース）

| 項目 | 実発話にある表現 | メールへの反映 |
|---|---|---|
| 一人称 | 私、弊社 | 署名・本文の距離感は「私」「弊社」 |
| 承諾・受け | 承知いたしました、かしこまりました | 顧客の話を受け止める締め |
| 案内・依頼 | お送りさせていただきますね、ご確認ください、〜いただければと思います | 資料案内・ネクストアクション |
| 安心対応 | ご安心ください、もちろんです、そんなことないですね | 不安対応・相談導線 |
| 共感 | そうですよね、〜ですよね | 顧客の状況に寄り添う一文 |
| 承認・持ち上げ | 素晴らしいですね、素晴らしい考え方ですね、さすがです、ありがとうございます | 冒頭の会話反映（多用しない） |
| 説明の締め | 〜となっております、〜になります、〜と思いますので | プラン・作業内容の案内 |
| 余白表現 | かと（例:「お役に立てるお話が今日できるかと思います」「失礼かと思いますので」） | 冒頭の温度感・軽い提案で1通0〜1回 |

## メール反映で使ってよい表現

- 承知いたしました。/ かしこまりました。
- この後メールで資料をお送りさせていただきますね。
- ご確認いただければと思います。
- ご安心ください。/ もちろんです。
- そうですよね。（共感の受け）
- 〜かと思います。（冒頭の温度感・軽い提案でのみ、1通0〜1回）

## 余白表現の扱い

- `かと`: 栗原の実発話に複数回あり（「お話ししにくいかと思いますので」「失礼かと思いますので」「お役に立てるお話が今日できるかと思います」）。冒頭の温度感や軽い提案で1通に0〜1回まで使ってよい。
- `かなと` / `できればと` / `見ていただけると`: 栗原の実発話には確認できなかった。今回は使わない。依頼文は「〜いただけますと助かります」「ご確認ください」で着地させる。

## 禁止・注意候補

- `伝わってまいりました` などの過度な美文敬語
- 成果保証・収益保証に聞こえる断定（「必ず稼げます」「絶対に収益が出ます」）
- 顧客が言っていない感情・不安の断定
- 承認・持ち上げ表現（「素晴らしい」「さすが」）の多用。メールでは冒頭に多くても1回まで。
