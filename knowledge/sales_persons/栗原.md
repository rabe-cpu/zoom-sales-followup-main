# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かなと思っています` / `〜かなと思うので` / `〜かなと思います`（口癖。判断や所感の着地で多用。`向いてるかなと思っています`、`失礼かなと思うので`、`ベストかなと思います`）
- `〜かと思います`（`一時間ちょっとざっくりした内容でいらっしゃったかと思で`、`あるかと思ですけど`）
- `〜していければと思います` / `〜お伝えしていきたいと思います`（提案・案内の切り出し）
- `ご安心ください` / `ご安心いただければと思います`（不安をほどくときの定番）
- `かしこまりました` / `承知いたしました` / `わかりました。わかりました。`（受けの相槌。繰り返しがち）
- `いやー、すごい` / `すごい` / `ガッツがありますね`（顧客の行動を具体的に褒めて持ち上げる）
- `ありがとうございます` / `ありがとう`（相槌・お礼として頻出）
- `一旦` / `改めて` / `ちなみに` / `で、` / `じゃあ` / `じゃあですね`（段落間の自然なつなぎ）
- `遠慮なく`（`遠慮なく受けられるように`）
- `もちろん大丈夫ですよ` / `全然〜できます` / `無理せず`（相手の選択を肯定する受け）
- `〜だなと感じました` / `心から思ってます`（所感の一文。多用はしない）

## 一人称・距離感

- 一人称: 私 / 僕 / 僕ら（`私の方からね`、`僕ら五年間`、`僕らのビジネス`）、改まると 弊社
- 顧客への呼び方: `渡辺さん`（商談中は基本さん付け）
- 距離感: 同年代・共通点（同級生・経営者）を見つけて距離を縮めるが、押しは強くしない

## メール反映の定型

- `〇〇かなと思っています`（判断・所感の着地。1通あたり0〜1回まで）
- `〇〇していければと思います`（次の案内への切り出し）
- `ご安心ください` / `ご安心いただければと思います`（不安への受け止め）
- `無理せず、まずは〇〇からで大丈夫かと思います`（選択の肯定）
- 冒頭の持ち上げは具体的な行動事実に紐づける（例: 法人設立まで動いた行動力）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`向いてるかなと思っています`、`ベストかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`あるかと思ですけど`、`〜かと思で`）→ 1通あたり0〜1回までOK、依頼文の着地は曖昧にしない
- `できればと`: あり（`お役に立てるお話ができればと思います`）→ 冒頭の温度感・軽い提案でのみ少量
- `見ていただけると`: 明確な出現なし → 使わない。資料案内は`ご覧いただけますと助かります`で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗がしにくい`、`全然目指せます`、`この通りに行ってる方多い` と語るが、メールでは保証表現にせず `〜という方が多いです`、`平均のデータです` 程度に留める）
- 審査・与信の確約（`審査が通ります` のような断定はしない。`最終審査があります` の事実までに留める）
- 過度な美文
- 顧客感情の断定
