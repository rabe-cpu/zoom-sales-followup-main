# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました` / `承知いたしました`（受け止め・締めで非常に頻出。同じ返答を2回重ねることもある）
- `〜していければなと思います` / `〜できればなと思います`（提案・進行の柔らかい着地）
- `〜かと思いますけれども`（前置き・留保。`ゼロではないかと思いますけれども`、`たくさん種類あるかと思いますけれども`）
- `〜かなと思うので`（見立てを控えめに出す。`条件マッチしてくるかなと思うので`）
- `早速ですね` / `じゃあ` / `では`（話題の切り替え）
- `ありがとうございます` / `こちらこそです`（相槌・お礼として頻出）
- `遠慮なく〜いただければなと思います`（相談導線の締め）
- `ちなみに`（軽い質問の切り出し）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らはそういう商品を`、`僕らみたいな個人`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `〇〇していければなと思います`（次の一歩の柔らかい提案）
- `〇〇かと思いますけれども、〇〇です`（留保を置いてから事実を伝える）
- `遠慮なくご相談いただければなと思います`（安心導線）
- `かしこまりました` / `承知いたしました`（受け止め）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`〜かと思いますけれども` を複数回）→ 1通あたり0〜1回までOK
- `かなと`: あり（`条件マッチしてくるかなと思うので`）→ 1通あたり0〜1回までOK。冒頭の温度感か軽い提案でのみ
- `できればと`: `お話できればと思うので` の形はあり → ネクストアクションは着地形（`いただけますと助かります`）を優先し、途中で止めない
- `見ていただけると`: 明確な出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `ほとんど失敗する確率がない`、`七ヶ月やればもう出てきます` と語る場面があるが、メールでは千名以上の平均データという事実の範囲に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
