# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（相槌・受け止めで非常に頻出）
- `〜させていただければと思います`（依頼・案内の定番の着地）
- `〜と思いますので` / `〜かなと思うので`（提案の柔らかい導入）
- `ぜひ`（案内・お誘いの前置き）
- `要するに` / `つまり`（仕組みをかみ砕いて言い換えるとき）
- `まあ` / `ええ`（説明中のつなぎ。多用するので文章では減らす）
- `〜なんですよ` / `〜なんですね`（仕組みや根拠を伝えるときの語尾）
- `〜という形`（締めの言い回し）
- `ぶっちゃけ` / `ざっくり`（質問をやわらげるカジュアル表現。本文では控えめに）

## 一人称・距離感

- 一人称: 僕ら / 僕（`僕らのビジネスモデル`、`僕らが狙っている`）、改まると 弊社 / 私
- 顧客への呼び方: `神田さん`（※VTTでは音声認識で「患者さん」と誤変換されている箇所が多いが、実際は「神田さん」。メールでは必ず正しい宛名にする）

## メール反映の定型

- `承知いたしました`（受け止め）
- `〜させていただければと思います`（案内・依頼の着地）
- `要するに〇〇です` / `つまり〇〇です`（仕組みの言い換え）
- `ぜひ〇〇ください`（やわらかい案内）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`進めにくいかと思うので`、`情報収集されている段階かと思います`、`ベストな選択かと思うので`）→ 複数回確認。1通あたり0〜1回までOK
- `かなと`: あり（`失礼かなと思うので`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`、`お伺いできればと思います`）→ 冒頭の温度感・軽い提案でのみ少量OK
- `見ていただけると`: 出現なし（`見ていただきたい` `見ていただくと` はある）→ `見ていただけると` は使わない。ネクストアクションは `ご覧いただけますと助かります` で着地させる

## 禁止候補

- `患者さん`（VTTの誤変換。宛名・本文では絶対に使わない）
- 成果保証・断定（商談では `失敗がないビジネス` `81.4%` `他にビジネスはない` と強めに語る場面があるが、メールでは `〜という方が多いです` `堅実に取り組まれています` 程度に留め、`必ず`『安心して稼げます』などの保証表現にしない）
- 過度な美文・AI臭い敬語（`伝わってまいりました` は発話に確認なし）
- 顧客感情の断定
