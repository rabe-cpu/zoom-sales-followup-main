# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました` / `承知いたしました`（締め・受けの定番、非常に頻繁）
- `一応` / `もちろん` / `ちなみに` / `逆に`
- `しっかりと`（`しっかりとご案内したい`、`しっかりお伝えできればと思います`）
- `〜できればと思います`（`お話できればと思います`、`ご案内してまいりたいと思います`）
- `〜いただければと思います` / `〜いただけると`
- `率直におっしゃっていただいて`（顧客の本音を歓迎する受け）
- `ご質問いただけて嬉しかったです` / `ありがとうございます`（お礼が厚い）
- `かと` 系の柔らかい判断（`ご安心いただいて大丈夫かと。`）
- `かなと` 系（`おすすめかなと`、`吉田さんの条件ではすごくマッチするかなと`）

## 一人称・距離感

- 一人称: 僕／僕ら／弊社
- 顧客への呼び方: `〇〇さん` / `〇〇さま` 併用（本文の宛名は `さま`）

## メール反映の定型

- `本日はお時間をいただきありがとうございました`
- `ご質問いただけて嬉しかったです`
- `一応、〜もお送りいたします`
- `しっかりとご案内できればと思います`
- `ご覧いただいたうえで`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`ご安心いただいて大丈夫かと。`）→ 1通あたり0〜1回までOK、文末で連発しない
- `かなと`: あり（`おすすめかなと`、`マッチするかなと`）→ 0〜1回までOK
- `できればと`: あり（`お話できればと思います`）→ ネクストアクションでは「〜と思います」「〜いたします」で着地させる
- `見ていただけると`: 直接出現なし（`ご覧いただけると` は近い）→ 依頼文では着地形に寄せる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 過度な美文・情緒過多
- 顧客感情の断定
- 「必ず」「絶対」「稼げます」など成果保証に聞こえる表現（商談では平均値・シミュレーションとして案内しており、断定はしていない）
- 副業と会社の関係について「会社にバレない」を断定的に書くこと（税務面はデリケートなため、案内は勉強会・確定申告の一般論に留める）
