# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（前置き・補足で多用。`一応ね`、`一応補足だと`、`一応期限が`）
- `まあ`（やわらげ・要約の接続。頻出）
- `なので`（結論・次アクションへの接続）
- `正直`（率直に伝えるときの前置き。`正直包み隠さず言うと`、`正直プラスアルファの収入`）
- `結構`（程度を示す。`結構詳細なことが`、`結構強制力働く`）
- `おそらく` / `一つ仮説としては`（推測を断定にせず仮説として置く）
- `例えば`（たとえ話で噛み砕く。ライザップ・ジム・店舗ビジネスに例える）
- `そうですよね` / `そうです。そうです`（強めの相槌・共感）
- `かしこまりました` / `承知いたしました`（受け止め）
- `ありがとうございます`（相槌・お礼として頻出）

## 一人称・距離感

- 一人称: 僕ら / 弊社（`僕らのいいところは`、`弊社の方で`）、改まると 私（`私の方で回答させていただく`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `一応〇〇なので`（前置きで情報を添える）
- `なので、〇〇いただければと思います`（結論から次アクションへ）
- `正直〇〇です`（率直な情報開示。数字・データを隠さず出す姿勢）
- `おそらく〇〇かなと思います`（断定せず仮説として置く）
- `少しでも気になるところ引っかかるところあれば、メールでもすぐ私の方で回答させていただきます`（安心導線の定番）
- 締め: `よろしくお願いいたします` / `ありがとうございます`

## 余白表現の出現

- `かなと`: あり（`該当しない方かなと思ですけど`、`日程大丈夫かなと思って`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`改めて契約日を調整できればと思ですけれども`）→ 1通あたり0〜1回まで。依頼の着地が曖昧にならない範囲で使う
- `かと`: 単独での明確な出現は確認できず → 使わない
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`取り組めば収益化売り上げにつながるっていうのは確信してる` と語る場面はあるが、同時に `必ず上手くいくビジネスがあるわけではない` と率直に補足している。メールでは `取り組まれた方は成果につながっている` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 継続率・解約率・アクティブ率などの社内数値を顧客送付メールにそのまま書かない（口頭では率直に共有していたが、書面では一般化した表現に留める）
- 既存利用者の氏名・契約日・登録数など第三者の個人情報（`社外秘` と明言。顧客送付メールに固有情報を残さない）
