# 栗原 哲也さん

## 商談内で見えた特徴

- `もちろんね`（相手の考えを一度受け止めてから続けるときの切り出し）
- `そうですよね`（強い共感の相槌。顧客の不安に何度も重ねる）
- `私としては` / `私の経験上`（自分の見解・経験を根拠に添える）
- `一緒に頑張っていきましょう` / `一緒に頑張って`（クロージングの鼓舞）
- `承知いたしました`（要望を受けたときの受け止め）
- `〜した方がいいんじゃないのかな` / `〜べきだと思います`（やわらかい主張）
- `安心いただければと思います` / `安心してくださいよ`（不安をほどく定番）
- `本当に`（気持ちを込めるときの強調。多用）

## 一人称・距離感

- 一人称: 私（`私としては`）/ 僕ら（`僕らのシステム`、会社を指すとき）、改まると 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `もちろん〇〇というタイミングでもいいかと思いますが、私としては〇〇`（受け止め→見解）
- `私の経験上、〇〇という方が多いです`（保証にせず経験で支える）
- `一緒に頑張っていきましょう`（前向きな締め）
- `安心いただければと思います`（サポートの安心導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`いいかと思いますが`、`興味を持ってくださったかと思うので`、`分かるかと思います`）→ 1通あたり0〜1回まで、穏やかな受け止めで可
- `かなと`: あり（`一番かなと思います`、`難しいんじゃないかなと`）→ 1通あたり0〜1回まで可
- `できればと`: 明確な出現なし → ネクストアクションは「いただけますと助かります」「ご連絡いただけますでしょうか」で着地させる
- `見ていただけると`: 明確な出現なし → `ご覧いただければ` で着地させる

## 禁止候補

- `必ず成果が出ます` / `絶対に稼げます`（商談では「絶対とは言えませんが」と自ら留保している。メールでも保証表現にしない）
- `伝わってまいりました`（栗原さんの発話に確認なし）
- 過度な美文・顧客感情の断定
- 審査・回収の断定（`必ず通ります` `必ず回収できます` にしない）
