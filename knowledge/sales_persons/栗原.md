# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（前置きで多用。「一応弊社」「一応この後の流れ」）
- `まあ`（緩衝のクッション言葉）
- `改めて` / `承知いたしました`
- `ご安心ください`
- `要するに` / `逆に` / `ちなみに`
- `〜みたいなイメージでいらっしゃいますか`（相手の状態を確認する問い）
- `〜かなと思います`（柔らかい判断）
- `ぜひぜひご準備いただければと思います`
- 相手の発言を受けて `さすがですね` / `おっしゃる通りです` と一度受け止めてから展開する

## 一人称・距離感

- 一人称: 僕ら / 僕 / 弊社 / 私（説明時は「僕ら」、会社主語は「弊社」）
- 顧客への呼び方: `中原さん`（`さん` 付けが基本。`さま` は書き言葉で使用）
- 距離感: 自己開示（自身の経歴・独立失敗談）を先に出して相手も話しやすくする進め方

## メール反映の定型

- `改めて、本日はありがとうございました`
- `一応こちらの資料もお送りさせていただきます`
- `〜いただければと思います`
- `ご質問とかもぜひぜひご準備いただければと思います`
- `ご不明な点があれば、お気軽にご連絡ください`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: 実発話に複数回あり（「失礼かと」「お話しさせていただいたかと思います」）→ 1通あたり0〜1回まで、文末で多用しない
- `かなと` / `かなと思`: あり（「合ってるかなという印象ですね」「進めやすいかなと思います」）→ 1通あたり0〜1回OK
- `できればと`: あり（「お伺いできればと思います」）→ ネクストアクションでは「〜と思います」で着地させ、文を途中で止めない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 過度な美文・整いすぎた敬語
- 顧客感情の断定
- 成果保証・断定的な収益表現（本人も「大成功はあまりない」「失敗しにくい」と堅実に表現している）
