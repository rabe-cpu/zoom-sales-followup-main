# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました`（相槌・受け止めで非常に頻出）
- `承知いたしました`（確認の締めで頻出）
- `わかりました。わかります。`（共感を重ねる言い方）
- `じゃあですね` / `じゃあ早速ですね`（話題の切り替え）
- `そっか、じゃあ〜`（顧客の話を受けて噛み砕く）
- `ちなみに〜`（軽い質問の切り出し）
- `一旦` / `改めて` / `逆に言うと`（接続）
- `〜という形になります` / `〜というようなイメージになります`（説明の着地）
- `〜していただければと思います`（依頼の柔らかい着地）
- `すごいですね` / `おお、すごい` / `いいですね`（顧客の話に乗って褒める。温度を上げる相槌）
- `よかった。よかった。`（顧客の不安が解けたときの受け）

## 一人称・距離感

- 一人称: 僕ら / 僕（`僕らがアマゾンで`、`僕らのショップ`、`個人的にも本当にスタンダードがおすすめです`、`僕の方で`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中はさん付け。親しみのある距離感で、相手の経歴や事業に素直に関心を示す）

## メール反映の定型

- `本日はお話を伺う中で〜と感じました`（冒頭の会話反映）
- `〜という形になります` / `〜というイメージです`（説明の締め）
- `まずは〜を確認しながら進められればと思います`（主導権を取りすぎない進め方）
- `〜していただければと思います`（依頼の着地）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話進めにくいかと思うので`、`必要かと思いますので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`どっちかかなと思います`、`〜かなと`）→ 1通あたり0〜1回までOK（`かと`と合わせて1通に1回まで）
- `できればと`: 単独での明確な出現は確認できず → 使わない。ネクストアクションは「いただけますと助かります」「ご返信いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗する方は少ない`、`95%の方は継続` と語るが、メールでは `〜という方が多いです` 程度に留め、収益保証・審査通過保証にしない）
- 過度な美文
- 顧客感情の断定
