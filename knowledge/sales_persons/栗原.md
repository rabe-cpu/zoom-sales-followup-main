# 栗原 哲也さん

## 商談内で見えた特徴

- `〜させていただければと思います` / `〜させていただきます`（依頼・案内の中心。`お伺いさせていただいて`、`お伝えさせていただきます`、`ご紹介していきます`）
- `〜できればと思います`（`お伝えできればと思います`、`お答えられるようにお話できればと思います`、`ご理解を深めていただければと思います`）
- `〜かと思います`（`話進めにくいかと思います`、`受けてくださったかと思います`、`あまり売るジャンルではないかと思いますね`）
- `〜かなと思います`（`一番検討しやすいかなと思います`、`一番時間をかけていただくべきところかなと思いますね`）
- `〜という形です` / `〜というイメージです`（説明の着地。森田さんと近い）
- `かしこまりました` / `承知いたしました`（受けの定番）
- `さすがです` / `おっしゃる通りです`（顧客の理解・指摘を持ち上げる相槌が非常に多い）
- `ありがとうございます`（相槌・お礼として頻出）
- `ちなみに`（話題を一つ足すときの接続）
- `もちろんです`（不安・確認への即答）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らがもう徹底的にサポート`）、改まると 弊社 / 私（`私がこの事業部では一番古株`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- スタンス: 顧客の理解度・指摘を`さすがです`『おっしゃる通り』とこまめに肯定してから補足する。売り込みより「一緒に確認していく」寄り添い型。

## メール反映の定型

- `〇〇させていただければと思います`（案内・依頼の着地）
- `〇〇できればと思います`（提案・お願いの着地。1通で2回以上は続けない）
- `〜という形です` / `〜なイメージです`（説明の締め）
- `もちろんです`（不安の受け止め）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`〜かと思います`の形で複数回）→ 1通あたり0〜1回までOK。着地を曖昧にしない範囲で使う
- `かなと`: あり（`検討しやすいかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`の形で多用）→ 冒頭の温度感・軽い提案で少量。依頼文の着地には使わない
- `見ていただけると`: 単独での明確な出現は確認できず → 使わない。資料案内は「ご覧いただけますと」で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `90%以上継続` `どなたでもうまくいきやすい` `確実に収益化` と語る場面があるが、メールでは `〜という方が多いです` 程度に留め、保証表現にしない）
- 審査・回収・成果の断定（`必ず回収できます` などにしない）
- 過度な美文
- 顧客感情の断定
