# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（最頻出。相槌・受け止め・話題転換で多用）
- `かしこまりました`（受け止めの丁寧版）
- `〜かと思うので` / `〜かと思います`（実発話に複数回あり。`お話ししにくいかと思うので`、`失礼かと思うので`、`ご心配な生活とか続いてるかと思いますけど`、`わかりやすいかと思うので`）
- `〜させていただきます` / `お伝えできればと思います`（依頼・案内の定番）
- `〜というイメージですか` / `〜なイメージですね`（確認・着地の言い回し）
- `ご安心ください`（不安の受け止め。`外部に公開すること一切ございませんのでご安心ください`）
- `遠慮なく`（`追加のご質問があれば遠慮なく聞いてください`）
- `〜していきたいと思います`
- `全然大丈夫です` / `焦っていただかなくて全然大丈夫です`（即決を迫らない姿勢）
- 自己開示が厚い（自分の失敗・借金・独立・物販で立て直した経験を語り、共感に接続する）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのような個人`、`僕らはアメリカで唯一`）、改まると 弊社 / 私（`私としては`、`私が明日`）
- 顧客への呼び方: `〇〇さん`（商談中はさん付け）

## メール反映の定型

- `承知いたしました`（受け止め。ただしメールでは多用しない）
- `〜かと思います`（やわらかい提案の着地。1通0〜1回）
- `お伝えできればと思います` / `お送りさせていただきます`（案内）
- `〜というイメージで持っていただければと思います`（説明の締め）
- `焦らず、納得いく形で選んでいただければと思います`（即決を迫らない安心導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思うので` ほか複数）→ 1通あたり0〜1回までOK
- `かなと`: 単独での明確な出現は弱い → 無理に使わず、着地形に寄せる
- `できればと`: あり（`お伝えできればと思います`）→ 1通あたり0〜1回までOK
- `見ていただけると`: 出現なし → 使わない。ネクストアクションは「ご覧いただけますと助かります」で着地させる

## 禁止候補

- `必ずお力になると思います`（商談では発話あり。ただし成果保証に近いためメールでは使わない）
- `伝わってまいりました`（栗原さんの発話に確認なし。`伝わってきて`は1回あるが、営業所感は重ねない）
- 成果保証・収益保証・審査通過保証の断定
- 顧客の不安・感情の断定
- 過度な美文
