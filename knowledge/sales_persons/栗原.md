# 栗原 哲也さん

## 商談内で見えた特徴

- 相槌が非常に温かい。`そっか。そっか。`、`はいはい`、`よかった。よかった。` を多用し、顧客の話をしっかり受け止める
- `〜と思います` / `〜かなと思います` / `〜かと思います`（説明の着地でよく使う）
- `〜していただければと思います`（依頼・案内の定番）
- `〜させていただきます` / `ご案内させていただきます`（手続き案内で丁寧に）
- `一緒に頑張りましょう` / `一緒にね、あのやっていければと思います`（伴走の姿勢）
- `安心してください` / `安心して`（不安をほどくとき）
- `遠慮なくご連絡いただければと思います`（相談導線）
- 顧客の仕事や状況への共感を言葉にする（`本当に頭が下がりますね`、`すごいタフですね`、`私もすごく嬉しいです`、`私はすごいわくわくしてます`）
- `末長くよろしくお願いいたします`（締めの言い回し）

## 一人称・距離感

- 一人称: 私 / 僕ら / 弊社（`私もすごく嬉しい`、`僕らのシステム`、`弊社の方から`）
- 顧客への呼び方: `〇〇さん`（商談中はさん付け。メールでは `〇〇さま`）

## メール反映の定型

- `〇〇かなと思います` / `〇〇かと思います`（説明・提案の着地）
- `〇〇していただければと思います`（依頼・案内）
- `一緒に進めていければと思います`（伴走）
- `安心してお進めいただけます`（サポートの安心導線）
- `ご不明点があれば遠慮なくご連絡いただければと思います`（相談導線）
- 締め: `引き続きよろしくお願いいたします` / `末長くよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`大丈夫かなと思って`、`候補なのかなと`、`よかったかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`いい流れもいいかと思います`、`あるかと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`最後ご調整できればと思う`、`ご参加できれば`）→ 発話準拠で少量ならOK
- `見ていただけると`: 単独での明確な出現は確認できず（`見ていただければと`、`ご覧いただけますと` は出現）→ `見ていただけると` は使わず、`ご覧いただけますと` / `見ていただければと` で着地

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗はしないと思う`、`皆さん結果出るんですよ`、`月70〜80万狙える` と語る場面があるが、いずれも平均・傾向・本人の期待。メールでは保証表現にせず、`〜という方が多いです` / 平均シミュレーションである旨に留める）
- 過度な美文
- 顧客感情の断定
