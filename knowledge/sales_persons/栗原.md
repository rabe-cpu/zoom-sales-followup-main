# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（口癖。前置き・確認の切り出しで非常に多用。`一応前回のお話ですと`、`一応弊社では`、`一応過去の平均ベースですが`）
- `で、`（段落・話題転換のつなぎで頻出）
- `まあ`（やわらげ・言い添え）
- `なんか`（質問をやわらかく切り出すとき。`なんかご不明点などは出てきましたでしょうか`、`なんかご予算とか収益性加味して`）
- `じゃあ`（次の話題・次アクションへ進むとき）
- `ちなみに`（話題を足すとき。`ちなみに、前回のお話ですと`）
- `承知いたしました` / `かしこまりました`（顧客の返答を受けての相槌。非常に頻出）
- `ありがとうございます`（相槌・お礼として頻出）
- `〜させていただいて` / `〜させていただきます`（依頼・行為の丁寧化で多用）
- `ご安心ください`（不安をほどくとき。`今後サポートの担当からもしっかりお伝えできるのでご安心ください`）
- 確認を挟む: `あってますかね？`、`大丈夫そうですかね？`、`なんとなく伝わりましたか？`
- 本音を引き出す: `なんかぶっちゃけたところどこと迷ってる感じなんですか？`

## 一人称・距離感

- 一人称: 弊社 / 僕ら（`僕らの強み`、`僕らも実は役員とかで`）、改まると 私（`私の方で`、`私の方からお電話差し上げましょうか`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。会社主語のときは `御社`）
- ときどき砕けた `〜っすよね`（`そうっすよね`）も出るが、メールでは使わない

## メール反映の定型

- `一応〇〇でして`（前置き・状況説明の切り出し）
- `〇〇させていただければと思います`（依頼・提案の着地）
- `〇〇いただけますと`／`〇〇いただければと思います`（ネクストアクションの着地）
- `このあたりは今後サポートからもお伝えできますのでご安心ください`（不安への受け止め）
- `承知いたしました`（受け止めの相槌。本文では多用しない）
- 締め: `よろしくお願いいたします` / `失礼いたします`

## 余白表現の出現

- `かなと`: あり（`現状結構聞けましたかなと`、`会社に残ってくる営業利益になってくるかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`だったかと思ですが`、`うまくいってない時になるかと`）→ 1通あたり0〜1回までOK。依頼文の着地を曖昧にしない範囲で
- `できればと`: 単独での明確な出現は確認できず → ネクストアクションは「いただけますと」「いただければと思います」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では継続率95%・年間営業利益8,000,000〜9,000,000円などを語るが、いずれも「過去の平均ベース」として説明している。メールでは保証表現にせず、「過去の平均では」「〜という方が多いです」程度に留める）
- 過度な美文
- 顧客感情の断定
