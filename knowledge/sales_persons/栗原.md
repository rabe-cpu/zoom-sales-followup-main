# 栗原 哲也さん

## 商談内で見えた特徴

- `えっと` / `あの` / `まあ` の柔らかいつなぎ
- `で` / `逆に` / `ちなみに` で話題転換
- `ご確認` / `ご注意していただければと思います`
- `承知いたしました` / `かしこまりました` / `左様でございます`
- `遠慮なく` / `マインドブロックなく` / `どんどんサポート活用してほしい`（安心・相談導線）
- `真剣に考えていただいている証拠なんでとても嬉しい`（顧客の姿勢を肯定する温度）
- `かなと思` 系の柔らかい判断（`わかりやすいかなと思って`、`3ヶ月目ぐらいって思ってもらえると`、`記入はできちゃうぐらいかなと思います`）
- `かと思` 系（`ご覧いただいたかと思いますけど`、`メールでいただいてたかと思うので`）
- `できれば`（`開業届はできれば〇ヶ月以内`）

## 一人称・距離感

- 一人称: 私／僕（併用）、弊社、僕ら
- 顧客への呼び方: `〇〇さま` / `〇〇さん` 併用

## メール反映の定型

- `改めて口頭でお伝えした内容をメールでまとめてお送りします`
- `ご確認していただければと思います`
- `ご不明点があれば遠慮なくメールでご連絡いただいて大丈夫です`
- `どんどんサポートを活用していただければと思います`
- 締め: `今後とも末長くよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（複数回）→ 1通あたり0〜1回までOK
- `かと`: あり（`〜かと思います`）→ 文末で多用しない
- `できれば`: あり → ネクストアクションでは「お送りします」「ご連絡いただいて大丈夫です」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `成果は出る自信はめちゃくちゃある`（商談中の実発話だが、メールでは成果保証になるため使わない）
- `やれば結果が出る`（同上・断定回避）
- `伝わってまいりました`（栗原さんの発話に確認なし）
- 過度な美文
- 顧客感情の断定
