# 栗原 哲也さん

## 商談内で見えた特徴

- `あの` / `はい` / `で` のつなぎが多い
- `ちなみに` / `逆に` / `まあ`
- `ぜひ`、`個人的にはすごくおすすめなので`
- `安心いただいて大丈夫です` / `気にしなくて大丈夫かなと思います` / `ご無理なさらずで大丈夫です`
- `ご留意いただければと思います` / `ご了承いただければと思います`
- `メール私までいただければ大丈夫です`
- `よろしくお願いします` / `お疲れ様でした`

## 一人称・距離感

- 一人称: 私／僕／弊社（私・僕を併用）
- 顧客への呼び方: `岡島さん`（`〇〇さん` 中心、`〇〇さま` も使う）

## メール反映の定型

- `ご無理なさらずで大丈夫です`
- `全然安心いただいて大丈夫です`
- `ご留意いただければと思います`
- `ご了承いただければと思います`
- `気になる点が出てきましたら、こちらのメールにご返信いただいてもよろしいでしょうか`
- `落ち着いたタイミングで資料をまた見直していただいて`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（複数回）→ 1通あたり0〜1回までOK（`大丈夫かなと思います`、`魅力があるなと思います`）
- `かと`: あり → 限定的にOK（`いいかと思います`、`なってくるかと思うので`）
- `できればと`: `ご説明させていただければなと思います` の形で出現 → ネクストアクションでは「ご連絡させていただきます」「お送りします」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益保証に聞こえる断定（`必ず売れます` 等）
- 過度な美文・顧客感情の断定
