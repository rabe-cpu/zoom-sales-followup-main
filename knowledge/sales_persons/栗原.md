# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（相槌・受け止めで非常に頻出。顧客の発言を受け止める起点）
- `ありがとうございます`（質問をもらったときのお礼・受け止めで頻出。`あ、ありがとうございます。えっと、`）
- `おっしゃる通りですね` / `さすがです`（顧客の指摘・理解を肯定する）
- `そうですね`（考えながら答える前置き）
- `もちろんです` / `全然〜`（不安をほどく肯定。`全然狙っていけるんですよ`）
- `率直にお伝えすると`（本音を聞かれたときの切り出し）
- `わかりやすく言うと`（かみ砕くときの接続。`魚を釣って与えるんじゃなくて、釣り方を教えている`のような比喩を使う）
- `〜という形となりまして` / `〜という形で`（手続き・段取りの説明の着地）
- `〜していければと思います` / `〜していきたいと思います`（次アクションの提案）

## 一人称・距離感

- 一人称: 僕 / 私（`僕は自分でもやってます`、`私もまあ七年間やってきました`、`私がご案内する方`）、会社は 弊社
- 顧客への呼び方: `〇〇さん` / `〇〇様`（商談中はさん付け中心、改まると様）
- 不安対応に厚い: `遠慮なくわからなければわからないって聞いてもらって`、`たくさんサポートを頼って一緒にタグ組みながら進めていければ`

## メール反映の定型

- `承知いたしました`（受け止め）
- `率直にお伝えすると、〇〇です`（本音の見解を求められた場面）
- `わかりやすく言うと〇〇です`（仕組みをかみ砕く）
- `〇〇の方が御社の規模感にはあると思います`（提案の着地。断定でなく見立てとして出す）
- `〜していければと思います`（次アクションの提案）
- 不安導線: `ご不明点があればいつでもご連絡ください`、`遠慮なくご質問ください`
- 締め: `引き続きよろしくお願いいたします` / `よろしくお願いします`

## 余白表現の出現

- `かなと`: あり（`妥当な判断かなとは思いますね`、`問題ないのかなと`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「いただけますと幸いです」「ご連絡いただければと思います」で着地させる
- `見ていただけると`: 出現なし → 使わない（`ご覧いただけましたかね`、`目を通していただけますと幸いです`の形はあり）

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `全然狙っていけるんですよ`、`売上出てないという方は聞いたことない` と語る場面があるが、メールでは `〜という方が多いです`、`〜を目指していけます` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
