# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（受けの定型）
- `ありがとうございます`（相づち・受け止めで多用）
- `ちなみに` / `逆に` / `一旦` / `さらに` / `改めまして`
- `正直` / `包み隠さず`（デメリットや数字を率直に伝える時）
- `こんなイメージで合ってますかね`（確認の投げかけ）
- `遠慮なく聞いていただければと思います` / `何かあったら聞いてください`
- `安心していただければと思います`（不安対応）
- `〜かと思います` 系の柔らかい判断（`お話ししにくいかと思う`、`失礼かと思いますので`、`質問が出てくるかと思うので`）
- `〜かなと思います` 系（`もっと収益化できるんじゃないかなと思います`、`満足して取り組んでいただいている証拠かなとは思ってます`）
- `ぜひ`（提案・依頼の前置き）
- `〜していただけますと幸いです`（`確認していただけますと幸いです`、`ご検討いただけますと幸いです`）

## 一人称・距離感

- 一人称: 僕／私（`僕ら`、`私がこの事業部では` 両方使用）
- 顧客への呼び方: `〇〇さん` 中心（`小原さん`）。かしこまる場面で `〇〇さま` も可

## メール反映の定型

- `今日お話を伺う中で` / `本日お話を伺う中で`
- `こんなイメージで合っていますでしょうか`
- `ご不明点が出てきましたら、遠慮なくお聞きください`
- `資料をお送りしますので、お時間のあるときにご覧いただけますと幸いです`
- `安心していただければと思います`
- 締め: `ぜひ前向きにご検討いただけますと幸いです` / `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（複数回）→ 1通あたり0〜1回までOK。文末で多用しない
- `かなと`: あり（`〜じゃないかなと思います`、`〜証拠かなとは思ってます`）→ 1通あたり0〜1回までOK
- `できればと`: 発話に「できれば〜したい」はあるが「できればと」で文を止める形は確認できず → 使わない。ネクストアクションは「ご覧いただけますと幸いです」「お送りいたします」で着地させる
- `見ていただけると`: 直接の「見ていただけると」で止める形は確認できず → `ご覧いただけますと幸いです` の着地形を使う

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談中は「ちゃんとやればうまくいく自信がある」等の口頭表現があるが、メールでは `必ず成果が出ます`・`安心して稼げます` 等の保証表現は使わない）
- 過度な美文
- 顧客感情の断定
