# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かと思います` / `〜かと思うので`（口癖。頻出。「進めにくいかと思うので」「失礼かと思いますので」「手元に残しておいた方が安心かと思うので」「大変かと思いますけど」）
- `一応`（前置きで多用。「一応弊社」「一応これが過去の平均です」「一応月曜日は夕方空いてる」）
- `承知いたしました` / `かしこまりました`（受け止めの定番）
- `お間違いないですか`（確認表現）
- `〜させていただければと思います` / `〜させていただく`（依頼・案内の柔らかい着地。非常に頻出）
- `〜という形になります` / `〜という形です`（説明の締め）
- `〜という感じですね` / `こんなイメージです`（説明の着地）
- `個人的には`（おすすめを伝えるときの前置き。「個人的にはこの二つ」「個人的にはめちゃくちゃおすすめ」）
- `逆に`（「逆に言うと」）
- `ちなみに`（話題の切り出し）
- `もちろん`（相手の選択を尊重するときの前置き）
- `おっしゃる通りです`（同意）
- `そうですよね` / `確かに` / `大事ですよね`（共感の相槌。頻繁）
- `ぜひですね` / `ぜひぜひ`（後押しの前置き）
- `〜んですよ`（仕組みを噛み砕くときの語り口）
- `ありがとうございます`（お礼・相槌として頻出）

## 一人称・距離感

- 一人称: 僕 / 僕ら（「僕らのシステム」「僕ら五年間」「僕の方で」）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん` / `〇〇さま`（商談中は基本さん付け、改まると さま）
- 温度感: 相手を立てながら共感を挟み、押しつけずに「合うかどうか一緒に整理する」姿勢

## メール反映の定型

- `〜かと思います`（やわらかい推量の着地。1通あたり0〜1回まで）
- `一応、〇〇という形になります`（事実説明の前置き＋着地）
- `個人的には〇〇がよいかと思います`（おすすめの伝え方。断定を避ける）
- `承知いたしました` / `かしこまりました`（受け止め）
- `〇〇させていただければと思います`（案内・依頼の柔らかい着地）
- `こんなイメージです` / `〜という形です`（説明の締め）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（多数。「安心かと思うので」「大変かと思いますけど」）→ 1通あたり0〜1回までOK。依頼文の着地を曖昧にしない範囲で使う
- `かなと`: 明確な単独出現は確認できず → 積極的には使わない
- `できればと`: 出現なし → ネクストアクションは「ご返信いただけますと助かります」「ご確認いただけますでしょうか」で着地させる
- `見ていただけると`: 単独では未確認だが `見ていただければと思います` は頻出 → 着地形として使ってよい

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では「再現性が高い」「95%以上が未経験」「継続率90%以上」等の実績語りはあるが、収益・成果の保証表現にはしない。メールでは「〜という方が多いです」「平均のデータでは〜」程度に留める）
- 審査・分割が「必ず通る／必ず続く」といった断定（商談でも「なくなる可能性もある」と条件付きで話している）
- 過度な美文
- 顧客感情の断定
