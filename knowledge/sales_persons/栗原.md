# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（相づち・受けで多用）
- `あの` / `えー` / `ええ` / `ちょっと` / `まあ` / `一応`（やわらかいフィラー）
- `〜かと思うので` / `〜かと思います`
- `〜かなと思います` / `〜じゃないかなと思います`
- `〜お伝えできればと思います` / `〜ご案内していきたいと思います` / `〜してまいりたいと思います`
- `〜いただければと思います`
- `いいご質問ありがとうございます`
- `いかがですか？`（次アクションの打診）
- 自分が現役プレイヤーである点を根拠に語る（`私自身も無在庫物販やってるプレイヤーでもあるので`）

## 一人称・距離感

- 一人称: 私／僕ら／弊社
- 顧客への呼び方: `〇〇さん` / `御社`（法人相手では `御社` を多用）
- 距離感: 丁寧でフラット。経営者相手でも対等に相談に乗る姿勢

## メール反映の定型

- `この後メールで諸々お送りさせていただきますので、ご確認お願いいたします`
- `〜の資料をお送りさせていただきます`
- `〜のあたりは、御社が…に応じてご案内していきたいと思います`
- `また資料を見直して追加のご質問が出てくるかもしれないので`
- `一つのご判断材料にしていただければと思います`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`〜かと思うので`、`今日の今日じゃないかと思いますが`）→ 1通あたり0〜1回までOK。文末で多用しない
- `かなと`: あり（`合うんじゃないかなと思います`、`上振れで想定していただけるんじゃないかな`）→ 0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`、`ご案内できればと思います`）→ ネクストアクションでは「お送りいたします」「ご案内します」で着地させる
- `見ていただけると`: 近い表現（`ご覧いただければ`）あり → 依頼の着地形で使う

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証に聞こえる断定（`必ず儲かります` 等）。本人も商談で「100%成功するビジネスはない」「未達の方もいる」と慎重に話している
- 過度な美文
- 顧客感情の断定
