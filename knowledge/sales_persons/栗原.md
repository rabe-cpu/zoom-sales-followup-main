# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（最頻出。相手の話を受け止めてから次へ進むときの定番。相槌・確認の締め）
- `かしこまりました`（依頼・日程確認を受けたときの締め。複数回）
- `ちなみに`（話題を一つ足すときの接続。`ちなみに今回弊社はどういう経緯で`、`ちなみに今の会社`）
- `一旦`（`じゃあ一旦ね、この質疑応答は以上で`）
- `逆に`（`逆に一日一時間じゃなくて`、`逆に二週間だったら行けますか`）
- `さすが` / `さすがですね`（顧客の知識・鋭い質問を受け止める相槌）
- `なるほど`（受け止め）
- `〜させていただければなと思います` / `〜できればなと思います`（提案・お願いの柔らかい着地）
- `ぜひ`（`ぜひね、今日は`、`ぜひあの聞いてください`）
- `ありがとうございます`（お礼・相槌として頻出）
- `〜という形`（締めの言い回し。`追加で契約を増やしていくっていう形`）
- `もちろんです` / `全然大丈夫です`（不安・要望をほどくときの受け）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕がすごく大事にしている`、`僕らみたいな会社`、`僕らとしては推奨している`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。文字起こし上は「コウ／ホウ／甲」等の揺れがあるが、正しくは康さん）
- 自分の立場を先に開示してから相手に質問する進め方（自己紹介→ヒアリング）

## メール反映の定型

- `承知いたしました`（本文では多用しない。受け止めの温度感として1回程度）
- `〜させていただければなと思います` / `〜できればなと思います`（提案・お願いの柔らかい着地）
- `ちなみに` / `一旦`（段落間の自然な接続として少量）
- `ぜひ〇〇いただけますと`（前向きな案内）
- 締め: `よろしくお願いいたします` / `何卒よろしくお願いします`

## 余白表現の出現

- `かと`: あり（`お話進めにくいかと思いますので`、`聞いてしまうのは少し失礼かと思いますので`）→ 1通あたり0〜1回までOK
- `かなと`: 栗原さんの発話に明確な出現は確認できず → 使わない
- `できればと`: あり（`お役に立てるお話ができればと思います`、`一緒に整理できればなと思います`）→ 1通あたり0〜1回までOK
- `見ていただけると`: 出現なし → 使わない。ネクストアクションは「ご覧いただけますと助かります」「ご返信いただけますでしょうか」で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `誰でも上げやすい` `再現性が高い` `全然問題ないです` と語る場面があるが、メールでは `〜という方が多いです` `〜しやすいです` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
