# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（非常に頻出。相槌・受け止めの定番）
- `かしこまりました`
- `端的に言うと` / `シンプルに言うと`
- `正直言うと` / `正直`
- `逆に` / `ちなみに`
- `〜かと思います` / `〜かと思うので`（実発話に複数回あり）
- `〜という形`（「お申し込みで、で次回契約日っていう形」など）
- `〜していきたいと思います`（案内・提案の締め）
- `ぜひ` / `もちろんです`
- `まあ` / `あの` / `ですね`（口語のつなぎ。多用しすぎない）

## 一人称・距離感

- 一人称: 僕／僕ら（自分の物販経験を語る場面）、弊社（会社としての説明）
- 顧客への呼び方: `〇〇さん` / `〇〇さま` 併用。本文では `廣田さま` に統一する

## メール反映の定型

- `本日はお時間をいただきありがとうございました`
- `承知いたしました` を受け止めに使う
- `ぜひ〜していきたいと思います`
- `しっかりとご紹介していきたいと思います`
- `〜をお送りさせていただきます`
- `また何か気になる点があればお気軽にご連絡ください` 系の相談導線

## 余白表現の出現

- `かと`: あり（「お話進めにくいかと思うので」「失礼かと思うので」「お伝えできるかと思いますので」など複数回）→ 1通あたり0〜1回までOK。文末で連発しない
- `かなと`: 直接の確認は限定的 → 無理に足さない
- `できればと`: 明確な出現は確認できず → ネクストアクションは「〜と思います」「お送りいたします」で着地させる
- `見ていただけると`: 直接出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- `必ず利益が出ます` / `誰でも稼げます` などの成果保証（本人も「多くの方が」「平均で」と幅を持たせて話しており、断定はしていない）
- 過度な美文
- 顧客感情の断定
