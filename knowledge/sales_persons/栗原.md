# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（受けの定番。質問や要望を受けた直後に多用）
- `ありがとうございます`（相槌・お礼として頻出）
- `端的に言うと` / `分かりやすく言うと`（要点をかみ砕く切り出し）
- `具体的にお伝えさせていただくと`（説明を一段深くするときの接続）
- `逆に言うと`（視点を反転させる接続）
- `〜という形になります` / `〜という形ですね`（締めの言い回し）
- `〜させていただきます` / `〜させていただく`（依頼・案内の基本形。やや丁寧め）
- `〜いただければと思います` / `〜いただければ幸いです`（依頼の着地）
- `ご安心ください` / `安心いただいて大丈夫かと思います`（不安をほどく定番）
- `ぶっちゃけ`（カジュアルに本音を出すとき。メールでは使わない）

## 一人称・距離感

- 一人称: 僕ら / 弊社（`僕らのシステム`、`弊社では`）、改まると 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `端的に言うと、〇〇です`（要点を先に出す）
- `具体的にお伝えさせていただくと、〇〇という形になります`
- `〇〇いただければと思います`（依頼の着地）
- `ご安心ください` / `安心いただいて大丈夫かと思います`（不安への受け止め。ただし成果保証にはしない）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`〜かと思います`、`分かりやすいかと思うので`、`失礼かと思います`）→ `〜かと思います` の形でメール可。1通あたり0〜1回まで
- `かなと`: あり（`多いんじゃないかなと思いますね`、`向いているビジネスモデルですね`）→ `〜かなと思います` の形で1通あたり0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`、`お伺いできればなと`）→ `〜できればと思います` の形で使用可。依頼文の着地を曖昧にしない範囲で
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では実績や返金保証を語るが、`絶対稼げる` `必ず成果が出る` とは言わない。メールでは `〜という方が多いです`、`平均で〜前後` 程度に留め、保証表現にしない）
- `ぶっちゃけ` などの口語はメールに持ち込まない
- 過度に冗長な `〜させていただいて、〜させていただく` の連結（メールでは1文1動作に整理する）
- 顧客感情の断定
