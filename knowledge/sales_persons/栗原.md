# 栗原 哲也さん

## 商談内で見えた特徴

- `改めて` / `じゃあ` / `では`
- `ちなみに` / `逆に` / `ただ`
- `承知いたしました` / `かしこまりました`
- `おっしゃる通りです`
- `ご安心ください` / `安心いただいて大丈夫です`
- `〜かと思います` 系の柔らかい判断（`失礼かと思うので`、`進みにくいかと思うので`、`よかったかと思いますが`）
- `〜できればと思います`（`ご紹介できればと思うので`、`お伝えできればと思います`、`お話できればと思います`）
- `そうですよね` で受け止めてから論点を戻す
- `改めてよろしくお願いいたします`

## 一人称・距離感

- 一人称: 私（`私の自己紹介`、`私自身も`）／僕ら・弊社（`僕らのいいところ`、`弊社の場合`）を併用
- 顧客への呼び方: `〇〇さん`（商談中は基本これ）。メールでは `〇〇さま` に寄せる

## メール反映の定型

- `しっかりとご紹介できればと思います`
- `〜をお伺いできればと思います`
- `こちらのメールにご返信いただいてもよろしいでしょうか`
- `またタイミング等ございましたらいつでもご連絡ください`
- 受け止め: `そうですよね` → 論点整理 → 次の確認、の順
- 締め: `本日は貴重なお時間をいただきありがとうございました。引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`かと思います` を多用）→ メールでは1通あたり0〜1回までに抑える。文末の `〜かと。` 単独止めはしない
- `できればと`: あり（`〜できればと思います`）→ ネクストアクションでは「お送りします」「お伺いします」で着地させる
- `かなと`: 直接出現は確認できず → 使わない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- `必ず成果が出ます` / `簡単に取れます` のような断定（商談中に勢いで出やすいので、メールでは使わない）
- 顧客感情の断定
- 過度な美文
