# 栗原 哲也さん

## 商談内で見えた特徴

- `僕ら`（自社・チームを指すときの口癖。`僕らは販売戦略があって`、`僕らだけが`、`僕らのような個人`と多用）
- `一応`（説明の切り出し・補足でよく使う。`一応先ほどいただいたご質問と`、`一応平均で`）
- `要は`（かみ砕いて言い換えるときの接続）
- `なので`（因果でつなぐときの定番）
- `ちょっと`（前置きのやわらげ。`ちょっと具体的に`、`ちょっとお待ちくださいね`）
- `じゃあ`（話題転換の切り出し）
- `承知いたしました` / `かしこまりました`（受け止め・相槌として非常に頻出）
- `〜いただければと思います`（依頼・案内の締めの定番）
- `〜させていただきます` / `〜させていただきました`（行動の丁寧提示）
- `安心してください` / `ご安心いただければ`（不安をほどくとき）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕の方で`、`僕らのシステム`）、改まると 弊社 / 私
- 顧客への呼び方: `寺田さん`（商談中は基本さん付けで、名前を頻繁に呼びかける）
- 相手の熱意・行動力をまっすぐ肯定する温度が高い（`叶えましょうよ`、`決断力と行動力がすごくある方`、`すごいですね`）

## メール反映の定型

- `一応〇〇なので、〇〇いただければと思います`（案内の着地）
- `なので、〇〇という形になります`（仕組みの説明）
- `要は〇〇です`（かみ砕きの言い換え）
- `ご安心いただければと思います`（不安への受け止め。押しつけない）
- `まずは〇〇を進めていければと思います`（次アクションの提示）
- 締め: `よろしくお願いします` / `ありがとうございます`
- 体調気遣い: `お体を崩されないように`（商談末尾で暑さ・多忙をねぎらう場面あり）

## 余白表現の出現

- `かなと`: あり（`把握いただけるかなと思います`、`〇〇な感じかなと`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「いただけますと助かります」「ご確認いただければと思います」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってきますね` / `伝わってまいりました`（商談では熱意を受けて `伝わってきますね` と言う場面があるが、メールでは美文・AI臭になりやすいので使わない。受け止めは `お話を伺っていて〜と感じました` 程度に留める）
- 成果保証・断定（`叶うと思いますよ`、`通りやすいと思います` と背中を押す場面があるが、メールでは `〜という方が多いです`、`〜しやすいです` 程度に留め、収益・審査の保証表現にしない）
- 過度な美文・持ち上げの連発
- 顧客感情の断定
