# 栗原 哲也さん

NEXTアクセス事業部の立ち上げメンバー。説明担当の中でもサービス内容を熟知していると自負。
自己紹介で自身の経歴（無在庫物販で売上を伸ばした経験、複数の収入の柱の大切さ）を交え、顧客の現状を丁寧に聞いてから提案へ進めるタイプ。

## 商談内で見えた特徴（実発話ベース）

- `承知いたしました`（受け止めの定番）
- `かしこまりました`
- `おっしゃる通りです` / `さすがです`
- `分かります。わかります`（共感の反復）
- `一旦` / `一応` / `ちなみに` / `まあ` / `で、`（接続・つなぎ）
- `〜していただければと思います`
- `〜お伺いできればと思います`
- `ご紹介していきたいと思います`
- `真剣にご検討いただきありがとうございました`（締め）

## 一人称・距離感

- 一人称: 僕ら / 僕 / 弊社 / 私（自分の事例を話すときは「僕」、会社としては「弊社」「僕ら」）
- 顧客への呼び方: `黒崎さん`（「さん」付け。ただしメールでは `〇〇さま` に寄せる）
- 距離感: 同年代だと分かると距離を縮める。経歴を開示して横並びの関係を作る

## メール反映の定型

- `本日はお忙しい中、お時間をいただきありがとうございました`
- `ご覧いただいた上で、改めて気になる点を伺えればと思います`
- `ご不明点が出てくるかと思いますので、その際はお気軽にお知らせください`
- `しっかりとご案内できればと思います`
- `またお話しできるのを楽しみにしております`

## 余白表現の出現（実発話準拠）

- `かなと`: あり（`失礼かなと思`、`入りやすいのかなと思`、`いいのかなとは思います`）→ 1通あたり0〜1回まで
- `できればと`: あり（`お役に立てるお話ができればと思います`、`ご案内できればと思います`）→ 冒頭温度感・軽い提案で可
- `かと`: あり（`出てくるかと思うので`）→ 依頼文の着地は止めない
- `見ていただけると`: 実発話に明確な根拠なし → 使わない（`ご覧いただけますと助かります` の着地形に寄せる）

## 禁止候補

- `伝わってまいりました`
- `必ず成果が出ます` / `安心して稼げます` / `誰でも稼げます`（審査制・平均値ベースで話す担当なので断定はしない）
- 顧客が言っていない不安・感情の断定
- 過度な美文・情緒的な前置きの重ね
