# 栗原さん（栗原 哲也）

## 商談内で見えた特徴（実発話ベース）

- `承知いたしました`（相槌・受け止めで多用）
- `かしこまりました`
- `〜という形で大丈夫ですか？`（合意確認）
- `〜という形です`（説明の締め）
- `ちなみに`（話題転換）
- `逆に`（視点の切り替え）
- `実は`（背景説明の導入）
- `要するに` / `だから`（要点整理）
- `ぜひ聞いてください` / `遠慮なくご連絡ください`（相談導線）
- `よかったよかった` / `素晴らしい` / `確かに確かに`（肯定的な相槌）

## 一人称・距離感

- 一人称: `僕` / `僕ら` / `私` / `弊社`（自社は「僕ら」「弊社」を併用）
- 顧客への呼び方: `〇〇さん`（商談中は「さん」付け。メールでは `〇〇さま` に統一）
- 顧客の経験・強みを具体的に肯定する（「その経験を生かして」「好きに勝てない」など）

## メール反映の定型

- `〜という形でお送りします`
- `ぜひ〜ご確認ください`
- `ご質問が出てきましたら、遠慮なくご連絡ください`
- `わかんなくなったらぜひ聞いてください` → メールでは `気になる点が出てきましたら、遠慮なくご連絡ください` に整える
- `精一杯対応させていただきますので`

## 余白表現の出現

- `かと`: あり（「進めにくいかと思うので」「失礼かと思いますので」「出てくるかと思うので」）→ 1通あたり0〜1回まで
- `かなと`: あり（「わかりやすいかなと思います」「おすすめかなと思います」「合うんじゃないかなと思いますね」）→ 1通あたり0〜1回まで
- `できればと` / `いただければと`: あり（「お役に立てるお話ができればと思います」「ご判断いただけるように」）→ 依頼文の着地では止めず、`〜いただけますと助かります` へ寄せる
- `見ていただけると`: 明確な発話なし → 使わない

## 禁止候補

- `伝わってまいりました`
- 成果保証・断定（商談では「成果を出せる自信はある」等の口頭表現があるが、メールでは保証表現にしない）
- 期限特典を強く迫る言い方（商談終盤で「今決めた方が」というやり取りがあったが、メールでは押しつけにしない）
- 顧客が言っていない不安・感情の断定
