# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かなと思います` / `〜かなと思うので` / `〜かなという風に思っております`（着地の口癖。頻出）
- `〜かと思います` / `〜かと思ですけど`（受け止め・推測の着地）
- `〜という形になります` / `〜という形ですね` / `〜というような形`（説明の締め）
- `一応`（前置き。`一応平均の`、`一応このミニマムプランの場合は`）
- `まあ`（クッション。多用）
- `ちょっと`（柔らげ。`ちょっとお待ちください`、`ちょっと資料に戻って`）
- `正直なところ` / `本当に包み隠さずお伝えすると`（率直さを出す前置き）
- `もちろんです。もちろんです。`（依頼を受けるときに繰り返す）
- `かしこまりました` / `よかったです` / `ちょうどよかったです`
- `〜させていただければと思います` / `〜させていただきます`（丁寧な申し出）

## 一人称・距離感

- 一人称: 弊社 / 僕ら（`僕らのサポート`、`弊社のシステム`）、改まると 私（`私が説明した内容`、`私も今まで何千人と`）
- 顧客への呼び方: `増田さん`（さん付け。商談中は基本さん付けで距離を詰めすぎない）

## メール反映の定型

- `〜かなと思います`（見立て・提案の柔らかい着地。1通0〜1回）
- `〜という形になります`（手順・条件の説明締め）
- `正直なところ〜`（メリットだけでなく実際の作業量・条件も率直に伝える姿勢）
- `無理せず〜でいいと思います`（上位プランへ押し込まず、顧客の制約を尊重する言い回し）
- `もちろんです`（依頼・確認要望への即応）
- 依頼: `おっしゃっていただければと思います` / `メールでご連絡いただければ` / `ご確認いただけますと`
- 締め: `よろしくお願いします` / `今後ともどうぞよろしくお願いします`

## 余白表現の出現

- `かなと`: あり（`ミニマムでいいかなと思います`、`現実に近い形かなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`大きくしたいというお話だったかと思ですけど` など受け止めで使用）→ 1通あたり0〜1回までOK
- `できればと`: 明確な出現なし → ネクストアクションは「ご連絡いただければ」「ご確認いただけますと」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `確実性高く収益データをお伝えできる`、`ミニマムでも500,000狙える方` と語る場面があるが、いずれも「過去の平均データ」「個人的な見立て」として述べている。メールでは `平均で〜が見込めます`、`〜という方が多いです` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
