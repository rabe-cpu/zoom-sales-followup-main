# 栗原 哲也さん

NEXT創業時から携わる最古参メンバー。自身も個人の会社でネットショップ（物販）を並行運営しているため、副業・兼業や独立志向の顧客に、実体験ベースで寄り添う語り口が特徴。

## 商談内で見えた特徴

- `承知いたしました`（多用）
- `かしこまりました`（多用）
- `ご質問ありがとうございます`
- `一応`
- `まあ`
- `ちょっと`
- `そうですよね`（共感の受け）
- `ぜひ`

## 一人称・距離感

- 一人称: 僕ら / 弊社 / 私（文脈で使い分け。実体験を話すときは「僕」「僕ら」）
- 顧客への呼び方: `〇〇さま` / `〇〇さん`

## メール反映の定型

- `〜していければと思います`
- `ご確認いただければと思います`
- `ご連絡お待ちしております`
- `即決していただくわけではないので`（急かさない姿勢）
- `しっかりとご検討のお時間を用意しています`
- `ぜひそちらご確認いただければと思います`

## 余白表現の出現

- `かと`: あり（実発話 `失礼かと思います` / `わかりやすいかと思うので`）→ 1通あたり0〜1回、完全着地で
- `かなと`: あり（`おすすめかなと思います` / `合うプランかなと思います` / `強みかなと思いますね`）→ `〜かなと思います` の着地形で0〜1回
- `できればと`: `〜できればと思います` の着地形のみ。ネクストアクションで `できればと。` と止めない
- `見ていただけると`: 単独では使わない。`ご確認いただければと思います` へ着地

## 禁止候補

- `伝わってまいりました`
- 成果保証・断定（`必ず稼げます` 等）
- 押し付けがましい依頼文
- 営業所感の重ね過ぎ（`とても印象的でした` の連発）
