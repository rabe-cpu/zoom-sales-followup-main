# 栗原 哲也さん

## 商談内で見えた特徴

- `おっしゃる通りです` / `おっしゃる通り`（顧客の理解を肯定する相槌。非常に頻出）
- `大丈夫です` / `大丈夫でございます`（不安をほどく定番）
- `〜という形になります` / `〜という形`（手順・結論の締め）
- `〜みたいな形` / `〜みたいなイメージ` / `そんなイメージです`（説明の着地）
- `かしこまりました` / `承知いたしました`（受け）
- `ぜひ` / `ぜひぜひ`（前向きな後押し）
- `正直`（率直さを出す前置き。`正直、あのご状況すごく理解できます`）
- `ちょっと`（依頼・確認の緩衝）
- `あの` / `えっと`（填充。多め。メールでは落とす）
- `ありがとうございます`（相槌・お礼として頻出）

## 一人称・距離感

- 一人称: 私 / 弊社（`弊社の方で`、`私も創業時に`）
- 顧客への呼び方: `〇〇さん`（商談中はさん付け。メールでは `〇〇さま`）
- 自己開示を交えて距離を縮める（自身も個人会社で無在庫物販、家族旅行のマイル運用など）

## メール反映の定型

- `おっしゃる通りで、〇〇です`（顧客の理解を肯定してから補足）
- `〇〇で大丈夫です`（不安への受け止め）
- `〇〇という形になります`（手順・結論の締め）
- `まずは〇〇だけ押さえていただければ大丈夫です`（複雑な内容を一言に圧縮）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`大丈夫かと思います`）→ 1通あたり0〜1回まで、断定を避ける場面で少量
- `かなと`: 明確な単独出現は確認しづらい → 基本は使わず、`〜かなと思います` は控えめに
- `できればと`: 出現なし → ネクストアクションは「いただければと思います」「ご連絡いただければと思います」で着地
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`必ず成果`、`絶対に稼げる` など。商談では収益シミュレーションを「平均を上限にした悲観的想定」として保守的に見せる姿勢なので、メールでも保証表現にしない。上振れ事例は「目標」として明示分離する）
- 期限だけで急かす表現（割引期限を伝える場合も、着金遅延時の救済＝割引維持調整をセットで添える）
- 過度な美文・顧客感情の断定
