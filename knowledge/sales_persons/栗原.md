# 栗原 哲也さん

## 商談内で見えた特徴（実発話ベース）

- `かしこまりました` / `承知いたしました`（頻出）
- `もちろんです`
- `よかったです` / `ありがとうございます`
- `一応`（`一応、輸入者は弊社が代行します`、`一応内訳はわかるようにしている`）
- `じゃあ` / `えっと` / `ちょっと`
- `〜させていただく`（`お送りさせていただいた`、`ご案内させていただく`、`以上にさせていただき`）
- `おっしゃる通りです`
- `ぜひ`（`次またそういう機会があったら是非`）
- `少々お待ちください` / `ちょっとお待ちください`
- `〜ですね` / `そうですね`

## 一人称・距離感

- 一人称: 弊社／私（`私の社用メールなんで`）
- 顧客への呼び方: `〇〇さん` / `〇〇さま` 併用（商談中は `福本さん`）
- 気遣いの一言を添える（`わざわざお時間取っていただいて`、`事前にすいません`）

## メール反映の定型

- `かしこまりました`
- `ご確認いただければと思います`
- `お送りさせていただきますので`
- `また改めてお打ち合わせできればと思います`
- `次回しっかりお伝えさせていただきます`
- `他に何か確認しておきたいことはありますか`（確認を促す聞き方）

## 余白表現の出現

- `かと`: あり（`っていうような形になるかと思います`、`取り組めるかと思います`）→ 文末で1通0〜1回までOK
- `できればと`: あり → ただし `お打ち合わせできればと思います` のように着地している形で使う。途中で止めない
- `かなと`: 栗原さんの実発話に確認できず → 使わない（商談内の `かなと` は福本さん側の発話）
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益保証・審査保証の断定
- 顧客感情の断定
- 過度な美文
