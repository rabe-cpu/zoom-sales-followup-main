# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（確認の相づちが非常に多い）
- `〜という形になります` / `〜というイメージ`（着地の言い回し）
- `〜していただければと思います`
- `ご安心ください`
- `正直` / `ぶっちゃけ`（数字や見立てを率直に出すときの前置き。例:「正直まだまだ拡大途中かなっていう」「ぶっちゃけたこと言うと」）
- `一応`（前置きの緩衝。「一応この後平均をお伝えする」「一応リスクヘッジとして」）
- `結構`（程度の表現として多用）
- `逆に`
- `かと思うので` 系の判断（実発話に出現。「根掘り葉掘り聞いてしまうのも失礼かと思うので」「お役に立てるお話できるかと」）
- `かなっていう` 系の柔らかい見立て（「拡大途中かなっていう」「最初はいいかもしれないですね」）
- 自分の物販・経営経験を一度はさんで共感を作る（中国輸入の在庫リスク、自身のネットショップ経営）
- `すごいですね` / `素敵だな` など率直な称賛

## 一人称・距離感

- 一人称: 僕／私／弊社（場面で使い分け。状況説明は「弊社」、体験談は「僕」「私」）
- 顧客への呼び方: `〇〇さん` / `〇〇さま` 併用

## メール反映の定型

- `承知いたしました`
- `〜という形になります`
- `ご不明点などございましたら、いつでもご連絡ください`
- `一度見直していただいたうえで`
- `正直なところ〜`（率直な見立てを添えるとき。盛らずに事実ベースで）
- `引き続きよろしくお願いいたします`

## 余白表現の扱い

- `かと` / `かなと`: 実発話にあるため**少量（1通0〜1回）なら可**。依頼文の着地を曖昧にしない範囲で使う。
- `できればと` / `見ていただけると`: 今回の実発話に明確な出現なし。**使わない**（着地形「〜いただけますと助かります」に寄せる）。

## 禁止候補

- 成果保証・断定（「必ず」「確実に」「絶対稼げる」）。本人は返金保証や実績を率直に語るが、断定はしない口調なので、メールでも保証表現にしない。
- `伝わってまいりました` のような過度な美文敬語。
