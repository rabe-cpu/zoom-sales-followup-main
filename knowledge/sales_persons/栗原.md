# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かと思います` / `〜かと`（実発話に複数あり。`見にくいかもしれないので横に倒していただいていると`→`見やすくなるかと`、`いきなり聞くのは失礼かと思うので`、`質問しやすいのかなっていうふうに思いますけれど`、`有意義なお話ができるかと`）
- `承知いたしました` / `かしこまりました`（確認・受け止めの定番。非常に頻出）
- `もちろんです` / `もちろんでございます`（依頼を受けるときの即答）
- `ご安心ください`（不安をほどくときの締め）
- `改めて`（`改めてよろしくお願いいたします`、`改めて前回`）
- `一旦` / `早速`（`一旦ここまでで`、`早速質疑応答に`）
- `〜という形になります` / `〜っていう形`（説明の着地）
- `〜させていただければと思います` / `お伝えできればと思います`（依頼・案内の柔らかい着地）
- `ありがとうございます`（相槌・お礼として頻出）
- `ぜひ` / `しっかりと`（案内の後押し）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕ら個人の人が`、`僕の方で`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま`）

## メール反映の定型

- `改めて、本日は貴重なお時間をいただきありがとうございました`
- `〜かと思います`（見立て・提案の柔らかい着地。1通0〜1回）
- `〜させていただければと思います`（資料案内・次回案内）
- `ご安心ください` / `お気兼ねなくご連絡ください`（安心導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（実発話に複数）→ 1通あたり0〜1回までOK。見立て・提案の着地でだけ使う
- `かなと`: 弱く出現（`〜のかなっていうふうに思います`）→ 使うなら1通0〜1回、着地を曖昧にしない範囲で
- `できればと`: あり（`しっかりとお伝えできればと思いますので`）→ 案内文で0〜1回までOK
- `見ていただけると`: 出現なし → 使わない。ネクストアクションは `ご覧いただけますと助かります` `ご返信いただけますでしょうか` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では返金保証・`8割超が目標通り`・`10年20年続けられる` と語る場面があるが、メールでは `〜という方が多いです` `資料でご確認いただけます` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 税金・住民税・審査に関する断定（`普通徴収にすれば会社に行かない` 等は一般的な進め方として触れる程度に留め、詳細は次回・税理士確認へ促す）
