# 栗原 哲也さん

## 商談内で見えた特徴

- `そうですね`（相槌として頻出）
- `ありがとうございます`（受け止め・感謝を細かく入れる）
- `要は`（言い換え・要約の接続）
- `一旦`
- `引き続き`
- `率直に言うと` / `ぶっちゃけ`（正直に伝える前置き）
- `〜という感じですね` / `〜みたいな`
- `すごく気持ちは分かります`（顧客の迷いに共感してから進める）

## 一人称・距離感

- 一人称: 私・僕（両方を自然に使う）、会社は `弊社`
- 顧客への呼び方: `〇〇さん`（相談会2回目でやや距離が近い。フォーマル文書では `〇〇さま`）
- 押し売りを避け、「納得して進めたい」というスタンスを明言するタイプ

## メール反映の定型

- `〜と思いますね` / `〜かなと思います`
- `〜で見ていただけるといいかと思います`
- `引き続きよろしくお願いします` / `引き続き長い目で`
- `かしこまりました`
- `率直な気持ちをおっしゃっていただいてありがとうございます`

## 余白表現の出現

- `かと`: あり（実発話「200数十万ぐらいで見ていただけるといいかと」）→ 1通あたり0〜1回
- `かなと`: あり（実発話「いう感じで見ていただけるといいかなと」）→ 1通あたり0〜1回
- `できればと`: 発話に無し → 使わない
- `見ていただけると`: あり → 冒頭の温度感や軽い提案で使用可

## 禁止候補

- 成果保証・回収保証に聞こえる断定（`必ず稼げます` など）
- `伝わってまいりました`
- 顧客が言っていない不安・感情の断定
- 依頼文を途中で止める（`〜いただければと。` の言いさし）
