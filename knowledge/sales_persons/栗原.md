# 栗原 哲也さん

## 商談内で見えた特徴

- `じゃあ早速`（話を次に進めるときの切り出し。頻出）
- `一旦`（`じゃあ一旦ここまで`。区切りの接続）
- `逆に`（`逆にうまくいってない人の傾向をお伝えした方が分かりやすい`）
- `ちなみに`（`ちなみに佐藤さん`。話題を差し込むとき）
- `なので`（理由から結論へつなぐ）
- `〜んですよ` / `〜んですね`（仕組み・事例を説明するときの語り口。頻出）
- `〜という形になります` / `〜という感じ`（説明の着地）
- `承知いたしました` / `かしこまりました`（受け止めの丁寧語。両方使う）
- `ご安心いただければと思います`（不安をほどくときの定番）
- `しっかりと`（`しっかりと今日ご紹介していきたい`。丁寧さ・誠実さを出す副詞）
- `ぜひ`（依頼・案内の前に置く）
- `ありがとうございます`（相槌・お礼として非常に頻出）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのうまくいっている理由`、`僕どうするか`）、改まると 私 / 弊社（`私がサービス内容を熟知していて`、`弊社のシステム`）
- 顧客への呼び方: `佐藤さん`（商談中は基本さん付け。時折「御社」も使う）
- 自己開示を交えて距離を縮める（自身の経歴・失敗・独立の話を先に開示してから相手に質問する）

## メール反映の定型

- `じゃあ〜していきますね` / `早速〜`（次アクションへの切り出し）
- `〜という形になります` / `〜という感じです`（説明の締め）
- `ご安心いただければと思います`（不安への受け止め。ただし成果保証にしない）
- `しっかりとお伝えしていきたいと思います`（誠実さを出す）
- `ぜひ〜ご確認いただければと思います`（案内・依頼）
- 締め: `よろしくお願いいたします` / `本日は貴重なお時間をいただきありがとうございました`

## 余白表現の出現

- `かと`: あり（`進めにくいかと思いますので`、`失礼かと思ので`、`わかりやすいかと思うので`）→ 商談で複数回。1通あたり0〜1回までOK
- `かなと`: あり（`メモ取ってくださったかなと思うので`、`週明けかな`）→ 1通あたり0〜1回までOK
- `できればと`: 明確な出現なし → ネクストアクションは「ご確認いただけますと」「ご返信いただけますと」で着地させる
- `見ていただけると`: 明確な出現なし。ただし `今日ご覧いただいた資料も目を通していただきたい` の言い回しはある → `ご覧いただけますと` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では平均値・事例として `月々三四十万ぐらい`、`一年後は月58万ぐらい` と語るが、いずれも「平均」「見ていただければ」と条件付き。メールでは `〜という方が多いです`、`〜と見ていただければと思います` に留め、保証表現にしない）
- `必ず`、`確実に稼げる` のような断定
- 過度な美文
- 顧客感情の断定
