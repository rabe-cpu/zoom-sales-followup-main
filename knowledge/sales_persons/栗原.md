# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました`（相槌・受け止め・締めで最頻出。顧客の話を受けた直後に置く）
- `承知いたしました`（`かしこまりました` と並ぶ受け止めの定番）
- `ありがとうございます`（相槌・お礼として非常に頻出）
- `〜できればと思います` / `〜していければと思います`（提案・案内の着地で多用。`ご紹介できればと思います`、`お伝えできればと思います`、`お話できればと思います`）
- `一応`（説明の前置き。`一応このミニマムプランは`、`一応今日から一週間以内で`）
- `改めて`（`改めて確認していただきながら`、`改めて見てほしい`）
- `ちなみに`（話題の切り出し。`ちなみにどこのサイトで`、`ちなみにどちらですか`）
- `じゃあ` / `じゃあですね`（段落の切り替え）
- `〜んですよ` / `〜んで`（仕組みをかみ砕くときの説明口調）
- `逆に`（`逆に2,000,000円ぐらいで`）
- `おっしゃる通りです` / `さすがです`（顧客の理解への共感・承認）

## 一人称・距離感

- 一人称: 私（`私としては`、`私の方からの`）、弊社（`弊社のシステム`、`弊社の場合は`）
- 顧客への呼び方: `〇〇さま` / 商談中は `〇〇さん`（本メールの宛名は `福本有規さま`）
- 温度感: 丁寧でやわらかく、顧客の状況や決断を素直に肯定する（`素晴らしいと思います`、`すごいですね`）。急かさず、確認・相談の形で進める。

## メール反映の定型

- `〇〇できればと思います`（提案・案内の着地）
- `一応〇〇です`（補足・前置き）
- `改めて〇〇していただきながら`（資料の見直し案内）
- `〇〇かと思います`（やわらかい見立て）
- 受け止め: `かしこまりました` / `承知いたしました`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`見やすいかと思ので`、`失礼かと思うので`、`出てくるかと思うので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`一括の方かなと思ってます`、`安心できるのかなと`、`ありかなと`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`ご紹介できればと思います`、`お伝えできればと思います`、`お伺いできればと思います`）→ 1通あたり0〜1回までOK
- `見ていただけると`: 出現なし（`見ていただきたい` はあるが `見ていただけると` ではない）→ 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `月300,000の利益を作っていける可能性は高い` と語るが、`可能性` の範囲で止めている。メールでも `〜という方が多いです`、`〜の可能性が高いと思います` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
