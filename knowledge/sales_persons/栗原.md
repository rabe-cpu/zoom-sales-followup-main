# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました` / `承知いたしました`（依頼・質問を受けたときの受け止め。頻出）
- `一応`（数字・データ・条件を出す前の前置き。`一応過去の平均で`、`一応今後のスケジュール`）
- `逆に`（視点を切り替えるときの接続。`逆に百万のお金を使って`）
- `もちろんです`（不安・要望を受けたときの即答。`あ、もちろんです`）
- `おっしゃる通りです` / `おっしゃる通りで`（顧客の理解を肯定して進める）
- `要は` / `端的に`（仕組みをかみ砕く・結論を出す接続）
- `〜という形になります` / `〜という形です`（説明の締め）
- `〜かなと思います` / `〜かと思います`（説明・提案の柔らかい着地）
- `ざっくばらんに`（質問を促すときの砕けた言い回し）
- `ありがとうございます`（相槌・お礼として頻出）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らがこのサービスを`、`僕らのシステム`、`僕は中国にも拠点が`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん` / `〇〇様`（商談中は基本さん付け、改まると様）
- 自己開示が厚め（創業時からの最古参、独立失敗からの再起、自社事業も並行）。信頼づくりに実体験を混ぜる

## メール反映の定型

- `かしこまりました。〇〇についてお伝えします`（依頼の受け止め→本題）
- `一応〇〇でお伝えすると`（数字・条件を出す前の前置き）
- `〇〇という形になります`（説明の締め）
- `〜かなと思います`（提案・見立ての柔らかい着地）
- `もちろんです。〇〇できます`（要望への即答）
- 依頼: `ご確認いただけますと幸いです` / `〜いただければと思います` / `おっしゃってください`
- 締め: `よろしくお願いいたします` / `失礼いたします`

## 余白表現の出現

- `かと`: あり（`聞いてしまうのは少し失礼かと思うので`、`回ってくるかと思います`、`判断に近づいてくるかと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`お役に立てる話ができるかなと思います`、`やりやすいかなと思います`、`チャンスはあるんじゃないかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: 単独での明確な出現なし → ネクストアクションは「いただけますと幸いです」「ご返信いただければ」で着地させる
- `見ていただけると`: 明確な出現なし → 使わない。`ご覧いただけますと幸いです` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんは `ご状況が伝わってきました` とは言うが、`まいりました` の美文形は発話になし。使うなら `伝わってきました` の口語まで）
- 成果保証・断定（商談で `収益化がしっかりと確実に出そうか` と語る場面があるが、メールでは `〜という方が多いです`、`〜も十分可能です` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 特典期限を煽るクロージング（`今日から一週間` の特典は事実として触れてよいが、急かす圧にしない）
