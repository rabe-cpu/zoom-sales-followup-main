# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました` / `承知いたしました`（受け止め・区切りで非常に頻出）
- `ありがとうございます`（質問へのお礼・相槌として頻出）
- `端的にお伝えすると` / `端的にお答えすると`（要点を先に出すときの切り出し）
- `〜していければと思います` / `〜お伝えできればと思うので`（案内の着地）
- `〜させていただきます` / `ご案内してまいりたいと思います`
- `しっかりと`（`しっかりとお伝えできれば`、`しっかりと収益を上げていける`）
- `ぜひ`（`ぜひやっていただく価値がある`、`ぜひご確認いただいて`）
- `〜みたいなイメージ` / `そんなイメージですね`（説明の締め）
- `〜っていうふうに`（説明のつなぎ）
- 相談スタンス（`今日判断してくださいってわけじゃない`、`しっかり一週間考えてほしい`）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らの売り方`、`僕らは`）、改まると 私 / 弊社
- 顧客への呼び方: `渡邉さん`（商談中は基本さん付け）。メール宛名は `渡邉英雄さま`

## メール反映の定型

- `端的にお伝えすると、〇〇です`（要点を先に出す）
- `〇〇をしっかりとご案内できればと思います`
- `〜みたいなイメージです`（説明の締め）
- `今日すぐご判断いただくというより、〇〇を確認いただければと思います`（押しつけない導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`お役に立てるお話は今日できるかなと思います`、`やっていけそうかなと`）→ 1通あたり0〜1回までOK
- `かと`: あり（`対応させていただいたかと思うんですけれども`、`進めにくいかと思うので`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伝えできればと思うので`、`整理できればと`、`お伺いできればと`）→ 案内の温度感に少量。依頼文の着地は「ご確認いただけますと助かります」で止める
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `確実性が高い`、`ほぼ確実に上がる` と語る場面があるが、本人も `100%とは言えないかもしれませんが` と留保している。メールでは `〜という方が多いです`、`判断材料になるかと思います` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
