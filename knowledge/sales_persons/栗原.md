# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（受け止め・確認の定番。非常に頻出）
- `〜かと思うので` / `〜かと思いますが` / `〜かと`（実発話で複数回。例：`お話進みにくいかと思ので`、`根掘り葉掘り聞いてしまうのは失礼かと思ので`、`フランチャイズビジネスってあったかと思ですけど`、`心配していただかなくて大丈夫かと思います`）
- `〜させていただければと思います`（提案・お願いの着地で多用）
- `ご安心ください` / `安心いただいて大丈夫です` / `そこは安心いただければと思います`（不安をほどくときの定番）
- `しっかり〜`（`しっかりお伝えできれば`、`しっかりお答えしていきたい`）
- `あの` / `ええ`（間つなぎ。文章では削る）
- `ぶっちゃけ`（くだけた強調。ごく稀。メールでは使わない）
- `〜という形になります` / `〜という流れですね`（仕組み説明の着地）

## 一人称・距離感

- 一人称: 僕ら / 私 / 弊社（`僕らのシステム`、`私がですね`、`弊社の`）
- 顧客への呼び方: `小川さん`（文字起こしでは音声誤認識により一部`お母さん`と表記されるが、実際は`小川さん`と呼んでいる。口調反映では`お母さん`を使わない）
- 相手を立てる・気遣いの言葉が多い（お子さんの声に `音声オンのままで大丈夫ですよ`、土曜の面談に `お休みのところ` など）

## メール反映の定型

- `〇〇かと思います`（柔らかい見立て。1通0〜1回まで）
- `〜させていただければと思います`（提案・お願いの着地）
- `そこはご安心ください` / `安心いただいて大丈夫です`（不安への受け止め）
- `しっかりお伝えできればと思います`
- 締め: `引き続きよろしくお願いいたします` / `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（実発話で複数回、明確）→ 1通あたり0〜1回までOK
- `かなと`: あり（`面白そうかなと思って`＝自分の経歴を語る場面）→ 控えめに0〜1回までOK
- `できればと`: 単独の余白止めは確認できず → ネクストアクションは「いただけますと幸いです」「ご連絡いただけますでしょうか」で着地させる
- `見ていただけると`: `ぜひ見ていただきたい` はあるが余白止めの `見ていただけると。` は無し → 余白止めとしては使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `ちゃんとやれば売り上げ利益が出る`、`どなたでも上がりやすい` と語るが、`めちゃくちゃ儲かることもない`、`平均点みたいな感じ` と必ず期待値を戻している。メールでも `〜という方が多いです` 程度に留め、保証表現にしない）
- ローン審査・割引特典の断定（`審査がある`、`一週間以内だと割引特典` は商談内で出たが、メールでは条件・期限を断定せず、次回面談で確認する形にする）
- 過度な美文
- 顧客感情の断定
