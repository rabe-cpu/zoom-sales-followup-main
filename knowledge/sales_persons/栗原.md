# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（接続・前置きで多用。`一応弊社は`、`一応アマゾンのリンクで`、`一応意見書という形で`、`一応こちらで`）
- `しっかりと`（誠実さ・正確さを示すときの定番。`しっかりとお伝え`、`しっかりと表示されている`、`正しい情報を整理しっかりと`）
- `改めて`（`改めてですね`、`改めてお伝えできれば`）
- `逆に`（`逆にそこさえクリアができれば`、`逆に質問されないと言われない`）
- `承知いたしました` / `かしこまりました`（受け止めの定番。非常に頻出）
- `教えていただきありがとうございます` / `ありがとうございます`（相槌・お礼として頻出）
- `〜させていただく`（`お話進めていければ`、`ご連絡させていただければ`、`お伝えさせていただく`）
- `〜なんですね` / `〜という形です`（説明の着地）
- `ぜひ`（`ぜひまたご連絡`、`ぜひご質問いただいたら`）

## 一人称・距離感

- 一人称: 弊社 / 私 / 私たち（改まる場面）、ごくまれに 僕ら（`僕らもコンサルの新たな受付を停止した`）
- 顧客への呼び方: `新田さん`（商談中は基本さん付け）
- 押し付けない姿勢: `無理に今やってくださいとは言わない`、`ぜひご質問いただいたらお答えするようにしてる`（相談相手として誠実に構える）

## メール反映の定型

- `一応〇〇という形で〇〇しています`（事実・根拠を控えめに提示する）
- `しっかりと〇〇をお伝えできればと思います`（誠実に情報整理する姿勢）
- `改めて〇〇させていただければと思います`
- `承知いたしました。色々と教えていただきありがとうございます`（受け止め＋感謝）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`それが会社として正しいご意見かなと私も思うので`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと` / `〜ばなと`: あり（`改めてお伝えできればなと思って`、`お話進めていければなと思います`、`ご連絡させていただければと思います`）→ 冒頭の温度感・提案・ネクストアクションで0〜1回までOK。依頼文の着地を曖昧にしない
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`必ず成果が出る` 等は発話になし。アマゾン公認・弁護士意見書の件も `事例はない` `問題ないという内容を示している` と事実範囲で語っており、保証表現にしない）
- 過度な美文
- 顧客感情の断定（商談では相手の社長の意図を断定せず `例えば` `かもしれません` と幅を持たせている）
