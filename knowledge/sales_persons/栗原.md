# 栗原 哲也さん

## 商談内で見えた特徴

- `はい、ありがとうございます`（相槌・お礼として非常に頻出）
- `そうですよね`（共感の受け止め。多用）
- `わかりました。わかりました。`（二度重ねて受け止める）
- `かしこまりました` / `承知いたしました`（依頼を受けるとき）
- `正直` / `正直なところ` / `包み隠さずお伝えすると`（デメリットも率直に出す前置き）
- `一応`（控えめに事実を置くときの接続）
- `まあ` / `ちょっと` / `えっと`（やわらげの口語）
- `ご留意いただきたい点が`（注意点を丁寧に切り出す）
- `〜という形になります` / `〜というレベルですね` / `〜イメージになっています`（説明の着地）
- `さすがです`（顧客の理解を立てる）

## 一人称・距離感

- 一人称: 私 / 弊社（`私の方で`、`弊社は`、`弊社のシステム`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 温度感: 柔らかい敬語で相手を立てつつ、要所で `正直に申し上げると` と率直さを混ぜて信頼を作る

## メール反映の定型

- `本日もお忙しい中、ありがとうございました`（お礼の切り出し）
- `正直に申し上げると、〇〇です`（デメリット・前提を率直に）
- `〜という形になります`（条件・仕組みの着地）
- `ご安心ください` / `お気になさらず`（不安の受け止め。ただし成果保証にはしない）
- `もし必要であれば、遠慮なくお申し付けください`（相談導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`〜じゃないかなと思いますね`、`〜かなと思います`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → `かなと` に寄せ、多用しない
- `できればと`: 出現なし → ネクストアクションは `いただけますと助かります`、`おっしゃってください` で着地させる
- `見ていただけると`: `見ていただければと思います` の形で出現あり → `見ていただければと` は1回まで可

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし。AIっぽい美文として使わない）
- 成果保証・収益保証・断定（商談では未達の方が一定数いることも正直に開示している。メールでは `〜という方が多いです` `狙っていけるイメージです` 程度に留める）
- 価格・割引特典の断定（適用可否は社内確認中のため、確定前に言い切らない）
- 審査・信販・資金調達の断定（融資・借入は確認前提で書く）
- 顧客感情の断定
