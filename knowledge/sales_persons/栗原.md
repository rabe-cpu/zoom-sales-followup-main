# 栗原 哲也さん

## 商談内で見えた特徴

- `端的に言うと`（要点を先に出すときの切り出し）
- `要は`（かみ砕いて言い換える接続）
- `実は`（背景・裏側を明かすときの導入。`実は輸出やってるんですよね`）
- `逆に`（`逆にその方がいいです`）
- `おっしゃる通りです`（顧客の理解を肯定する相槌。非常に頻出）
- `〜という形になります` / `〜という形で`（締めの言い回し）
- `〜っていうイメージです` / `〜という感じですね`（説明の着地）
- `〜っていう仕組みになってます`（機能説明の締め）
- `ありがとうございます`（相槌・お礼として超頻出）
- `かしこまりました` / `承知いたしました`（依頼・要望を受けたときの返し）
- `すごい` / `本当ですか` / `嬉しいですね` / `面白いですね`（会話を温める素の反応）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのやり方`、`僕の方で`）、改まると 私 / 弊社
- 顧客への呼び方: `中塚さん`（商談中は基本さん付け）
- スタンス: 押し込まず、率直に損得を説明する（`やめるメリットがないんですよね`、`お金がある方は分割しないです`）。最後は `個人的にはすごくおすすめかなと思います` と、あくまで所感として添える

## メール反映の定型

- `端的に言うと、〇〇です`（要点を先に）
- `要は〇〇という形です`
- `〇〇という感じですね` / `〇〇というイメージです`（説明の締め）
- `おっしゃっていた〇〇の件`（顧客の発言を受け直すとき）
- 依頼・案内: `〇〇いただければと思います`、`〇〇していただくと〜`
- 締め: `よろしくお願いします` / `ありがとうございました`

## 余白表現の出現

- `かなと`: あり（`個人的にはすごくおすすめかなと思います`）→ 1通あたり0〜1回までOK。所感・軽い提案の場面でのみ
- `かと`: あり（`〇〇だったかと思うので`）→ 1通あたり0〜1回まで。依頼文の着地には使わない
- `できればと`: 明確な出現なし → ネクストアクションは「いただけますと助かります」「ご確認いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `成果が出る自信もあります` `再現性が高い` と語るが、メールでは `〜という方が多いです` `平均的な目安として` 程度に留め、`必ず売れます`『稼げます』にしない）
- `誰でも簡単に`（発話になし）
- 過度な美文
- 顧客感情の断定
