# 栗原 哲也さん

## 商談内で見えた特徴（実発話ベース）

- `かしこまりました` / `承知いたしました`
- `ありがとうございます`（受け止め・感謝を厚めに置く）
- `一応` / `ちょっと` / `まあ` / `実は` / `逆に` / `ぶっちゃけ`
- `改めまして`
- `〜かと思います`（`落ち着いた環境の方がお話ししやすいかと思ので`、`全画面表示で見やすいかと思います`）
- `〜かなと思います`（`いいのかなと思です`、`お安くご案内できるんじゃないかなと思いますね`）
- `〜できればと思います` / `〜していければと思います`（`お役に立てる話ができればと思います`、`お話進めていければと思います`）
- `ご安心いただければと思います`（安心導線）
- 顧客の行動・姿勢を具体的に称賛（`さすがです`、`行動力があるな`、`すごく素晴らしいなと思います`）

## 一人称・距離感

- 一人称: 僕ら／弊社／私
- 顧客への呼び方: `小野さん` のように `〇〇さん`（さん付け中心）

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `ご不明点等があれば、いつでもご連絡ください`
- `資料を改めてお送りします`
- `ご確認いただいたうえで`
- 安心導線: `ご安心いただければと思います`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（複数回）→ 1通あたり0〜1回までOK。文末で多用しない
- `かなと`: あり → 1通あたり0〜1回までOK
- `できればと`: あり → ネクストアクションでは `お送りします` `お待ちしております` 等で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益保証に聞こえる断定（`必ず稼げます` 等）
- 顧客感情の断定
- 過度な美文
