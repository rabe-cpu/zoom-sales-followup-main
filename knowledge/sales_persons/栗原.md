# 栗原 哲也さん

## 商談内で見えた特徴

- `ありがとうございます`（受け止め・お礼として非常に頻出。相手の発話を一度受けてから返す）
- `もちろん` / `もちろんね`（相手の気持ちを肯定してから本題へ）
- `包み隠さずお伝えすると`（率直さを担保する前置き）
- `経験上` / `私の経営をしてきた経験上` / `今まで◯◯人以上とお話ししてきた`（自身の経営・商談経験を根拠に置く）
- `なんで`（順接「なので」の口語。段落のつなぎで多用）
- `〜という形`（説明の着地）
- `かしこまりました` / `承知いたしました`（依頼受けの締め）
- `遠慮なく〜活用していただきたい`（サポート導線・安心づけ）
- `早めに手を打つ` / `動いたもん勝ち`（背中を押すときの言い回し。ただしメールでは煽りにしない）

## 一人称・距離感

- 一人称: 私 / 僕（両方使う。改まる場面や経営者としての話は`私`、雑談寄りは`僕`）。メールでは`私`に統一する。
- 顧客への呼び方: `◯◯さん`（商談中はさん付け）。メール宛名は`さま`。

## メール反映の定型

- `本日は◯◯の中、お時間をいただきありがとうございました`（冒頭のお礼）
- `包み隠さずお伝えすると〜`（率直な整理の前置き。メールでは控えめに）
- `経験上、◯◯という形が多いです`（根拠を経験に置く。保証にしない）
- `〜という形で進めていければと思います`（次アクションの着地）
- `遠慮なくご連絡いただければと思います`（安心導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`合うビジネスかなと`、`いいのかなと`など複数回）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「いただければと思います」「ご連絡いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `平均以上出ると思います` `500,000は狙える` と語る場面があるが、メールでは実績や見込みとして保証表現にしない）
- 過度な美文
- 顧客感情の断定
- マイル・ポイント・カード紹介など個人的な雑談要素を顧客送付メールに持ち込まない
