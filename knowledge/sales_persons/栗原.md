# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（説明の前置きで多用。`一応弊社で`、`一応今後のご提案としては`、`一応平均で`）
- `改めて`（仕切り直し・名乗りで使う。`改めて本日`、`改めて弊社のこのアクセス`）
- `ちょっと`（やわらげの前置き。`ちょっとご説明させていただくと`、`ちょっとお伺いしていきます`）
- `じゃあ` / `じゃあですね`（話題の切り替え）
- `なので`（理由から結論へつなぐ）
- `承知いたしました` / `かしこまりました`（受け止めの相槌。非常に頻出）
- `〜という形になります` / `〜という形です`（締めの言い回し）
- `〜していきたいと思います` / `〜お伝えできればと思います`（次の動きの予告）
- `ご安心ください` / `遠慮なくご連絡ください`（安心導線）
- `ありがとうございます`（お礼・相槌で頻出。`真剣にご検討いただきありがとうございます`）

## 一人称・距離感

- 一人称: 僕ら / 私 / 弊社（`僕らのシステム`、`僕ら個人なので`、改まると `私`・`弊社`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）。メールでは正式名で `師さま`

## メール反映の定型

- `一応〇〇という形です`（事実を控えめに置く）
- `改めて、本日はありがとうございました`（仕切り直しのお礼）
- `なので、〇〇していきたいと思います`（次アクションの予告）
- `ご不明点等ございましたら、遠慮なくご連絡ください`（安心導線）
- `〜お伝えできればと思います`（次回への接続）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思うので`、`失礼かと思いますので`、`いらっしゃったかと思うので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`意味な違いかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`しっかりとお伝えできればと思うので`、`整理できればと思います`）→ ネクストアクションでの軽い接続に少量だけ可
- `見ていただけると`: 明確な出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `あまり失敗がしにくい`、`確実性高く` と語る場面があるが、`ほとんど難しいかもしれませんが` と振れ幅も添えている。メールでは `〜という方が多いです` 程度に留め、保証表現にしない）
- `全額返金保証`・キャンペーン期限・申込特典は、営業本人が条件を最終確認すべき情報。メール本文に細かい金額・期限を断定で書かず、資料と次回面談での確認に寄せる
- 過度な美文
- 顧客感情の断定
