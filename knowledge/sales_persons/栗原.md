# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（丁寧な受け。非常に頻出）
- `ありがとうございます`（相槌・お礼として頻出）
- `〜かなと思います` / `〜じゃないかなと思います`（やわらかい推量での着地）
- `〜という形になっています` / `〜という仕組みになってます`（説明の締め）
- `ぜひ一緒に頑張っていきましょう`（合意形成・前向きな誘い）
- `素晴らしいですね` / `行動力が素晴らしい`（顧客の決断を立てる）
- `ご安心いただけるところかな` / `安心いただいて大丈夫`（不安をほどく）
- `別にやってほしいというよりかは、合うかどうか確認してほしい`（押し売り回避の枕）

## 一人称・距離感

- 一人称: 僕 / 私 / 弊社
- 顧客への呼び方: `〇〇さん`

## メール反映の定型

- `〇〇という形になっています`（仕組みの着地）
- `〜かなと思います`（やわらかい推量）
- `ご安心いただけるところかなと思います`（安心導線）
- `合うかどうかを確認していただければ`（判断を顧客に委ねる）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`〜かなと思います` を多用）→ 1通あたり0〜1回までOK、連発しない
- `かと`: あり（`進めにくいかと思うので`）→ 穏やかな前置きで0〜1回
- `できればと`: 単独の明確な出現なし → ネクストアクションは「いただけますと」「お待ちしております」で着地
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `必ず成果が出ます` / `最低限これぐらい出る`（商談中に近い表現があるが、成果保証になるためメールでは使わない。`取り組まれた方の過去の平均では』程度に留める）
- `伝わってまいりました`
- 過度な美文
- 顧客感情の断定
