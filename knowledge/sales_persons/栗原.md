# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（相槌・受け止めで非常に頻出）
- `〜かと思いますので` / `〜かと思います`（提案・案内の切り出しで多用。例: `ご紹介できるかと思いますので`、`質問しやすいかと思います`）
- `〜させていただきます` / `〜させていただければと思います`（依頼・案内の定番）
- `ご安心ください` / `ご安心いただければと思います`（不安をほどくとき）
- `もちろんです` / `もちろん`（顧客の確認に対する即答）
- `おっしゃる通りですね` / `左様でございます`（顧客の理解への同意）
- `逆に言うと` / `逆を返すと` / `要は` / `つまり`（仕組みをかみ砕く接続）
- `なので` / `だから`（因果の接続）
- `ぜひ〜くださいね` / `使ってくださいね`（軽い提案の締め）
- `〜という方が多いですね` / `〜みたいな方が多いですね`（事例を一般化する言い回し）
- `ありがとうございます`（相槌・お礼として頻出）
- `ちょっと` / `まあ`（話の切り出しのクッション。多用）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らのような個人`）、改まると 弊社 / 私
- 顧客への呼び方: `小山さん`（商談中は基本さん付け）

## メール反映の定型

- `〜かと思います`（提案の柔らかい着地。例: `お役に立てるかと思います`）
- `ご安心いただければと思います`（不安への受け止め）
- `〜させていただきます` / `〜お送りさせていただきます`（案内・送付の定番）
- `逆に言うと〇〇です` / `要は〇〇です`（仕組みの言い換え）
- `〜という方が多いですね`（事例の一般化。保証にしない）
- 締め: `よろしくお願いいたします` / `失礼いたします`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思いますので`、`ご紹介できるかと思います`、`失礼かと思いますので` など複数回）→ 1通あたり0〜1回までOK。提案・案内の柔らかい着地でのみ使う
- `かなと`: あり（`必ずお役に立てるお話できるかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: 栗原さんの発話に確認なし（顧客側の `できればいいなあ` はあるが営業発話ではない）→ 使わない。ネクストアクションは `いただけますと助かります` `ご確認いただけますでしょうか` で着地させる
- `見ていただけると`: 単独での出現なし → `ご覧いただければと思います` の着地形で使う

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `8割達成` `負けがない` と語る場面があるが、`めちゃくちゃ儲かることはない` とも自ら補足している。メールでは `〜という方が多いです` 程度に留め、収益保証・審査保証にしない）
- 過度な美文
- 顧客感情の断定
