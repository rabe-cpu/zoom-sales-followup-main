# 栗原 哲也さん

## 商談内で見えた特徴

- `一旦` / `改めて` / `ちなみに` / `逆に言うと`
- `で、` `まあ` `要は` で話をつなぐ
- `〜という形になります` / `〜という形で大丈夫です`（説明の着地）
- `ご安心ください` / `安心いただければと思います`
- `わかります、わかります` / `そうですよね`（顧客の不安への共感）
- `遠慮なく` / `何度でも` / `気兼ねなく`（サポート導線の案内）
- `ご確認いただいて` / `ご覧いただいて` / `活用していただければと思います`
- `させていただく`（お送りさせていただいた、ご案内させていただく）
- 事例・数字を出すときは断定せず `〜かなと思います` `〜と思ってます` で止める

## 一人称・距離感

- 一人称: 僕ら／弊社／私
- 顧客への呼び方: `石川さん`（`〇〇さん` を基本、丁寧に寄せる場面で `さま`）
- お客様先行事例は「渡辺さん」「パートナー様」のように敬称付きで紹介

## メール反映の定型

- `先日はお時間をいただきありがとうございました`
- `資料を改めて見ていただいたうえで`
- `ご不明点があれば遠慮なくご連絡いただければと思います`
- `弊社の方でしっかりとサポートさせていただければと思います`
- `安心いただければと思います`
- 締め: `引き続きどうぞよろしくお願いいたします` / `本当にありがとうございます`

## 余白表現の出現

- `かと`: あり（`大丈夫かと思います`、`おありだったかと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`安心かなと思います`、`ないかなと`）→ 1通あたり0〜1回までOK
- `いただければと`: 多数あり → ネクストアクション・安心導線で自然に着地させる（文を途中で止めない）
- `見ていただいて`: あり（`資料を改めて見ていただいて`）→ 依頼の柔らかい導入で使用OK

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- `必ず成果が出ます` / `絶対に稼げます`（栗原さんはむしろ「100%うまくいくビジネスはない」と正直に話すタイプ。断定はしない）
- 過度な美文
- 顧客感情の断定
