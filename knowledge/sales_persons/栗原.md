# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（相槌・受け止めで非常に頻出。話の切り替え時にも使う）
- `かしこまりました`（依頼を受けた締めで使用）
- `じゃあ` / `まず` / `改めて`（段落の切り出し）
- `一応`（前置きをやわらげる）
- `〜という形ですね` / `〜というイメージです`（説明の着地）
- `ご安心ください`（不安への受け止め。`許可なく外部に公開すること一切ございませんのでご安心ください`）
- `〜させていただければと思います` / `〜お伝えできればと思います`（提案・案内の柔らかい着地）
- `しっかり`（`しっかりとご紹介`、`しっかりご検討`）
- `ぜひ`（`ぜひね、しっかりとご検討いただけるように`）
- `いつでもご連絡ください`（締めの相談導線）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らみたいな個人`）、改まると 弊社 / 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま` に上げてよい）

## メール反映の定型

- `承知いたしました。`（受け止めの一言）
- `改めて〇〇させていただければと思います。`
- `〇〇というイメージです` / `〇〇という形ですね`（説明の締め）
- `ご安心ください` / `気兼ねなくご連絡ください`（不安への受け止め）
- `ぜひ一度〇〇いただけますと幸いです`（やわらかい依頼）
- 締め: `引き続きよろしくお願いいたします` / `本日はありがとうございました`

## 余白表現の出現

- `かと`: あり（`見やすくなるかと思います`、`失礼かと思いますので`、`お役に立てるお話できるかと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`立ち上げぐらいかなとは思いますね`、`しっかりご検討できるかなと思います`）→ 1通あたり0〜1回までOK。`かと`と合わせて1通2回以上連続させない
- `できればと`: あり（`ご紹介できればと思って`、`お伝えできればと思います`）→ 提案・案内の着地で少量OK
- `見ていただけると`: 明確な出現なし（`ご覧いただいて`、`見ていただきたい`はある）→ `見ていただけると`形は使わず、`ご覧いただけますと幸いです`などの着地形にする

## 禁止候補

- `確実に収益が上がる` / `自信を持って〇〇できる`（商談終盤で口にしているが、成果保証になるためメールでは使わない。`しっかり取り組まれている方が多いです`程度に留める）
- `必ず成果が出ます` / `誰でも簡単に`（成果保証・断定）
- `伝わってまいりました`（栗原さんの発話に確認なし）
- 顧客感情の断定、過度な美文
