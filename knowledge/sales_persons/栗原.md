# 栗原 哲也さん

## 商談内で見えた特徴

- `〜させていただければと思います` / `〜させていただきます`（依頼・案内の基本形。非常に頻出）
- `〜していただければと思います`（お願い・確認の着地）
- `ご安心ください` / `ご安心いただければと思います` / `安心していただければと`（不安を受け止める定番）
- `もちろんです`（快諾）
- `承知いたしました`（受け止め）
- `ありがとうございます` / `教えていただきありがとうございます`（相槌・お礼として頻出）
- `〜という形になります` / `〜という感じですね` / `〜という形ですね`（説明の着地）
- `〜っていう方が多いですね`（事例の一般化）
- `一応`（データ・条件を出すときの前置き）
- `改めまして`（名乗りの入り）
- `ぜひ`（次アクションへの誘導）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らみたいな個人`）、改まると 私 / 弊社（`私の方で対応させていただく`、`弊社のシステム`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `〜させていただければと思います`（案内・依頼の基本）
- `〜という形になります` / `〜という形ですね`（説明の締め）
- `ご安心ください` / `安心していただければと思います`（不安への受け止め。ただし成果保証にはしない）
- `〜という方が多いですね`（事例の紹介）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`失礼かと思うので`、`進めにくいかと思うので`、`投資する必要が出てくるかと思うので`）→ 1通あたり0〜1回までOK
- `かなと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: あり（`お伺いできればなと思います`、`お話できればと思います`、`整理できればと思います`）→ 冒頭の温度感や次アクションの軽い提案で少量OK
- `見ていただけると`: `ご覧いただいて` / `確認いただいて` / `見ていただければ` の形で出現 → `ご覧いただけますと` `ご確認いただけますと` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗しにくい`、`確実に出やすい`、`81.4%` と語る場面があるが、メールでは `〜という方が多いです` 程度に留め、収益保証・審査通過保証にしない）
- 過度な美文
- 顧客感情の断定
