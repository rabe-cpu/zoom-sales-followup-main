# 栗原 哲也さん

## 商談内で見えた特徴

- `ちょっと`（前置き・やわらげの口癖。非常に頻出。`ちょっと簡単に`、`ちょっとご説明の方を`）
- `じゃあ` / `じゃあ早速`（場面転換の切り出し）
- `で、`（段落間のつなぎ）
- `なので`（理由から結論へつなぐ）
- `まず初めに` / `改めて`（順序立ての接続）
- `要するに` / `端的に言うと`（かみ砕くときの接続）
- `〜させていただければと思います`（依頼・案内の定番。多用）
- `〜お伺いできればと思います`（ヒアリングの切り出し）
- `〜という形ではいかがですか` / `〜という流れはいかがですか`（相談ベースのクロージング。押しつけない）
- `〜いただいてもいいですか`（やわらかい依頼）
- `承知いたしました` / `かしこまりました`（受けの締め。頻出）
- `ご安心ください`（不安への受け止め）
- `ありがとうございます` / `こちらこそありがとうございます`（相槌・お礼として頻出）

## 一人称・距離感

- 一人称: 僕ら / 僕（`僕らのシステム`、`僕自分でも`、`僕らのビジネス`）、改まると 弊社 / 私（`私の自己紹介から`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `まず〇〇について、次に〇〇について`（順序立てて案内する）
- `要するに〇〇ということです`（仕組みをかみ砕く）
- `〜させていただければと思います`（案内・送付の着地）
- `ご安心ください` / `無理せず〇〇で大丈夫です`（不安への受け止め）
- `〜という形ではいかがですか`（次アクションを相談で置く）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話進めにくいかと思います`、`聞いていただいたかと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`最後のチャンスかなと思って`、`お忙しいのかなと思って`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伺いできればと思います`、`ご案内できればと思います`）→ 案内・依頼の着地で少量ならOK。ただし依頼文を途中で止めない
- `見ていただけると`: 明確な出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗はしにくい`、`81.4%`、`継続率90%以上` と数字を語るが、あくまで平均・実績値として提示している。メールでは `〜という方が多いです`、`平均では〜` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
