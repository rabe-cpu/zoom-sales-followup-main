# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（確認・受け止めで多用）
- `ありがとうございます`（傾聴の区切りで多用）
- `確かに確かに`（共感の相槌）
- `はい、はいはいはい`（傾聴の相槌）
- `一旦`（`一旦あの、その旨でお伺いしましたので`）
- `〜と思います` / `〜と思うので`
- `お伺いできればと思います`
- `割と` / `まあ` / `ええと`（やわらかいフィラー）
- 仕組みを画面で見せながら具体で説明する進め方

## 一人称・距離感

- 一人称: 私／僕ら（弊社）
- 顧客への呼び方: `〇〇さん`
- 創業メンバーで事業歴が長く、経験談を交えつつ傾聴・共感で信頼を作るスタイル

## メール反映の定型

- `承知いたしました`
- `一旦こちらのメールにご返信いただいても問題ございません`
- `一つずつ確認させてください`
- `〜と思いますので`
- `資料をお送りしますので確認してください`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かと`: 直接の確認は限定的 → メールで多用しない
- `かなと`: 限定的 → 1通あたり0〜1回まで
- `できればと`: `お伺いできれば` の形で出現 → ネクストアクションでは「〜と思います」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 過度な美文
- 顧客感情の断定
- 成果・収益の保証表現
