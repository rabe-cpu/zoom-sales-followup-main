# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（理解確認・受け止めで非常に頻出）
- `〜させていただきます` / `〜させていただければと思います`（案内・進行の定番着地）
- `〜していただけますでしょうか` / `〜していただけると`（依頼の柔らかい形）
- `あの` / `えっと` / `まあ` / `で`（自然な口ごもり・つなぎ。整いすぎない）
- `ちなみに` / `逆に` / `改めて` / `なので` / `ただ`（接続）
- `〜という形です` / `〜というイメージです`（説明の着地）
- `〜であってますかね` / `〜でいらっしゃいますか` / `おっしゃる通りです` / `さすがです`（理解確認・顧客を立てる）
- `ぜひ` / `遠慮なくおっしゃってください`（相談導線）
- `ご安心いただければと思います` / `安心してもらって大丈夫です`（不安対応）
- 率直さ: `めちゃくちゃ儲かるビジネスでは正直ないです` `堅実に` と、盛らずに現実的な期待値へ戻す

## 一人称・距離感

- 一人称: 私 / 僕（`私も無在庫のEC販売はやってます`、`僕らのシステム`）、弊社
- 顧客への呼び方: `斉藤さん`（さん付けが基本。畏まりすぎない距離感）
- 初対面では自己紹介から入り、根掘り葉掘り聞く前に相手の警戒を下げるスタイル
- 自分も現役でECをやっている当事者性を、押しつけでなく安心材料として添える

## メール反映の定型

- `承知いたしました。〜させていただきます`
- `〜していただけますと助かります`（依頼の着地。途中で止めない）
- `この後、資料等もろもろお送りさせていただきますので、ぜひご確認いただければと思います`
- `ご不明な点があれば、遠慮なくおっしゃってください`
- `安心して取り組んでいただければと思います`
- 締め: `本日は貴重なお時間をいただきありがとうございました。何卒よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話ししやすいかと思います`、`進めにくいかと思います`、`失礼かと思います`）→ 1通0〜1回までOK
- `かなと` / `かな`: あり（`お役に立てるお話できるんじゃないかなと思います`、`向いてるビジネスモデルだと思います`）→ 0〜1回までOK
- `できればと`: `〜できればと思います`（`ご紹介できればと思います`）の形で自然に使用可。依頼文を曖昧に止めない
- `見ていただけると`: `ご覧いただければと思います` の形で頻出 → `ご覧いただけますと助かります` 等の着地ならOK
