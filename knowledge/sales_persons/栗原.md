# 栗原 哲也さん

## 商談内で見えた特徴

- `改めて`（おさらい・仕切り直しで多用。`改めてもう一つ大きな特徴としては`）
- `端的に言うと` / `正直ベースで端的にお伝えすると`（結論を先に置く前置き）
- `ちなみに`（話題の追加・確認で使用）
- `承知いたしました` / `かしこまりました` / `もちろんです` / `もちろんでございます`（依頼受けの定番）
- `〜させていただければと思います` / `〜していただければと思います`（案内・依頼の着地）
- `わかります。わかります。` / `そうですよね` / `いえいえいえ`（共感の相槌。顧客の苦労話を受け止める）
- `一つ、いい方法がありまして`（提案の切り出し）
- `思い立ったら吉日`（ことわざで背中を軽く押す。※押しつけにはしない）

## 一人称・距離感

- 一人称: 僕ら / 弊社 / 私（`僕らのビジネス`、`弊社のシステム`、`私から電話いたしましょう`）
- 顧客への呼び方: `野津さん`（さん付けで距離が近い。丁寧だが堅すぎない）
- 顧客の状況（体調・家族・仕事の繁閑）に雑談で触れてから本題へ入る。相手の事情を否定せず受け止めてから提案するスタイル

## メール反映の定型

- `改めて〜させていただきます`
- `正直ベースで端的にお伝えすると、〜`
- `また、メールでもお送りしますので、ご確認いただければと思います`
- `私からお電話差し上げます`（次アクションを自分から巻き取る）
- 締め: `本日はありがとうございました。引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`0時間というお話でいらっしゃったかと思ので`）→ 1通0〜1回までOK。依頼文の着地は曖昧に止めない
- `かなと` / `かな`: あり（`大事かなと思います`）→ 0〜1回までOK
- `できればと`: 栗原さんの発話に確認なし（顧客側の発話）→ 使わない
- `見ていただけると`: 発話になし → `ご確認いただければと思います` 等の着地に寄せる

## 禁止候補

- `伝わってまいりました`（発話に確認なし）
- 成果保証・断定（商談では `100%絶対とは言えない` と自ら保険をかけている。メールでも収益・回収を保証にしない）
- 資金・借入の具体的手段（消費者金融・カード・融資など）に踏み込む記述（顧客のプライバシー。メールでは触れない）
- 顧客の資金不安を煽る・急かす表現、`今決めたほうがいい` の同調圧力
- 過度な美文
