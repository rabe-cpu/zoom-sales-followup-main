# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（口癖。相手の話を受け止めるときに非常に頻出。ヒアリングの区切りで多用）
- `ありがとうございます`（相槌・お礼として頻出。相手が質問してくれたときにも挟む）
- `〜かと思うのですが` / `〜かと思いますので`（クッション。実発話にあり。例：`少し失礼かと思うので`、`文字とかも入ってくるかと思いますので`）
- `〜させていただければと思います` / `〜お伝えできればと思います`（依頼・提案の着地。丁寧）
- `もちろんでございます`（相手の要望を受けるとき）
- `〜という形になります` / `〜という形ですね`（仕組み説明の締め）
- `一応` / `ちょっと` / `まあ`（口語のクッション。多用）
- `〜していきたいと思うので`（次の展開へのつなぎ）
- `確かに確かに` / `そうですよね`（共感の相槌）

## 一人称・距離感

- 一人称: 僕ら / 弊社（`僕らのシステム`、`弊社のビジネス`）、改まると 私
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `承知いたしました`（受け止め。ただしメールでは連発しない。冒頭のお礼・受け止めで1回程度）
- `〜という形になります`（仕組み・流れの説明の締め）
- `〜させていただければと思います`（提案・依頼の着地）
- `一応〇〇です`（数字や条件を出すときのクッション）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`少し失礼かと思うので`、`見ていただいたかと思いますけど`）→ 1通あたり0〜1回までOK。冒頭の温度感か軽い提案でのみ使う
- `かなと`: 明確な単独出現は弱い → 無理に使わない
- `できればと`: 出現なし → ネクストアクションは「いただけますと助かります」「ご返信いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では返金保証や平均収益を語るが、メールでは `〜という方が多いです` `平均で〜くらい` 程度に留め、保証・確約表現にしない）
- 過度な美文
- 顧客感情の断定
