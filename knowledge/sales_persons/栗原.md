# 栗原 哲也さん

## 商談内で見えた特徴

- `一応`（口癖。頻出。`一応前回`、`一応最終契約書`、`一応今のところ12日`、`一応18番は別会社`）
- `あの` / `えっと`（説明前のつなぎ）
- `〜という形になります` / `〜っていう形です`（説明の着地・締め）
- `かしこまりました` / `承知いたしました` / `承知しました`（受けの定番）
- `ご安心ください`（不安対応。`社外には漏えいしないのでご安心ください`）
- `ありがとうございます` / `よかったです` / `もちろんです`（相槌・お礼として頻出）
- `さすがですね` / `すごいですよ` / `多才ですね`（相手を素直に立てる）
- `ご提案としては` / `一つ〜としては`（提案の切り出し）

## 一人称・距離感

- 一人称: 私 / 弊社 / 僕ら（`私の方で`、`弊社の物流会社`、`僕らのビジネス`）
- 顧客への呼び方: `〇〇さん`（商談中）。メールでは `〇〇さま`

## メール反映の定型

- `一応〇〇という形になります`（説明の着地）
- `〇〇いただければと思います`（依頼の着地。`ご連絡いただければと思います`、`変更としていただけるといいと思います`）
- `ご安心ください`（不安への受け止め）
- `かしこまりました` / `承知いたしました`（受け）
- 相手の経験・力量を立てる一言（`さすがですね`）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`売り上げのアッパーがある程度あるかと思ですけれど`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`営業系なのかなと思ってました`）→ 1通あたり0〜1回までOK
- `できればと`: 単独の余白用法は確認できず → 使わない。ネクストアクションは `いただけますと幸いです` `いただけますでしょうか` で着地させる
- `見ていただけると`: 出現なし → 使わない。`ご覧いただけますと` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益断定（本人は慎重。`私の立場では申告しましょうとしか言えない` のように断定を避ける姿勢。メールでも `〜という方が多いです` 程度に留める）
- 他ユーザーの突出売上（上田さま月商1,000万円など）を成果期待として書くこと
- 過度な美文、顧客感情の断定
