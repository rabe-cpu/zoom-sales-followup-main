# 栗原 哲也さん

事業部最古参・創業時メンバー。個人でもネットショップを経営している。

## 商談内で見えた特徴

- `じゃあ` / `一応` / `なので` / `だから`（説明の切り替え）
- `ちなみに` / `逆に` / `改めて`
- `かしこまりました` / `承知いたしました`
- `おっしゃる通りです`
- `〜していただければと思います`（依頼・提案の着地）
- `お伺いさせていただいて` / `ご案内させていただきます`（丁寧なヒアリング導入）
- `かと思うので` 系の柔らかい判断（`お話ししにくいかと思うので`、`スムーズかと思います`）
- `かなと思う` 系（`失礼かなと思うので`、`いいんじゃないかなと思います`）
- `遠慮なく`（サポート案内で使用）
- `ありがとうございます`（受け止め・感謝を頻繁に挟む）
- `〜ですよね` / `いいですね`（共感）

## 一人称・距離感

- 一人称: 私（自分のこと）／僕ら（事業部・チーム）／弊社
- 顧客への呼び方: `細川さん` 中心。ややフランクで距離を縮める会話運び

## メール反映の定型

- `簡単にご状況をお伺いさせていただきます`
- `〜をお伝えできればと思います`
- `資料をお送りさせていただきます`
- `ご不明点・気になった点が出てきましたら`
- `遠慮なくご質問いただいて大丈夫です`
- `無理に今日決めるのではなく、資料を見ていただいてから`
- 締め: `今日はお忙しいなかありがとうございました` / `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思うので`、`スムーズかと思います`）→ 1通あたり0〜1回までOK、文末で多用しない
- `かなと`: あり（`失礼かなと思うので`、`いいんじゃないかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お伝えできればと思います`）→ ネクストアクションでは「お送りいたします」「お話しできればと思います」で着地させる
- `見ていただけると`: 近い表現あり（`見ていただけるといいんじゃないかな`）→ 依頼文の着地は「ご覧いただけますと」で止めない形にする

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- `伝わってきました`（商談内で1回のみ出現。メールでは多用しない。営業所感より判断材料を優先）
- 成果保証・収益保証に聞こえる断定
- 顧客感情の断定
- 過度な美文
