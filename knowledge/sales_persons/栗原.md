# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（顧客の要望・回答を受けるときの定番。非常に頻出）
- `〜かと思いますので` / `〜かと思うですけれども`（前置き・配慮の接続で多用。→ 栗原さんは「かと」を実発話で複数回使用。メールでも0〜1回まで自然に使える）
- `ご安心ください`（不安への受け止め。`必要なものは弊社で準備してますのでご安心ください`）
- `〜させていただければと思います`（提案・案内の柔らかい着地）
- `ぜひあのご検討いただけると嬉しいです`（クロージングの締め）
- `何卒よろしくお願いします` / `改めてよろしくお願いします`
- `〜という形になります` / `〜というイメージになります`（説明の着地）
- `もちろん大丈夫です`（顧客の条件・懸念をほどくとき）
- 相手をよく褒める（`ご経験者だから理解がすごい早いですね`、`理解力が素晴らしい`、`飲み込みが早い`）
- 自己開示が厚い（自分の経歴・独立の失敗・借金からの再起を先に話し、距離を縮める）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らの強み`）、改まると 弊社 / 私（`私、栗原と申します`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま`）

## メール反映の定型

- `承知いたしました。〇〇させていただきます`（受け止め＋次の案内）
- `〇〇かと思いますので、〇〇いただければと思います`（配慮の前置き＋依頼）
- `必要なものは弊社でご用意しておりますのでご安心ください`（不安への受け止め）
- `もちろん大丈夫です`（条件をほどく）
- 締め: `ぜひご検討いただけますと嬉しく思います` / `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思いますので`、`失礼かと思いますので`、`お役に立てるお話ができるかと思います` など複数回）→ 1通あたり0〜1回までOK。依頼文の着地は濁さない
- `かなと`: 単独での明確な出現は確認できず → 無理に使わない
- `できればと`: 出現なし → ネクストアクションは「いただけますと助かります」「ご返信いただけますでしょうか」で着地させる
- `見ていただけると`: 明確な出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では平均データや `平均以上は目指せる` と語る場面があるが、メールでは `〜という方が多いです` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
