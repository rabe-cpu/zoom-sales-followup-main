# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（顧客の発言を受け止める相槌として非常に頻出）
- `ぜひぜひ`（質問・要望を歓迎するときの定番）
- `〜できればと思います` / `〜お伝えさせていただければと思います`（依頼・提案の着地）
- `〜ですかね？` / `〜というイメージでいらっしゃいますか`（条件確認・温度確認のやわらかい問い）
- `逆に`（`逆にあの高橋さんについて`、`逆にプラスで終われる`）
- `要するに`（仕組みをかみ砕くときの言い換え）
- `ちなみに`（補足質問の切り出し）
- `じゃあ` / `えっと` / `ちょっと`（段落の切り替え・前置き）
- `ご安心ください` / `安心していただければと思います` / `全然大丈夫です`（不安をほどく定番）
- `ありがとうございます`（相槌・お礼として頻出。`何度もお話聞いてくださりありがとうございます`）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕ら`、`僕らのシステム`、`僕の感覚ですけど`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `承知いたしました`（受け止め。ただしメールでは多用せず、お礼や受け止めの一文に1回まで）
- `〜できればと思います`（次アクション・提案の着地）
- `要するに〇〇です`（仕組みのかみ砕き）
- `〇〇というイメージで合っていますでしょうか`（条件確認）
- `ご安心ください` / `〜は安心していただければと思います`（不安への受け止め。ただし成果保証にはしない）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`失礼かと思いますので`、`ざっくりした内容だったかと思うので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`スムーズに入れるのかなと思います`、`安心かなと思います`、`いいんじゃないかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`〜できればと思います`の形で着地して使う）→ 着地形なので可。文を途中で止めない
- `見ていただけると`: 単独での明確な出現は確認できず → 使わない。`ご覧いただけますと助かります`で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（栗原さんは商談で `8割`、`継続率9割以上`、`ほとんどの方`、`思われる` と統計・伝聞で語り、`必ず儲かる` とは言い切らない。メールでも `〜という方が多いです` `〜というデータがあります` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 「リスクがない」と言い切る表現（在庫リスクが小さい点は事実だが、費用・回収のリスクまでゼロと取れる書き方はしない）
