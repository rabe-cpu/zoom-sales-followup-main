# 栗原 哲也さん

## 商談内で見えた特徴

- `無理せず`（口癖。プランを勧める場面でも `無理せず。でもベーシックでも大丈夫ですけど` と、押しつけずに着地させる）
- `おっしゃる通り`（顧客の理解・気づきを肯定するときの受け）
- `〜いただければと思います`（依頼・お願いの定番）
- `〜という形` / `〜っていう形にしてます`（説明の締め）
- `安心いただいて大丈夫` / `安心いただければと思います`（不安をほどく定番）
- `ぜひぜひ` / `ぜひ`（参加・活用を促すとき）
- `ありがとうございます`（相槌・お礼として非常に頻出）
- `承知いたしました` / `左様でございます` / `〜でございます`（要所で丁寧語がやや強くなる）
- `さすが早いですね`（顧客の行動を具体的にほめる）

## 一人称・距離感

- 一人称: 僕ら / 弊社（`僕らはね`、`僕らもそういう方にこそ`）、改まると 私（`私がご案内した方`、`私の方で行いました`）
- 顧客への呼び方: `加藤さん`（商談中は基本さん付け）
- 気遣いの入り: `貴重なお休みの日に`、`わざわざ`、`無理せず` と、相手の負担をねぎらう前置きが多い

## メール反映の定型

- `無理せず、〇〇で大丈夫です`（選択肢を残す）
- `おっしゃる通り、〇〇です`（顧客の理解を肯定してから補足）
- `〇〇いただければと思います`（お願い・次アクション）
- `安心いただければと思います`（サポート・不安への受け止め）
- 締め: `よろしくお願いします` / `今後ともよろしくお願いします`

## 余白表現の出現

- `かなと`: あり（`安心いただいて大丈夫かなと`、`スタンダードでもいいのかなと少し思った`）→ 1通あたり0〜1回までOK
- `かと`: `〜かと思うので` の形で限定的に出現（`合わないっていうことでいらっしゃったかと思うので`）→ 使うなら「〜かと思います」の着地形で控えめに。文を途中で止めない
- `できればと`: 出現なし → ネクストアクションは「いただければと思います」「ご連絡ください」で着地させる
- `見ていただけると`: 出現なし → 使わない（`目を通していただければ` で着地）

## 禁止候補

- 成果保証・断定（商談では `ほとんどうまく収益上がってる` `平均の倍以上` `年間700万` と語る場面があるが、メールでは保証にしない。`〜という方もいます` 程度に留める）
- 個人情報・審査の内部項目（住所、郵便番号、手取り月収、税込年収、貯蓄額など）はメール本文に出さない
- 過度な美文
- 顧客感情の断定
