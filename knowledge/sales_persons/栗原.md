# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（受け・締めで頻出。顧客の話を受け止める定番）
- `左様でございます` / `さようでございます`（丁寧・やや古風な同意）
- `一応`（前置きで多用。`一応弊社としては`、`一応このプランが`）
- `〜させていただければと思います`（依頼・提案の着地。`お伺いさせていただければと`）
- `ご安心ください` / `安心いただいて大丈夫かと思います` / `ご安心いただければと思います`（不安への受け止め）
- `おっしゃる通りです` / `さすがです`（顧客を立てる相槌。頻出）
- `ちなみに` / `改めて` / `逆に`（話題転換・補足の接続）
- `〜なんですよ` / `〜っていう`（説明時のカジュアルな砕け）
- `すごく` / `めちゃくちゃ` / `圧倒的に` / `本当に`（強調。商品特徴を語るとき）
- `はい、` / `はい。`（相槌として非常に頻出）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕個人としても`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん`（商談中はさん付け。メールでは `〇〇さま`）

## メール反映の定型

- `承知いたしました`（受け止めの一言）
- `一応〇〇です`（断定を避けて情報を出す前置き）
- `〇〇させていただければと思います`（提案・依頼の着地）
- `安心いただいて大丈夫かと思います`（不安への受け止め。ただし成果保証にはしない）
- `おっしゃる通りで、〇〇です`（顧客の理解を肯定してから補足）
- 締め: `引き続きよろしくお願いいたします` / `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`失礼かと思いますので`、`あるかと思います`、`安心いただいて大丈夫かと思います`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`うまくいきやすいんじゃないかなと`、`スタンダードが目安かなと`）→ 1通あたり0〜1回までOK
- `できればと`: 近い表現あり（`お役に立てるお話できればと思います`、`お伝えできればと思います`）→ 提案の着地で少量OK
- `見ていただけると`: 近い表現あり（`ご案内受けていただけるといいかと思います`、`思っていただけると`）→ `〜いただけると` の形で少量OK

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗がすごく少ない` `八割方収益出る` と語るが、`向いてない方もいる` `ローリスク` とバランスを取っている。メールでは `〜という方が多いです` `〜という結果が出ています` に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
