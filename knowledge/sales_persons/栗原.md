# 栗原 哲也さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。質問を受けた直後にも置く）
- `よくご存じで`（顧客が知識を出したときの受け）
- `おっしゃる通りです` / `おっしゃる通りで`（顧客の理解を肯定するとき）
- `あの` / `えっと` / `まあ`（言いよどみ・やわらげ。多用）
- `じゃあ`（話題の切り替え・本題への接続）
- `要は`（かみ砕くときの言い換え）
- `だから`（因果をつなぐ）
- `あくまで`（範囲を限定するとき。`あくまで投資資金なので`）
- `こんなイメージです` / `〜みたいなイメージ`（説明の着地）
- `〜という感じ` / `〜って感じ`（やわらかい締め）
- `安心いただいて大丈夫かなと思います`（不安の受け止め）

## 一人称・距離感

- 一人称: 僕ら / 僕（`僕らのシステム`、`僕らのショップ`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `本日はありがとうございました`（お礼を厚めに置く）
- `〇〇こんなイメージです`（仕組み説明の着地）
- `要は〇〇です`（要点をかみ砕く）
- `あくまで〇〇なので`（範囲を限定して誤解を防ぐ）
- `〜していければと思います`（前向きな締め）
- 締め: `よろしくお願いいたします` / `失礼いたします`

## 余白表現の出現

- `かと`: あり（`今日ご参加いただいたかと思うので`、`失礼かと思うので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`安心いただいて大丈夫かなと思います`、`おすすめできるかなと思います`）→ 1通あたり0〜1回までOK。`かと`と合わせて2回以上続けない
- `できればと`: 単独の明確な出現なし（`お伝えできればなと`、`していければと`は使う）→ ネクストアクションは「いただけますと助かります」「ご返信いただけますでしょうか」「ご確認ください」で着地させる
- `見ていただけると`: 出現なし → 使わない。「ご覧いただけますと助かります」で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗は相当しにくい`、`95%の方が継続`、`一年後には全然黒字`、`誰でも売り上げ利益が上げやすい` と語る場面があるが、メールでは保証表現にしない。`〜という方が多いです`、`〜しやすいです` 程度に留める）
- `誰でも簡単に` / `安心して稼げます`
- 過度な美文
- 顧客感情の断定
