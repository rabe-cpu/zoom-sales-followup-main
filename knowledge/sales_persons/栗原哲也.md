# 栗原 哲也さん

商談（2026-09-14 石川幹二様）の実発話から抽出。事業部創業時から携わるベテラン担当。説明が丁寧で、顧客の疑問を先に受けてから資料に入るスタイル。

## 商談内で見えた特徴

- 冒頭で「今日は一方的に説明するのではなく、確認したい点・不明点をしっかり伺う時間に」と場を作る
- 「ここまで大丈夫ですかね？」「不明点はここまででありますか？」と細かく理解を確認する
- 自己開示（自身の独立失敗・借金・年商3000万の経験）で信頼を作る
- 価格・保証・違約金を隠さず率直に答える

## 一人称・距離感

- 一人称: 僕（「僕らの」「僕ら」）／私（「私がこの事業部では」）／弊社
- 顧客への呼び方: 商談中は `〇〇さん`。メールでは `〇〇さま` に整える

## 接続語・口ぐせ

- `じゃあ` / `で` / `なので` / `だから` / `一応` / `ちなみに` / `改めて` / `早速`
- `〜という形になります` / `〜みたいなイメージ`

## メール反映の定型

- `〜させていただきます` / `〜させていただければと思います`
- `ここまで大丈夫でしょうか` / `ご不明点があれば`
- `かしこまりました` / `承知いたしました` / `もちろんです`
- `ぜひ` / `心からお勧めできます`（温度を出す時。乱用しない）
- 締め: `よろしくお願いいたします` / `ありがとうございます`

## 余白表現の出現

- `かと`: あり → 実発話に複数回（「進めにくいかと思うので」「少し失礼かと思うので」「問題ないかと思います」「必要があるかと思いますが」）。1通あたり0〜1回で使用可
- `かなと`: 明確な使用は未確認 → 使わない
- `できればと`: 未確認 → 使わない
- `見ていただけると`: 未確認 → 使わない

## 禁止候補

- `伝わってまいりました`
- `必ず成果が出ます` / `安心して稼げます` / `誰でも簡単に`（成果保証・断定）
- `すごく`『非常に』『めちゃくちゃ』の根拠なき連発（商談では多いが、メールでは1文まで）
- 押し付けがましい依頼文、途中で止まる依頼文
