# 栗原 哲也さん

## 商談内で見えた特徴

- `〜かなと思います`（口癖。最頻出。説明の着地・提案で多用。`ベーシックかなと思います`、`還元の方が大きいかなと思います`、`ご安心いただいて大丈夫かなと思います`）
- `〜かと思います` / `〜かと`（`お時間はもちろんあるかと思いますけど`）
- `〜できればと思います`（案内・締めの定番。`お伝えできればと思います`、`お話できればと思います`、`整理できればと思います`）
- `〜していただければと思います`（依頼の定番。`見ていただければと思います`、`受けていただければと思います`）
- `〜してくださいね`（やわらかい依頼。`分からなければいつでも問い合わせしてくださいね`）
- `承知いたしました` / `かしこまりました`（受けの定番）
- `ありがとうございます`（相槌・お礼として非常に頻出）
- `確かに確かに` / `そうですよね` / `本当にね`（強い共感の相槌。反復が多い）
- `よかった。よかった。` / `そうです。そうです。`（語の反復で安心感を作る）
- `ご安心いただいて大丈夫かなと思います` / `全然安心して大丈夫です`（不安をほどく定番）
- `ご無理なさらずに` / `ご無理になさらずで大丈夫です`（相手の負担を気づかう）
- `ご体調が一番` / `健康が本当に一番`（相手の体調を最優先に置く声かけ）
- `一緒に頑張っていきましょう` / `一緒に頑張っていければと思います`（締めの伴走表現）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのビジネス`、`僕としては`）、改まると 私 / 弊社（`私がご案内する方`、`弊社のサポート`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま`）
- 自己開示で距離を縮める（`私も一時期無収入で借金を抱えた経験があるので`、`私もアメックスを2枚持っていて`）

## メール反映の定型

- `〇〇かなと思います`（提案・見立ての着地）
- `〇〇できればと思います`（案内・次回接点の締め）
- `〇〇していただければと思います`（依頼の着地）
- `分からなければいつでも問い合わせしてくださいね`（不安への受け止め）
- `ご安心いただいて大丈夫かなと思います`（不安への受け止め。ただし成果保証にはしない）
- `ご無理なさらずに`（相手の体調・状況への気づかい）
- 締め: `よろしくお願いいたします` / `一緒に頑張っていければと思います`

## 余白表現の出現

- `かなと`: あり（最頻出。`ベーシックかなと思います`）→ メールでは1通あたり0〜1回までに抑える
- `かと`: あり（`お時間はもちろんあるかと思いますけど`）→ 発話準拠で少量OK
- `できればと`: あり（`お話できればと思います`、`お伝えできればと思います`）→ 案内・締めで自然に使える
- `見ていただけると`: 単独の明確な出現は確認できず（`見ていただければと思います` は頻出）→ 着地は `見ていただければと思います`／`ご覧いただけますと助かります` に寄せる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `自信を持って言えます`、`実績はどこよりも自信があります` と語る場面があるが、本人も `正確に上がりますとは断言できない`、`平均なので` と言い直している。メールでは `〜という方が多いです`／`平均的には` に留め、`必ず`／`確実に稼げます` のような保証表現にしない）
- 過度な美文
- 顧客感情の断定
- あおり・急かし（5%オフ等の期限特典は本人も `あんまり急かしたくないので`、`ご無理になさらずで大丈夫です` と添えている。メールでも期限を圧にしない）
