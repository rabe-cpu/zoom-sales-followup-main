# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（受け・締めで非常に頻出。顧客の話を受け止めた合図）
- `ありがとうございます` / `こちらこそです`（相槌・お礼として頻出）
- `一応`（説明の前置きで多用。`一応弊社で用意している`、`一応割合でお伝えすると`、`一応マニュアルがあるんで`）
- `ぶっちゃけ`（かみ砕くときのカジュアルな接続。多用しすぎない）
- `なんか`（口語のつなぎ。メールでは落とす）
- `手前味噌ですが`（自社の実績を控えめに出すときの前置き）
- `ご安心ください` / `ご安心いただければと思います`（不安をほどく締め）
- `〜していきたいと思います` / `〜させていただきます`（次の動きの提示）
- `さすがですね` / `すごいですね`（顧客を素直に持ち上げる相槌。増田さんの経営判断を複数回称賛）

## 一人称・距離感

- 一人称: 僕 / 僕ら（説明時。`僕らのシステム`、`僕らのビジネス`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま`）

## メール反映の定型

- `承知いたしました`（相手の意向を受けた一文として自然）
- `一応〇〇という形です`（制度・条件をやわらかく示す）
- `ご安心いただければと思います`（不安への受け止め）
- `〇〇させていただきます` / `〇〇していきたいと思います`（次アクションの提示）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`失礼かと思うので`、`数千円ぐらいかと思うので`、`難易度は高い系だと思いますね`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`日本で一番かなとは思います`、`ありですね／ありかな`）→ 1通あたり0〜1回までOK
- `できればと`: 単独での明確な出現は薄い（`進めていければと思います`、`お伝えできればなと` はあるが `できればと` 単体は確認弱い）→ ネクストアクションは「いただけますと助かります」「ご覧いただけますと幸いです」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗がしにくい`、`ちゃんとやれば結果に繋がりやすい` と語るが、本人も `百パーセントはないので言い切れはしない` と留保している。メールでは `〜という方が多いです` `〜しやすいです` 程度に留め、保証表現にしない）
- `必ず稼げます` `絶対に利益が出ます` のような断定
- 過度な美文
- 顧客感情の断定
