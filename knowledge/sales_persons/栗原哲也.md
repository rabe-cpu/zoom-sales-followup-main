# 栗原 哲也さん

## 商談内で見えた特徴

- `じゃあ` / `じゃあ早速`（話題の切り替え）
- `一旦` / `逆に` / `ちなみに`（接続語）
- `かしこまりました` / `承知いたしました` / `承知しました`（受け）
- `〜できればと思います` / `〜していければなと思います`（柔らかい提案・依頼）
- `〜かと思います`（`見やすいかと思いますので`、`失礼かと思うので`、`わかりやすいかと思うので`）
- `〜かなと思って`（`やっていけそうかなと思って`）
- `お伺いさせていただく` / `ご案内させていただく`（丁寧なへりくだり）
- `ざっくばらんに` / `NG質問は一切ないので`（相手の緊張をほぐす言い回し）
- `よかった、よかった` / `一緒にぜひ頑張っていきましょう`（温度感・伴走）
- `お役に立てるお話ができればと思います`

## 一人称・距離感

- 一人称: 僕／僕ら／私／弊社
- 顧客への呼び方: `佐近さん` を基本に `〇〇さん` / `〇〇さま` 併用
- 自己開示（自分の経歴・失敗談）を先に出して距離を縮めるスタイル

## メール反映の定型

- `本日はお忙しい中、お時間をいただきありがとうございました`
- `〜のお話を伺う中で`
- `〜できればと思います`
- `わからない点や確認したいところが出てきましたら、気兼ねなくご連絡ください`
- `一緒に進めていければと思います`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（複数回：`見やすいかと思いますので` 等）→ 1通あたり0〜1回までOK、文末で多用しない
- `かなと`: あり（`やっていけそうかなと思って`）→ 1通0〜1回まで、冒頭の温度感・軽い提案で使う
- `できればと`: あり（`お伝えできればと思います`）→ ネクストアクションでは「と思います」「お送りいたします」で着地させ、途中で止めない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（発話に確認なし）
- 成果保証・断定（`皆さんやりたいとおっしゃる`、`誰でも売り上げ利益を上げやすい` は商談中の説明トーク。メールでは成果保証に聞こえるため使わない）
- 過度な美文
- 顧客感情・顧客の financial 状況の断定
