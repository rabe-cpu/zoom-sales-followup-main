# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（確認・受け止めで多用）
- `ぜひ`
- `〜していきたいなと思います`（提案・案内の導入）
- `一旦`（`じゃあ一旦ちょっと私の方で社内に`）
- `ちょっと`（やわらげの前置き）
- `ご安心ください`（不安対応：`そこはあのご安心ください`）
- `遠慮なく`（`遠慮なくですね、ご質問をご連絡いただければ`）
- `正直言うと` / `ぶっちゃけ`（口頭ではカジュアルに出るが、メールでは使わない）
- `〜という形になります` / `〜という形です`（手順・流れの締め）
- `〜かなと思います` / `〜かなとは思います`（やわらかい判断）
- `〜かと思います`（`森山さんとってもおすすめかと思います`）

## 一人称・距離感

- 一人称: 私／弊社（`私の方で`、`私が知る限り`、`弊社`）
- 顧客への呼び方: `〇〇さん`（商談では基本`さん`付け）

## メール反映の定型

- `今日はしっかりとご紹介していきたいなと思います`
- `そこはご安心ください`
- `追加のご質問などございましたら、遠慮なくご連絡いただければと思います`
- `一旦、私の方で社内に確認しておきます`
- `〇〇という形になります`
- 依頼着地: `ご連絡いただければと思います` / `ご確認いただけますと` / `お待ちください`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（複数回：`予算感にはあってくるかなと思います`、`問題ないかなとは思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`森山さんとってもおすすめかと思います`）→ 文末で多用はしない
- `できればと`: 明確な出現なし → ネクストアクションでは「ご連絡いただければと思います」「お送りいたします」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・収益保証に聞こえる断定（`必ず〇〇万円`、`絶対に回収できます`）
- 過度な美文
- 顧客感情の断定
