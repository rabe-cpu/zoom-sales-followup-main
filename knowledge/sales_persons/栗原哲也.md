# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（受け止め・確認の切り出し）
- `ありがとうございます`（相槌・お礼として非常に頻出。`丁寧にありがとうございます`）
- `確かに` / `確かに確かに`（顧客の指摘を肯定するときの受け）
- `おっしゃる通り` / `新田さんのおっしゃることはわかります`（顧客の論理を一度受け止める）
- `あの` / `えっと` / `まあ` / `一応`（説明前のクッション）
- `ちなみに` / `改めて` / `要するに`（話題の切り替え・言い換え）
- `しっかりと`（サポート・案内の強調）
- `ぜひぜひ`（次アクションの後押し）
- `折衷案` / `いい塩梅`（落としどころを示すときの表現）
- `〜という形になります` / `〜という形`（説明の着地）
- `〜なんですよ` / `〜なんですよね`（仕組みをかみ砕くときの語尾）

## 一人称・距離感

- 一人称: 私（`私も今までかれこれ`、`私が社内に交渉して`）、弊社、まれに 僕ら（`僕らはもう徹底的に`）
- 顧客への呼び方: `新田さん`（商談中は基本さん付け）、メールでは `新田さま`

## メール反映の定型

- `承知いたしました。〇〇については〜`（受け止めてから説明に入る）
- `おっしゃる通り、〇〇です`（顧客の見立てを肯定してから補足）
- `〇〇という形になります`（説明の着地）
- `しっかりと〇〇させていただきます`（サポートの約束）
- `折衷案として、まず〇〇から始める進め方もあります`（無理に上げず選択肢を置く）
- 締め: `引き続きよろしくお願いします` / `本日はありがとうございました`

## 余白表現の出現

- `かなと`: あり（`収益が出るんじゃないかなと思う`、`見ていただけると分かりやすいかなと`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`ご案内できればと思います`、`行っていければと思います`、`すり合わせできればと`）→ ネクストアクションや軽い提案で0〜1回までOK
- `見ていただけると`: あり（`半額とか四割ぐらい見ていただけると分かりやすい`）→ 資料・数字の案内で0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない（`〜と思います` で着地させる）

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `収益回収が確実なんじゃないですか`、`確実に上がっていく` と語る場面があるが、メールでは `〜という方が多いです`、`判断材料になります` 程度に留め、保証表現にしない）
- 審査・カード枠を断定する表現（`必ず通ります` などにしない。`ご確認いただく` 前提で書く）
- 過度な美文
- 顧客感情の断定
