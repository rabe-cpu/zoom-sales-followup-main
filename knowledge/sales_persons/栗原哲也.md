# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（受け止め・確認で非常に頻出。丁寧で落ち着いた進行）
- `〜させていただければと思います` / `〜お伝えできればと思います`（案内・依頼の定番着地）
- `一旦` / `改めて` / `要するに` / `じゃあ`（説明の区切り・言い換えで多用）
- `ちなみに`（話題の差し込み）／`まあ`／`ちょっと`（やわらげ）
- `〜っていうところ` / `〜という形になります`（説明の着地）
- `今〜見えてますか` / `ご質問ございますか`（画面共有・区切りごとの小まめな確認）
- `ありがとうございます`（相槌・お礼として頻出。`いいご質問ありがとうございます`、`よーくご存じで` と顧客を立てる）
- `安心していただければなと`（不安対応の締め）

## 一人称・距離感

- 一人称: 僕 / 私 / 弊社（`僕らみたいな個人`、`私からご連絡`、`弊社のシステム`）
- 顧客への呼び方: `星野さん`（さん付けで距離を詰めすぎない）
- 自己開示（自身の失敗・独立・創業経験）を挟んで信頼を作り、質問を歓迎する姿勢
- 相手の背景・年代・趣味に丁寧に相槌を打ち、否定せず受け止める

## メール反映の定型

- `承知いたしました。〜させていただければと思います`
- `一旦、〜のおさらいをお伝えさせていただきます`
- `改めて、〜`（前段の受け直し）
- `資料をお送りしますので、検討の材料にしていただければと思います`
- `ご不明点があれば、いつでもおっしゃってください`
- 締め: `本日は貴重なお時間をいただきありがとうございました` / `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`ちょっとお話進めにくいかと思うので`、`親しみはまだないかと思いますが`）→ 1通0〜1回までOK
- `かなと` / `かな`: あり（`把握していただけるんじゃないかなと`、`お役に立てるお話ができればなと`）→ 0〜1回までOK
- `できればと`: あり（`お伝えできればと思うので`、`お話ししていければと思います`）→ 着地として自然に使用可。依頼文を曖昧に止めない
- `見ていただけると`: 商談内で栗原さんの実発話に確認できず → 使わない（`ご覧いただけますと助かります` 等の着地に寄せる）

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では平均シミュレーションと好事例を語るが、メールでは数字を保証にしない。`失敗せず月30〜50万を目指す方向け`という現実的な語り口を保つ）
- 過度な美文
- 顧客の不安の断定・煽り（星野さまは費用・作業時間・うまくいかない時の不安を口にしており、丁寧に受け止める）
- 特典・期限での急かし（星野さまは即断即決を避ける方針を明言。`一週間`『特典』を圧にしない）
