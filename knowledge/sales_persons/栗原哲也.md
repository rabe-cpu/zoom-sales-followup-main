# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（相槌・区切りで多用）
- `かしこまりました`
- `ちなみに`（話題転換・ヒアリングの入り）
- `しっかり` / `しっかりご案内` / `しっかりご説明`
- `〜と思いますけれど` / `〜と思うので` / `〜と思います`
- `〜できればなと思います` / `お伝えできればなと`
- `〜じゃないかなと`（柔らかい判断。限定的）
- `そうですよね` / `確かに確かに`（共感の受け）
- `はいはいはい`（傾聴の相槌）
- 事業部の古株として、仕組み・戦略を順序立てて説明するスタイル

## 一人称・距離感

- 一人称: 私／僕／弊社（`私、実家が` と `僕らの売り方` を併用）
- 顧客への呼び方: `〇〇さん`

## メール反映の定型

- `この後メールをお送りします`
- `しっかりご案内できればと思います`
- `ご状況を確認させていただきます`
- `取り組めそうなプランを改めてご案内できればと`
- `ちなみに〜`（次の確認・質問の入り）
- 締め: `よろしくお願いします` / `失礼いたします`

## 余白表現の出現

- `かなと` / `じゃないかなと`: 限定的に出現 → 1通あたり0〜1回までOK
- `かと`: `失礼かと思うので`、`同じだったかと思ですけど` の形で出現 → 文末で多用しない
- `できればと`: あり → ネクストアクションでは「ご案内できればと思います」「お送りします」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `必ず儲かります` / `誰でも儲かります`（栗原さんは平均データとして提示し、断定していない）
- 成果保証に聞こえる表現
- 過度な美文
- 顧客感情の断定
