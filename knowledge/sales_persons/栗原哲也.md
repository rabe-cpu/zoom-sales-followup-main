# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました` / `承知いたしました`（依頼受け・区切りで頻出）
- `よかったです`（相槌・安心の受け。非常に頻出）
- `〜させていただく`（案内・説明の基本形。`お伝えをさせていただく`、`ご案内をさせていただく`）
- `〜いただければと思います` / `〜いただけますと幸いです`（依頼の定番着地。`確認していただけますと幸いです`、`ご注意していただけますと幸いです`）
- `一応` / `じゃあ` / `改めて` / `念のため` / `漏れなく`（進行のつなぎ）
- `〜になります` / `〜という形`（説明の着地）
- `ご安心ください`（不安の受け）
- `祈ってます`（審査・成果を応援する温度。`審査が無事に通るように私自身も祈ってます`）

## 一人称・距離感

- 一人称: 私（`私自身も祈ってます`）、弊社
- 顧客への呼び方: `小田嶋さん` / `小田嶋様`（※商談音声では「小田島」「浦島」等と誤読が混ざるが、メールでは必ず正しい漢字「小田嶋様」で統一する）
- 応援型。`頭の回転が早い`、`飲み込みが早そう`、`うまくいきそう` と顧客を前向きに立てる。決めた顧客には次の手続きを一つずつ丁寧に案内する

## メール反映の定型

- `かしこまりました。ありがとうございます`
- `一応お伝えをさせていただくと、〜という形になります`
- `〜を確認していただけますと幸いです`
- `ご不明点ございますか` → メールでは `ご不明点があれば、いつでもおっしゃってください`
- `漏れなくご確認いただけますと幸いです`
- 締め・応援: `無事に進むよう、私も願っております`（商談の「祈ってます」を書き言葉に寄せる）

## 余白表現の出現

- `かと`: あり（`法人も設立する必要が出てくるかと思うので`）→ 1通0〜1回までOK
- `かなと` / `かな`: 明確な多用は確認なし → メールで足さない
- `できればと`: 確認なし → 依頼は `いただけますと幸いです` の着地に寄せる
- `見ていただけると`: `確認していただけますと幸いです` の形なら自然に使用可

## 禁止候補

- `伝わってまいりました`（発話に確認なし）
- 審査の通過保証・成果保証（`必ず通ります`／`必ず稼げます` は禁止。商談では貯蓄・収入を「多めに書くと通りやすい」と口頭で触れているが、メールには書かない）
- 過度な美文
- 顧客の不安の断定・煽り
