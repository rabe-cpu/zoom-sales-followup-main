# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました` / `承知いたしました`（受けの定番。繰り返し使う）
- `〜させていただいて` / `〜させていただきます`（丁寧に進める時の基本形）
- `まず` / `じゃあ` / `えっと` / `一応`（段取りを刻む接続）
- `ぜひ`（相談・次アクションの後押し。`ぜひご相談いただければ`、`ぜひ一緒に頑張っていければ`）
- `〜いただければと思います`（依頼の着地。多用）
- `ですかね` / `でしょうか`（やわらかい確認。`お持ちですかね`、`届いてましたかね`）
- `本当に` / `素晴らしい`（共感・相槌を厚めに置く）
- `全力でサポート` / `失敗しにくい`（安心づくりの言い回し。※メールでは成果保証にしない）
- 顧客の背景（老後・将来の不安）を汲んで励ます一言を添える

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らはもう本当に`、`僕の方で`）、改まると 私 / 弊社
- 顧客への呼び方: `〇〇さん` / 改まると `〇〇様`（商談中は基本さん付け）

## メール反映の定型

- `まず〇〇をご確認いただければと思います`
- `かしこまりました。じゃあ〇〇という形になります`（受けてから次の案内へ）
- `ぜひご相談いただければと思います`（相談導線）
- `遠慮なくご連絡ください`（サポート導線）
- `ご安心いただければなと思います`（不安の受け止め）
- 締め: `よろしくお願いいたします` / `何卒よろしくお願いします`

## 余白表現の出現

- `かと`: あり（`負荷がかかってるかと思いますが`、`やってる方もいらっしゃるかと`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`違う方法で試していただくのがいいかなと思います`）→ 1通あたり0〜1回までOK
- `見ていただければと`: あり（`後ほど見ていただければと思います`）→ ネクストアクションで自然なら少量OK
- `できればと`: 明確な出現なし → ネクストアクションは「いただければと思います」「ご連絡ください」で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `失敗しにくい`、`うまくいく方が多い`、`辞めるぐらいの収入は増やせる` と語る場面があるが、メールでは `〜という方が多いです` 程度に留め、収益保証・審査通過保証にしない）
- 過度な美文
- 顧客感情の断定
