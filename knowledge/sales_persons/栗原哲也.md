# 栗原 哲也さん

## 商談内で見えた特徴

- `そうですよね`（顧客の発言への強い共感・受け止めで多用）
- `〜という形になってきます` / `〜という形です`（説明の着地）
- `ご安心いただければと思います` / `安心していただければと思います`（不安をほどく定番）
- `〜いただければと思います`（依頼・お願いの柔らかい着地）
- `一緒に頑張っていければと思います` / `一緒に頑張っていきましょう`（伴走・クロージングの締め）
- `ぜひ`（行動を促すときの後押し）
- `素晴らしいですね` / `素晴らしいご決断だと思います`（肯定・承認）
- `ありがとうございます`（相槌・お礼で頻出）
- `かしこまりました`（受諾の返し）

## 一人称・距離感

- 一人称: 弊社 / 私（`弊社としては`、`私がご案内した方`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 伴走型。顧客の不安を否定せず「そうですよね」で受けてから、安心材料とサポート体制に接続する。

## メール反映の定型

- `〜という形になってきます`（流れの説明）
- `ご安心いただければと思います`（不安への受け止め）
- `〜いただければと思います`（次アクションの柔らかい依頼）
- `一緒に頑張っていければと思います`（締めの伴走表現）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: 明確な出現は確認できず → 使わない
- `かと`: 明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「ご確認いただけますと助かります」「ご連絡いただければと思います」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし。※商談では「気持ちが伝わってきた」と話す場面はあるが、メールのAI臭い定型敬語としては使わない）
- 成果保証・断定（商談では `8割以上は成果を出している` `私が案内した方はうまくいく方が多い` と語る場面があるが、メールでは保証表現にせず `取り組む時間を確保された方が成果につながりやすいです` 程度に留める）
- 収益保証、審査通過の断定
- 過度な美文、顧客感情の断定
