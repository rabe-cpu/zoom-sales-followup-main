# 栗原 哲也さん

## 商談内で見えた特徴

- `じゃあ` / `一旦` / `改めて` で場面を切り替える
- `ちなみに` / `逆に` / `要は` / `要するに` で論点を整理する
- `かしこまりました` / `承知いたしました` を確認の受けで多用
- `〜させていただければと思います` / `〜いただければと思います` の依頼形
- `ご確認ください` / `お送りしますので` で着地
- 自己開示が厚い（創業メンバー・独立の失敗・借金・立て直しの経験を自分から話す）
- 相手の状況を一度受け止めてから、顧客側のメリットに言い換えて返す
- `決して急かすってわけではないんですけれども` のように、押しつけを避ける前置きを入れる

## 一人称・距離感

- 一人称: 僕ら（会社・事業の主語）／私（自己紹介・所感）／弊社
- 顧客への呼び方: `〇〇さん` / `〇〇さま` 併用（本文の宛名は `さま`）

## メール反映の定型

- `一旦、この後、資料をお送りさせていただきますね`
- `〜させていただければと思います`
- `ご確認いただければと思います`
- `改めてご連絡させていただきますね`
- `決して急かすわけではないのですが`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`合ってるんじゃないかなとは思います`）→ 1通あたり0〜1回までOK
- `かと`: 限定的に出現（`ご理解いただけるかと`）→ 文末で多用しない
- `できればと`: `お役に立てるお話ができれば、と。` の形で出現 → ネクストアクションでは「思います」「お送りします」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 過度な美文
- 顧客感情の断定
- 成果保証・回収保証に聞こえる断定（`絶対`、`必ず稼げます` など）
