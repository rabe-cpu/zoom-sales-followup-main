# 栗原 哲也さん

## 商談内で見えた特徴

- `かしこまりました` / `承知いたしました`（受け止め・区切りで非常に頻出）
- `〜かと思うので` / `〜かと思いますけれども` / `〜できるかと`（`かと` を実発話で複数回使用。話の進め方・見立てで自然に出る）
- `〜させていただく`（案内・提案の丁寧な着地）
- `ちなみに` / `一応` / `なんで（＝だから）` / `じゃあ`（接続・切り替え）
- `〜という形になってます` / `〜というイメージです` / `〜かなというふうに思ってます`（説明・見立ての締め）
- `ぜひ` / `ぜひぜひぜひ`（前向きな後押し）
- `ありがとうございます` / `嬉しいです` / `よかったよかった`（相槌・お礼として頻出。顧客の行動力を素直に称える）
- カジュアルで温かい相槌: `そっかそっか` / `いやあ、すごい` / `なるほど`

## 一人称・距離感

- 一人称: 僕 / 私 / 僕ら（`僕らのビジネス`、`私の方から`）、弊社
- 顧客への呼び方: `野口さん`（さん付け中心。様よりも距離が近い自然体）
- 自身も個人事業でネットショップを運営している当事者性を出し、「同じ立場から」話すスタイル
- 顧客の経歴・行動力をよく観察し、具体的に言葉にして受け止める（`行動力がある方ですね`、`理想的な早期退職`）

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `〜させていただければと思います`
- `資料をお送りしますので、お時間のあるときにご覧いただけますと助かります`
- `ご不明点がございましたら、いつでもご連絡ください`
- `また改めてご連絡させていただきます`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`進めにくいかと思うので`、`失礼かと思うので`、`お役に立てるお話ができるかと`、`判断材料になるかと思うので`）→ 1通0〜1回までOK
- `かなと` / `かな`: あり（`向いてるという方が多いかな`、`おすすめになるかなと思います`）→ 0〜1回までOK。依頼文の着地を曖昧にしない
- `できればと`: 明確な発話は未確認 → 使うなら `〜いただけますと助かります` の着地に寄せる
- `見ていただけると`: `ご覧いただけますと助かります` の形なら自然

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `固く狙える`、`ちゃんとやればうまくいく` と語るが、メールでは数字や成果を保証にしない）
- 返金保証を「損しない」と言い切る断定表現（メールでは資料に基づく判断材料として書く）
- 過度な美文・過度な安心訴求
- 顧客の不安・感情の断定や煽り（野口さまは「うまくいかないケースもあるのでは」と不安を口にしており、丁寧に受け止める）
- 特典期限で急かす表現（商談で `急かすわけではない` と本人が明言。メールでも急かさない）
