# 栗原 哲也さん

## 商談内で見えた特徴

- `はいはい` / `はいはいはい`（相槌。顧客の話を受け止めるときに非常に頻出）
- `そうですよね`（共感の相槌。顧客の迷いや大変さを受け止める場面で多用）
- `本当に`（強調。`本当に思うので`、`本当に清水さんが取り組めれれば`）
- `要は`（要点を言い換えるときの接続。`要は何を売るかというよりかは数が`）
- `ちなみに`（話題を差し込むときの前置き。`ちなみに、どれぐらいのスケジュール`）
- `いずれにせよ`（論点を締めるときの接続）
- `もちろん`（受け止めの肯定。`もちろん大丈夫です`）
- `〜んですよ`（説明の着地。`少ないんですよ`、`データは社内で取れてるので`）
- `〜と思うんですよ` / `〜と思います`（見立てを述べる締め）
- `〜っていう計算なんですね` / `〜っていうことですね`（数字・仕組みの言い換え）
- `承知いたしました`（受諾の返答）

## 一人称・距離感

- 一人称: 僕ら / 私（`僕らのビジネス`、`僕らのシステム`、`私の方からご連絡`）。改まると 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。文字起こしでは同音の別表記になりやすいので、メールでは正式表記の氏名で宛名を作る）

## メール反映の定型

- `〇〇かなと思います`（見立ての柔らかい着地）
- `要は〇〇ということですね`（要点の言い換え）
- `いずれにせよ〇〇は必要になってくると思います`（前提を整理する）
- `もちろん大丈夫です`（相談・依頼への受け止め）
- `遠慮なくご連絡いただければと`（相談導線を残す締め）
- 締め: `よろしくお願いいたします` / `ありがとうございました`

## 余白表現の出現

- `かと`: あり（`話あったかと思うんですけど`）→ 1通あたり0〜1回までOK
- `かなと` / `かなぁと`: あり（`かなとは思います`、`センターかなぁと思います`）→ 1通あたり0〜1回までOK
- `いただければと`: あり（`遠慮なくご連絡いただければと`）→ 相談導線の締めで少量OK
- `できればと`: 出現なし → 使わない。ネクストアクションは「ご連絡いただけますと」「確認いただけますと助かります」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `出るなっていう自信はある`、`赤字になることはない` と語る場面があるが、メールでは `〜という方が多いです` `〜という計算です` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 家族の反対を障害・敵として書く言い方（本人は奥様の心配を `すごく分かる` と受け止めている。メールでも同じ姿勢を保つ）
