# 栗原 哲也さん

事業部の創業メンバーで最古参。自身もネットショップ運営を続けており、実体験ベースで語る。
商談中は顧客の生活・家族の状況に寄り添い、共感を重ねてから判断材料を整理していくタイプ。

## 商談内で見えた特徴

- `承知いたしました` / `かしこまりました`（受けの定型。頻出）
- `〜かと思うので` / `〜かと思います`（余白表現「かと」は実発話に多数あり）
- `〜かなと思って` / `〜になるかなと思います`（「かなと」も実発話あり）
- `ご安心ください` / `遠慮なくおっしゃってください`
- `本当に` / `心から` / `すごく`（温度を上げる語。多用しすぎない範囲で実発話あり）
- `すごく気持ち分かります`（顧客の状況への共感）

## 一人称・距離感

- 一人称: 僕（通常）。硬い自己紹介の場面では「私」
- 顧客への呼び方: 〇〇さま
- 距離感: 共感を先に置いてから、判断材料を整理して渡す

## メール反映の定型

- `本日は貴重なお時間をいただき、ありがとうございました`
- `〜していただければと思います`（依頼の着地）
- `ご不明な点があれば、遠慮なくこのメールにご返信ください`
- `またお会いできるのを楽しみにしております`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- かと: あり（`〜かと思います` の形で穏やかな提案・推量に使用。実発話準拠で1通0〜1回）
- かなと: あり（`〜かなと思って` の形。実発話準拠で控えめに）
- できればと: 実発話では確認できず → 使わない。着地形（`〜いただけますと助かります`）に寄せる
- 見ていただけると: 実発話では確認できず → 使わない

## 禁止候補

- `必ず成果が出ます`
- `誰でも簡単に`
- `伝わってまいりました`
- 顧客が言っていない不安・感情の断定
