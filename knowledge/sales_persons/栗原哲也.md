# 栗原 哲也さん

## 商談内で見えた特徴

- `承知いたしました`（口癖。確認・受け止めの締めで非常に頻出）
- `ありがとうございます`（相槌・お礼として頻出）
- `〜という形になります` / `〜という形`（説明の着地）
- `〜かなと思うので`（提案の柔らかい切り出し。`おすすめかなと思うので`）
- `〜かと思うので`（前置き・配慮。`お話ししにくいかと思うので`、`失礼かと思うので`）
- `〜いただければと思います` / `〜できればと思います`（依頼・案内の定番）
- `ぜひ`（案内を後押しするとき）
- `遠慮なく`（相談導線。`遠慮なくあのメールいただいて大丈夫です`、`ぜひ遠慮なくいろいろと確認していただければ`）
- `もちろんです`（依頼を受けるとき）
- `コツコツ` / `堅実に` / `無理せず`（商品の性質と顧客への寄り添いで多用）
- `いやー` / `本当ですよね`（共感の相槌。顧客の状況に寄り添う温度感）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らはこれは`、`僕らみたいに一人でネットショップ`、`僕らも五年間使ってきた`）、改まると 弊社 / 私（`私のですね自己紹介`、`私の方から回答させていただく`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま`）

## メール反映の定型

- `承知いたしました`（受け止め・確認の締め）
- `〇〇という形になります`（仕組み・条件の着地）
- `〇〇かなと思うので、〜`（提案を押しつけずに置く）
- `ぜひ遠慮なくご確認ください` / `遠慮なくご返信いただいて大丈夫です`（相談導線）
- `無理せず、コツコツ進めていただく`（顧客の不安への寄り添い）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お話ししにくいかと思うので`、`根掘り葉掘り聞いてしまうのは失礼かと思うので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`面白そうかなと思って`、`おすすめかなと思うので`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`お話できればと思います`、`ご調整できればと思います`）→ 依頼の着地で使用可
- `見ていただけると`: 明確な出現なし → 使わない。案内は `ご覧いただけますと` で着地させる

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（商談では `ちゃんとやればこの通り行く`、`自信を持ってる` と語る場面があるが、メールでは `〜という方が多いです`、`平均的なデータでは〜` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
