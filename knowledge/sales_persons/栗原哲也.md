# 栗原 哲也さん

## 商談内で見えた特徴

- `まあ` / `で、` / `もう` / `ね。`（相手の話を受けながら自然につなぐ）
- `一旦`（`一旦もう頭金なしでやるか`のように、いったん区切るときの接続）
- `じゃあ`（提案・行動の切り出し）
- `実は`（意外な事実・価値を出すときの前置き。`実は日米のアマゾン間でこういう商品がたくさんある`）
- `要は` / `ある意味`（かみ砕き・言い換え）
- `〜という形なんですね` / `〜という形になります` / `〜になってます`（説明の着地）
- `かしこまりました` / `承知いたしました`（依頼・確認を受けたときの返し。頻出）
- `〜させていただきます` / `〜させていただく`（案内・行動の丁寧形）
- `もちろんです` / `もちろん大丈夫です`（不安への即応）
- `さすがですね` / `すごい`（顧客の動きへの素直な相槌）

## 一人称・距離感

- 一人称: 僕 / 僕ら（`僕らのシステム`、`僕らの戦略`、`僕らどうすればいいか`）、改まると 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 顧客を具体的に褒めて安心を作る（`論理的で頭の回転がいい`、`この方うまくいきそうだな`）。ただし本人の実際の言い方は所感どまりで、成果保証にはしていない（`平均値を行くと思います`）。

## メール反映の定型

- `〜という形になります` / `〜という形なんですね`（説明の締め）
- `〜かなと思います` / `〜かと思います`（やわらかい提案・見立て）
- `〜していただければと思います`（ネクストアクションの着地）
- `〜いただけると（いいかと思います）`（軽い依頼）
- `かしこまりました` / `承知いたしました`（受け）
- `ぜひぜひ遠慮なく`（サポート・相談への誘導）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`向いてるプランかなと`、`ご判断していただけるといいかなと`、`個人的にはお勧めです`の前後）→ 1通あたり0〜1回までOK
- `かと`: あり（`いらっしゃるかと思ので`、`途中まででのお話でいらっしゃったかと思う`）→ 1通あたり0〜1回までOK。依頼文の着地は曖昧にしない
- `できればと`: 単独の明確な出現なし。代わりに `〜ていければと思います`（`進めていければと`、`ご案内させていただければと`）を使う → ネクストアクションは「〜していただければと思います」で着地
- `見ていただけると`: 出現なし。代わりに `ご覧いただければと思います` / `確認していただければと思います` → こちらで着地

## 禁止候補

- `伝わってまいりました`（栗原さんの発話に確認なし）
- 成果保証・断定（`うまくいきそう`、`自信持ってもらって大丈夫`のような励ましは本人も所感どまりにしている。メールでは `〜という方が多いです` `〜しやすいです` 程度に留め、`必ず`『稼げます』は使わない）
- 過度な美文
- 顧客感情の断定
