# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として極めて頻出。ほぼ全ターンで受ける）
- `〜かと思います` / `間違いないかと思います` / `スムーズかと思います`（着地の定番。「かと」は実発話に多数あり）
- `〜と思いますので` / `〜していただけたらと思います`（依頼・案内の柔らかい着地）
- `ご安心ください` / `大丈夫ですので` / `全然問題ないと思います`（不安のほどき方）
- `お手数ですけれども` / `お手数なんですけれども`（依頼の前置き）
- `一旦` / `一応`（区切り・確認の接続）
- `正直`（かみ砕くときの前置き。「正直もう佐野さんのペースで大丈夫」）
- `すいません` / `申し訳ありません`（見落とし・日程変更のお詫びを素直に入れる）
- `素晴らしいですね` / `バッチリですね`（相手の対応をこまめに承認）

## 一人称・距離感

- 一人称: 私（`私の方で`、`私から返送お願いします`）
- 顧客への呼び方: `〇〇さん`（商談中）。メールでは `〇〇さま`
- 距離感: 丁寧・低姿勢で、相手のできた行動を細かく褒めて安心させる寄り添い型

## メール反映の定型

- お礼を厚めに、そして重ねる（`お時間をいただきありがとうございました` を冒頭と結びで）
- `〜していただけたらと思います`（次アクションの依頼）
- `ご安心ください` / `遠慮なく頼っていただければ大丈夫です`（不安への受け止め）
- `お手数ですけれども、よろしくお願いいたします`（依頼の締め）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`（`問題ないかと思います`、`間違いないかと思います`）→ 実発話にあり。メールで0〜1回まで可。
- `〜たらと思います`（`お願いできたらと思います`）→ 実発話にあり。依頼の柔らかい着地に使用可。
- 依頼文を途中で止める用法（`〜と。`）は実発話では明確でないため、メールでは着地形（`〜いただけますと助かります`）に寄せる。

## 禁止・注意候補

- 成果保証・審査保証に聞こえる断定（審査は「承認が出れば」の条件付きに留める）
- 承認前に頭金・振込を確定事項のように書かない（`承認が出ましたら` の条件付き）
