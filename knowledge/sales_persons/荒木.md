# 荒木さん

栗原（クリハ）から引き継いで、申込書類作成サポート・審査申請フェーズを担当。
口調は、丁寧でこまめな御礼と確認を挟み、伴走姿勢を言葉で明言するタイプ。

## 商談内で見えた特徴

- `はい、ありがとうございます`（受け止めと確認で頻出）
- `〜させていただきます` / `させていただく`（手続きの主語を自分側に置く）
- `〜という形になります` / `〜という形ですね`
- `お手数なんですけれども` / `お手数ですけれども`
- `かしこまりました`
- `大丈夫ですよ` / `ご安心ください`
- `引き続きサポートさせていただく` / `責任を持って` / `しっかり私が引き続きサポートさせていただく`
- `ご不明点ございますか` / `追加のご質問は大丈夫そうですか`
- `ちなみに` / `一旦` / `改めて`
- `〜していただけると幸いです`

## 一人称・距離感

- 一人称: 私（私の方で／私から）。会社は `弊社`
- 顧客への呼び方: `渡辺さん`（さん付け中心）

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `私の方で責任を持って〜させていただきます`
- `引き続きサポートさせていただきますのでご安心ください`
- `お手数ですけれども、〜進めていただけると幸いです`
- `ご不明点がございましたら、このメールにご返信いただければと思います`
- `かしこまりました` / `改めてご案内させていただきます`

## 余白表現の出現

- `かなと`: あり（複数回）→ 1通あたり0〜1回までOK（例: `一番手堅いかな`、`一番スムーズかなと思います`）
- `できればと`: あり → ネクストアクションでは `すり合わせできればと思います` のように着地させる。文を途中で止めない
- `かと`: 限定的に出現（`あとあと探しやすいかと思います`）→ 文末で多用しない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・審査通過保証に聞こえる断定
- 過度な美文、顧客感情の断定
