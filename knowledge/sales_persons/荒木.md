# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます` / `教えていただいてありがとうございます`（相手の話を受けるお礼として非常に頻出）
- `そうですよね` / `もちろんですよ` / `なるほど`（共感相槌が多い。まず受け止める）
- `〜させていただきたい` / `〜させていただく`（案内・伴走の基本形）
- `〜っていうところ`（論点を置く口語のつなぎ）
- `本当に` / `やっぱり` / `ちょっと` / `なんか`（口語の温度）
- `素晴らしいですね` / `すごいですね`（顧客の姿勢を立てる）
- `引き続きよろしくお願いいたします` / `応援しております`（締めの定番）

## 一人称・距離感

- 一人称: 私
- 顧客への呼び方: `伊藤さん`
- 伴走・非強引型。`私も焦っているわけではなく`、`無理に押して契約いただいて後で困る形は望んでいない` と、決断を急かさず相手のタイミングを最優先する。相手の家族や目的をよく聞き、受け止めてから次の選択肢を並べる

## メール反映の定型

- `本日もお時間をいただき、ありがとうございました`
- `〜のお気持ち、あらためて伺えてよかったです`
- `急いで決めていただく必要はありませんので、〜`
- `気になる点が出てきたタイミングで、メールでもお電話でも構いませんのでご連絡ください`
- 締め: `引き続き応援しておりますので、よろしくお願いいたします`

## 余白表現の出現

- `かなと` / `かな`: あり（`そっちの方が大事かなと思ってる`、`厳しくなってきちゃうのかな`）→ 1通0〜1回までOK
- `かと`: 明確な多用は確認なし → 足すなら1回まで
- `できればと`: 確認なし → 依頼は `いただけますと` の着地に寄せる
- `見ていただけると`: `見ていただければ` の形で自然に使用可

## 禁止候補

- `伝わってまいりました`（発話に確認なし）
- 成果保証・審査保証（商談でも `100%うまくいくとは言えない` と明言している。メールでも保証表現は書かない）
- 顧客の不安を軽く扱う表現、急かす表現
- 顧客の家庭事情（ご家族の障害など機微情報）を本文に書かない。想いは `ご家族の将来を思って` のように配慮して抽象化する
