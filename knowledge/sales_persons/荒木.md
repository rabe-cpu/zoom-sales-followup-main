# NEXT 荒木さん

## 商談内で見えた特徴

- `ま` / `まあ`（文頭・言いよどみで非常に頻出。クッションとして多用）
- `要は`（要点を言い換えるときの接続）
- `結局は` / `結局`（話をまとめるときの接続）
- `ある意味`（やわらかく言い切るときの前置き）
- `ちなみに`（話題を軽く足すとき）
- `なので`（理由から結論へつなぐ）
- `〜という形です` / `〜という形になります`（締めの言い回し）
- `〜というところ(です)`（説明の着地）
- `〜みたいな`（例示の着地）
- `ありがとうございます`（相槌・お礼として極めて頻出。顧客の発話ごとに挟む）
- `教えていただいてありがとうございます` / `お聞きできてよかったです`（ヒアリング後のお礼）

## 一人称・距離感

- 一人称: 弊社 / 私たち / 私（`弊社のシステム`、`私たちのシステムを使う強み`、`私の方で`）
- 顧客への呼び方: `〇〇さん`（商談中はさん付け）
- 低姿勢・やわらかめ。`かしこまりました`、`とんでもないです`、`お忙しい中ありがとうございます` を自然に使う

## メール反映の定型

- `ま、〇〇というところですね`（説明の着地）
- `要は〇〇という形です`
- `結論、〇〇です`（要点を先に出すときの切り出し。ただし断定しすぎない）
- `ある意味〇〇です`（やわらかい言い切り）
- `ご安心ください` / `結構シンプルに考えていただいて大丈夫です`（不安への受け止め）
- 確認・依頼: `〜してもよろしいですか` / `もし可能であれば、〜していただくことって可能ですかね`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`お話ししやすくなるかなと`、`楽かなって思い`）→ 1通あたり0〜1回までOK
- `〜ればと`: あり（`お伝えできればと思います`、`やり取りさせていただければと思いますので`、`サポートできればと思います`）→ ネクストアクション・相談導線で自然に使える
- `〜たらと` / `〜たいなと`: あり（`作れたらと思います`、`お礼を伝えたいなと`）→ 提案・申し出でやわらかく使える
- `かと`: 単独での明確な出現は確認できず → 単独では使わない
- `できればと`: 単独の明確な出現は確認できず → 依頼文は「いただけますと助かります」「ご連絡いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `絶対10%返ってくる`、`負けなし`、`数うち当たる` のように強い言い切りが出る場面がある。メールでは `〜という方が多いです` / `〜という仕組みです` 程度に留め、収益保証・審査通過保証・成果保証にしない）
- `必ず成果が出ます` / `安心して稼げます` / `誰でも簡単に`
- 過度な美文
- 顧客感情の断定
- 顧客が話していない将来像の盛り過ぎ
