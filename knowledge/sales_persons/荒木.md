# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。顧客の発言をいったん受けてから話を進める）
- `はい、ありがとうございます`（区切りの相槌）
- `おっしゃる通りですね`（顧客の理解に同意するときの定番）
- `〜させていただきます` / `ご案内させていただきます` / `お伝えさせていただきます`（丁寧な申し出）
- `〜していただければと思います` / `〜していただけると`（依頼のやわらかい着地）
- `〜と思っております` / `〜かなと思います` / `〜かなっていうところ`（見立てを述べるとき）
- `ご安心ください`（不安をほどくとき。`今日この場で決めなくて大丈夫です。ご安心ください`）
- `結構`（強調の副詞として多用。`結構大事`、`結構重要`、`結構いろんな`）
- `〜っていうところ` / `〜っていう形`（説明の着地）
- `一旦` / `ちょっと`（話題の区切り・やわらげ）
- 顧客を具体的に褒める（`経営の目線でも素晴らしいと思います`、`理解力がすごく早い印象`）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社
- 顧客への呼び方: `〇〇さま`（メールでは「さま」、商談中の口頭では「さん」寄り）
- 距離感: 相手の事業判断を尊重し、決定を急がせない。`今日この場で導入するしないは決められないと思いますので、ご安心ください` のように主導権を顧客に残す

## メール反映の定型

- `本日はお忙しい中、ありがとうございました`（お礼の切り出し）
- `〜のところをご案内させていただきました`（商談で扱った論点の回収）
- `〜していただければと思います`（依頼の着地）
- `ご安心ください` / `いつでもご連絡いただけたらと思います`（安心導線）
- `おっしゃる通り` + 顧客の言葉を受け止めてから説明へ進む
- 締め: `体調に気をつけてお過ごしください` / `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`程よい人数かなと思います`、`サポートかなっていうところ`）→ 1通あたり0〜1回までOK。見立て・軽い提案でのみ使う
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: この商談では確認できず → ネクストアクションは「ご連絡いただけたらと思います」「ご確認いただけますと助かります」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- 成果保証・断定（荒木さんは `アマゾンが倒産しない限り` `規約変更しない限り` のように条件付きで話す。メールでは `〜という方が多いです` 程度に留め、収益保証・成果保証にしない）
- `伝わってまいりました`（発話に確認なし）
- 過度な美文・冗長な情緒表現
- 顧客感情の断定（`〜と感じていらっしゃる` の断定は避け、`〜とおっしゃっていました` の事実ベースに寄せる）
