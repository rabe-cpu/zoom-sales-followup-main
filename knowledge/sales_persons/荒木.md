# 荒木さん

## 商談内で見えた特徴

- `かしこまりました`（承り・区切りの定番。複数回）
- `ありがとうございます`（相槌・お礼として非常に頻出。丁寧で柔らかい）
- `一応`（`一応もう一回`、`一応栗原から`、`一応今日何時かわかんないんですけど`。やわらかい前置き）
- `一旦`（`一旦置いておいて`、`一旦クリハラとお話しした方が`）
- `逆に`（`逆に船橋さんなんですけれども`、`逆に絶対稼げますよっていうところは詐欺なので`）
- `ちなみに`（`ちなみに明日だと`。日程・条件を足すとき）
- `〜と思うんですよ` / `〜と思いますね`（見立てを伝える着地）
- `ご安心いただきたいんですね` / `ご安心ください`（不安をほどく定番）
- `無理に〜するつもりは全くない`（押し付けない姿勢を言葉にする。`無理に契約に促すつもりは全くない`）
- `〜じゃないですか`（会話的な確認）
- `申し訳ない` / `すいません`（相手の時間・手間への気づかい）

## 一人称・距離感

- 一人称: 私 / 私の方で（`私の方からも`、`私も`）、組織は 弊社 / 私たち
- 顧客への呼び方: `〇〇さま` / `〇〇さん`（手続き面談では丁寧に`さま`寄り）
- 社内の担当者は呼び捨てで言及（`栗原`、`森田`）。メールでは`栗原`など姓＋敬称なしの社内呼称は顧客向けには`栗原より`程度にとどめる

## メール反映の定型

- `かしこまりました`（承りの区切り。多用しすぎない）
- `ご安心いただきたいんですね` → メールでは `どうぞご安心ください`
- `無理にこのまま進めていただくつもりは全くございません`（押し付けない姿勢）
- `一応〇〇させていただきます`（やわらかい前置き）
- `一旦〇〇していただいた方が良いと思っております`（整理して戻す）
- 締め: `引き続きどうぞよろしくお願いいたします`
- お礼は厚め・誠実に（時間と手間への気づかいを言葉にする）

## 余白表現の出現

- `かと`: 発話に明確な出現なし → 使わない（ゼロ）
- `かなと`: 発話に明確な出現なし → 使わない（ゼロ）
- `できればと`: 出現なし → ネクストアクションは `いただけますと幸いです` `ご連絡を差し上げます` で着地させる
- `見ていただけると`: 出現なし → 使わない。`ご覧いただけますと幸いです` で着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証（本人は商談で明確に `絶対稼げますよっていうのは詐欺なので言わない` と線引きしている。メールでも保証表現は絶対に使わない）
- 顧客感情の断定（`不安ですよね` と受け止める場面はあるが、断定ではなく受け止めにとどめる）
- 過度な美文・AIっぽい敬語
- 社内呼称・社内事情（`詐欺`、`貸し倒れ`、`信販会社`などの社内説明語）を顧客メールにそのまま出さない
