# 荒木さん

> 初回登録。抽出元は「お申込後サポート面談（契約内容確認・電子署名・今後の進め方案内）」1本のみ。
> セールス初回相談ではなく、申込後のオンボーディング面談での口調のため、既存担当（笠井・鈴江等）とは場面が異なる。
> 既存担当ファイルとしてマージする前に、セールス面談側の発話でも一度上書き確認することを推奨。

## 商談内で見えた特徴

- `ありがとうございます`（各確認の区切りで非常に高頻度）
- `させていただきます` / `させていただきますね`
- `いただけたらと思います` / `いただければと思います`
- `一旦` / `一応` / `ちょっと` / `ちなみに` / `そしたら`
- `かしこまりました` / `恐れ入ります`
- `ご安心ください`
- `遠慮なく聞いていただけたら`
- `逐一ご相談いただけたら`
- `ぜひ末長くよろしくお願いいたします` / `五年十年長くパートナーとして`

## 一人称・距離感

- 一人称: 私
- 顧客への呼び方: `星野さん` /（書面では）`星野さま`
- 距離感: 丁寧で腰が低い。作業を1つずつ区切り、都度「ご不明点はございませんか」で確認を挟む。

## メール反映の定型

- `お申し込みいただきまして本当にありがとうございます`
- `〜の署名を進めていただけたらと思います`
- `〜次第、改めてメールでお送りさせていただきます`
- `ご不明点があれば、遠慮なく聞いていただけたらと思います`
- `何かあれば逐一ご相談いただけたらと思います`
- `ご確認をお願いいたします`
- 不安対応: `ご安心ください` / `全然まだまだ決めなくても大丈夫です`
- 締め: `今後ともよろしくお願いいたします` / `ぜひ末長くよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`ご確認いただくといいかなと思います`、`ご利用いただけるといいかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`届いているかと思います`）→ 文末で多用しない
- `できればと`: 発話に確認できず → 使わない
- `見ていただけると`: 発話に確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証（サポート担当としても使用しない）
- 過度な美文・顧客感情の断定
