# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。一区切りごとに必ず入る）
- `〜させていただきます` / `〜させていただいて`（案内・進行で多用）
- `〜していただけたらと思います` / `〜していただければと思います`（依頼・案内の定番着地。柔らかく押しつけない）
- `ご安心ください`（不安対応の締めで頻出。`臨機応変にご対応させていただきますのでご安心ください`）
- `お気軽に` / `気軽に`（`気軽に聞いてくださいね`、`お気軽にご相談くださいね`）
- `ご自分のペースで` / `〇〇さまのペースで`（立ち上げ・作業の進め方で頻出）
- `しっかり`（`しっかりサポート`、`しっかりフォローできたら`）／`無事に`／`改めて`／`一旦`／`ちなみに`
- `〜という形になります` / `〜になります`（説明の着地）
- `すいません` / `大変失礼いたしました`（不手際時は素直に詫びる。誠実な進行）
- `リラックスして`（審査電話など、緊張しそうな場面で和らげる）
- `よろしくお願いいたします`（締めの定番）

## 一人称・距離感

- 一人称: 私 / 弊社（`私の方で`、`私たちも`）
- 顧客への呼び方: `赤穂さん`／`赤穂様`、`松本さん`／`松本様`（さん・様を併用）
- 契約後・立ち上げ期のお客様に対し、手順を一つずつ確認しながら伴走するスタイル。ご家族への配慮の一言を自然に添える

## メール反映の定型

- `改めて、〜いただき本当にありがとうございます`
- `〜させていただきますので、よろしくお願いいたします`
- `まず〇〇していただけたらと思います`（次アクションを1つ置く）
- `気になることが出てきましたら、お気軽にお知らせください`
- `専任のサポート担当にもしっかり引き継ぎますので、ご安心ください`
- `〇〇さまのペースで進めていただけます`
- 締め: `本日は貴重なお時間をいただき、ありがとうございました`

## 余白表現の出現

- `かと`: あり（`まとめて押していただけると楽かと思います`）→ 1通0〜1回までOK
- `できれば`: あり（`できれば今日発行できるか確認します`）→ 事情説明として自然に使用可。依頼文の着地は曖昧に止めない
- `かなと` / `見ていただけると`: 明確な発話は未確認 → 無理に足さない。使う場合も着地形（`〜いただけますと助かります`）に寄せる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・審査通過の断定（`必ず稼げます`、`審査は大丈夫です` は使わない）
- 過度な美文
- 顧客の不安・感情の断定
- 保証範囲の誤記（分割は返金保証対象外。全額返金保証と混同しない。クーリングオフ8日間との区別を明確に）
