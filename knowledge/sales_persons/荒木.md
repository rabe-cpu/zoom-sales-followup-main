# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。顧客の発言・質問のたびに置く）
- `おっしゃる通りです` / `おっしゃる通りですね`（同意の定番）
- `結論`（要点を先に出すときの切り出し。`結論、実は私達のご提案も〜`）
- `〜させていただく`（`お声掛けさせていただいた`、`ご紹介させていただく`、`お見せしている`、`お伝えさせていただきますね`、`日程調整してもよろしいですか`）
- `〜していきませんか？`（提案の型。`収益化していきませんか`、`取り入れていきませんか`）
- `〜という形になります` / `〜という話ですね` / `〜というものになります`（説明の着地）
- `だったりとか`（列挙の接続。`スキルアップだったりとか`、`月額費のメンテナンス料金だったり`）
- `そうですね`（相槌・受け）
- `かしこまりました`
- 確認を挟む: `まずここまで大丈夫ですか？`、`ご紹介させていただいてもよろしいですかね？`、`〜してもよろしいですか`

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちの強みは`、`弊社のシステム`、`私がすいません、二時から別の`）
- 顧客への呼び方: `鈴木さん`（商談中は基本さん付け）
- 顧客の話を受け止めてから提案へ返す。まず相手の事業・こだわりを称賛し、共通点を見つけてから本題に入る運び

## メール反映の定型

- `本日はお忙しい中、お時間をいただきありがとうございました`（お礼）
- `結論から申し上げますと、〇〇です`（要点先出し）
- `〇〇していきませんか、というお話でした`（提案の振り返り）
- `〜という形になります`（説明の締め）
- `おっしゃる通り、〇〇ですので`（顧客の言葉を受けての接続）
- 確認導線: `まずはこの点だけ確認させてください`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: 弱く出現（`〜かなと思って`、`見ていただけるかな？`）→ 1通あたり0〜1回まで、軽い提案・温度感の箇所だけOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: `できればと思いますので` の完結形はあるが、途中で止める `できればと。` 形はなし → ネクストアクションは `〜できればと思います` `いただけますと助かります` で必ず着地させ、文を途中で止めない
- `見ていただけると`: `見ていただけるかな` はあるが、途中で止める `見ていただけると。` 形はなし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談でも `絶対売り上げ百パー上がりますよっていうのはどうしても言えない` と本人が明言。メールでは `やることをやっていただければ成果につながりやすい` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
