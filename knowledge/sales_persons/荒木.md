# 荒木さん

## 商談内で見えた特徴

- `お世話になっております` / `ありがとうございます`（相槌・お礼として非常に頻出）
- `〜という形です` / `〜という形になります` / `〜になってきます`（説明の着地）
- `〜させていただ〜`（謙譲を厚めに重ねる。`ご案内させていただ` `お渡しさせていただ`）
- `なので、`（話をつなぐ接続）
- `ある意味`（言い換え・補足の接続）
- `〜と思いますので` / `〜と思ですけれども`（見立ての着地）
- `教えていただけたらと思います` / `〜いただけたらと思います` / `〜いただければと思います`（依頼の着地）
- `そうですよね` / `確かに` / `間違いないですね`（共感の相槌）
- `いいですね` / `すごいですね` / `素晴らしいですね`（承認）
- `結構` / `ちょっと`（程度のやわらげ）
- `遠慮なく`（質問を促すとき）
- `ぜひ`（後押し）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちも自信がある` `弊社の倉庫`）
- 顧客への呼び方: `浜谷さん` / `御社`（法人相手は御社を併用）

## メール反映の定型

- `お世話になっております。ありがとうございます。`（冒頭の受け）
- `〜という形になります`（仕組み・費用の着地）
- `ある意味〇〇です`（言い換えでかみ砕く）
- `〜いただけたらと思います`（依頼の着地）
- `遠慮なくご質問ください`（相談導線）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`速度感は上がってるかなと思います` `取り組んでいただけるんじゃないかなと`）→ メールでは0〜1回までOK。文末で途中終止する `かなと。` は使わない
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: `できたらと思います` `いただけたらと思います` の完成形で使用 → ネクストアクションは `〜いただけたらと思います` `〜いただけますと助かります` で着地させる
- `見ていただけると`: `見ていただけると`（利用者さんを見ていただけると）の形で使用 → `ご覧いただけますと` で着地

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `手堅い` `しっかりやれば決まります` `全額返金保証` と語る場面があるが、顧客送付用メールでは保証・断定表現にしない。`〜という方が多いです` 程度に留める）
- `必ず成果が出ます` / `安心して稼げます` / `誰でも簡単に`
- 未確定の提案（輸出システムの追加提供は商談内で「交渉次第・かも」の段階。顧客送付用本文に確定情報として書かない）
- 過度な美文、顧客感情の断定
