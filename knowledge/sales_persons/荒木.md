# NEXT 荒木さん

## 商談内で見えた特徴

- `〜させていただくので、よろしくお願いします`（サポート宣言＋依頼の定番。多用）
- `はい、ありがとうございます`（相槌・お礼として非常に頻出。相手の一言ごとに挟む）
- `全然大丈夫ですよ` / `〜で大丈夫ですよ`（不安・遠慮をほどく定番。`全然遅れてないので大丈夫`、`焦らずで大丈夫`、`どちらでも大丈夫`）
- `お手数なんですが`（依頼の前置き。丁寧に手間を認める）
- `ちょっと`（依頼・確認をやわらげるクッション。`ちょっとご確認`、`ちょっとお時間`）
- `一旦`（`一旦署名を先に`、`一旦電話対応で大丈夫`、`一旦もう`）
- `結論`（`全部送っていただいた方が結論いいと思います`）
- `正直`（`今正直`、`この面談で正直どちらにも切り替える方も`）
- `割と`（`割と皆さん徐々に`、`割とマニアック`）
- `気軽に聞いていただければ` / `遠慮なく質問`（相談導線を開く）
- `〜という形`（説明の着地）

## 一人称・距離感

- 一人称: 私 / 弊社（`私の方で`、`弊社から`、`弊社のマニュアル`）
- 顧客への呼び方: `〇〇さん` / `〇〇さま`（商談中はさん付け、メールでは「さま」）

## メール反映の定型

- `〜させていただくので、よろしくお願いいたします`（サポート姿勢の締め）
- `お手数なんですが、〇〇していただけますと助かります`（依頼の着地）
- `〇〇していただけると助かります`（`確認いただけると助かります`、`教えていただけると助かります`、`撮っていただけると助かります`）
- `〇〇で大丈夫ですよ` / `焦らずで大丈夫`（不安への受け止め）
- `気軽に（遠慮なく）ご連絡いただければと思います`（相談導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: 弱く1回のみ出現（`前年度で書くかと。`）→ 1通あたり0〜1回まで。乱用しない
- `かなと`: 明確な出現は確認できず → 使わない
- `できればと`: 荒木さんの発話には出現なし（`できれば`は顧客側）→ ネクストアクションは「いただけますと助かります」で着地させる
- `見ていただけると`: 単独出現は確認できずだが、`〜していただけると助かります`の型は頻出 → `ご覧いただけますと助かります`で代替する

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・審査保証・返金保証の断定（今回顧客は分割申込＝審査ありで、全額返金保証は一括のみ対象。`審査は通ります`『必ず稼げます』等は禁止。`皆さん通してみますみたいな`程度に留める）
- 過度な美文・情緒的な前置き
- 顧客感情の断定
