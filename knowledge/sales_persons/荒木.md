# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。対応ごとに必ず挟む）
- `かしこまりました`（了解の定番。顧客の回答を受けたあとに多用）
- `すいません`（依頼・訂正をお願いするときの前置きのやわらげ）
- `ちなみに`（確認を切り出すときの接続。`ちなみに次へのページ進まれる前に`、`ちなみに今パソコンで`）
- `一応`（念押し・補足の切り出し。`一応次のページ進む前に`、`一応あの`）
- `そしたら`（話題の切り替え。`そしたら最後ですね`、`そしたら岡本さん`）
- `じゃあ`（段取りを進めるときの接続）
- `〜させていただきますね` / `〜させていただきます`（humble form。`お送りさせていただきますね`、`拝見させていただきますね`、`申請させていただきますね`）
- `〜という形になります` / `〜という形で`（手続きの着地。`審査開始という形になります`、`審査ができる形になります`）
- `〜で大丈夫です` / `〜大丈夫ですよ`（不安をほどく定番。`まだで大丈夫ですよ`、`後からのご提出で大丈夫`、`個人でもアマゾンでもどちらでも大丈夫ですよ`）
- `ご安心ください`（`また最初からのご入力にはならないのでご安心ください`）

## 一人称・距離感

- 一人称: 私（`私宛てに`、`私の方で`、`私から申請させていただきます`）、改まると 弊社
- 顧客への呼び方: `岡本さん` と `岡本様` を併用。段取り中は `さん`、御礼やお願いの改まった場面で `様`

## メール反映の定型

- 冒頭・締めの御礼: `本日はお忙しい中、根気よくご対応いただきありがとうございました`（実発話に `お仕事の合間のね、根気よくご対応いただき本当にありがとうございます` あり）
- 段取り案内: `そしたら、明日以降の流れについてご案内させていただきますね`
- 依頼の着地: `〜いただければと思います` / `〜いただけますと助かります` / `〜いただけますと幸いです`
- 不安の受け止め: `〜で大丈夫です` / `ご安心ください`
- 手続き説明の締め: `〜という形になります`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: 明確な出現なし → 使わない
- `かなと`: 明確な出現なし → 使わない
- `できればと`: 荒木さんの発話にはなし（顧客側の `できれば水曜日` はあるが営業発話ではない）→ 使わない
- `見ていただけると`: 出現なし → 使わない
- → ネクストアクションは `いただければと思います` / `いただけますと助かります` で必ず着地させる（文を途中で止めない）

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 審査保証・成果保証の断定。商談では `基本的には皆さん審査がですね、あの滞りなく承認が通っております` と語る場面があるが、メールでは保証表現にしない。`多くの方がそのまま審査に進まれています` 程度に留める
- 過度な美文
- 顧客感情の断定
