# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。話の区切りごとに置く）
- `そしたら` / `じゃあ`（次の手順へ移るときの接続）
- `一応`（やわらげ・前置き。`一応こういったものがあります`）
- `結論`（要点を先に出すとき。`結論、私たちって普段割引しないんですね`）
- `まず`（手順・論点の切り出し）
- `〜という形ですね` / `〜という形`（説明の着地）
- `〜と思いますので`（依頼・案内の締め）
- `とんでもないです` / `とんでもないんですよ`（恐縮への返し）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちの方で`、`弊社のシステム`、署名は「荒木」）
- 顧客への呼び方: `中島さん`（商談中は基本さん付け）

## メール反映の定型

- `〜いただけたらと思います`（依頼・案内の定番着地。非常に頻出）
- `〜していただいてよろしいですか` / `進んでいただけたらと思います`（手順の依頼）
- `ご安心ください` / `大丈夫ですよ` / `全然〜で大丈夫です`（不安の受け止め）
- `結論、〇〇です`（要点を先に出す）
- `一応〇〇しております`（体制・仕組みの案内）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`おそらく問題はないかなと`、`考えていただいてもいいかなと`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 明確な出現なし。`いただけたらと思います` が定番のため、依頼は「いただけたらと思います」「いただけますと助かります」で着地させる
- `見ていただけると`: `見ていただけたら` の形で出現 → メールでは「ご覧いただけたらと思います」で着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では不安に対し「ご安心ください」「大丈夫です」で受けるが、収益・成果を保証する言い方はしない。メールでも保証表現にしない）
- 過度な美文
- 顧客感情の断定
