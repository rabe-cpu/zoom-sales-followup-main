# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（区切りごとに非常に多用。受け止めの相づち）
- `ご案内させていただければと思います` / `〜させていただく`
- `〜という形です` / `〜という形になります`（説明の着地で頻出）
- `ま、` / `ね、` の口語的なつなぎ
- `〜と思っております` / `〜と思います`
- `ご不明点はありますか` / `何か確認したいことはありますか`（説明の節目で確認を頻繁に挟む）
- `しっかり` / `もちろん` / `やっぱり` / `ちょっと`
- `ご安心いただきたいのは` のように、不安を先回りして受け止める
- `率直に` / `正直` で本音ベースの説明に寄せる
- `〜いただけたらと思います`（依頼・次アクションの柔らかい着地）

## 一人称・距離感

- 一人称: 私／私たち／弊社
- 顧客への呼び方: `坂本さん`（`さん` 付け中心）
- 法人・経営者には `御社` を使う

## メール反映の定型

- `本日も貴重なお時間をいただきありがとうございました`
- `資料をお渡しさせていただきます` / `資料をお送りさせていただきます`
- `ご不明点や追加のご質問があれば、いつでもご連絡ください`
- `〜という形でご案内させていただきます`
- `ご検討いただけたらと思います`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`大きなデメリットにはなるかなと思います` 等）→ 1通あたり0〜1回までOK
- `かと`: 文末止めの明確な出現は確認できず → メールでは文末で多用しない
- `できればと`: `ご案内できればと思います` の形であり → ネクストアクションは「と思います」「お送りいたします」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない（`ご覧いただけたらと思います` で着地）

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 過度な美文・きれいすぎる言い回し
- 顧客感情の断定
- 成果保証・収益保証に聞こえる表現（商談でも `全員が全員成果が出るわけではない` と率直に伝えている）
