# 荒木さん

契約前段階（申込書類作成サポート）の面談から抽出。説明会・個別相談会は鈴江さんが担当し、荒木さんが契約・書類サポートを引き継ぐ流れ。

## 商談内で見えた特徴

- `かしこまりました`（依頼・確認を受けたときの定番。`はいかしこまりました`）
- `ありがとうございます`（相槌・お礼として非常に頻出。一区切りごとに置く）
- `ご安心ください`（不安をほどくときの締め。`そのまま契約進んじゃうとかじゃないのでね。ご安心ください`）
- `お手数なんですけれども` / `お手数ですけれども`（作業をお願いするときの前置き。頻出）
- `恐れ入ります`（記入・署名をお願いしたあとの受け）
- `念のため`（確認を足すときの接続。`念のため確認したいこと`、`念のためここ`）
- `ちなみに`（補足質問の切り出し。`ちなみに今回どちらの銀行様ですか`）
- `そしたら`（工程を次へ進めるときの転換。`そしたらですね`、`そしたら印鑑ですね`）
- `一旦`（`一旦その他には大丈夫そうですね`、`一旦個人事業主向けの見本で`）
- `正確には`（誤解をほどくときの言い換え。`正確には前払いではなく`）
- `〜という形` / `〜という形です`（説明の着地）
- `〜になります`（事実説明の締め。`契約前段階の面談にはなりますので`）
- `大丈夫です` / `大丈夫ですよ`（不安への受け止め。乱用せず事実とセットで使う）

## 一人称・距離感

- 一人称: 私 / 弊社（`私の方で`、`私宛て`、`弊社`）。「僕」は確認できず。
- 顧客への呼び方: 基本は `藤原様`。会話が砕けると `藤原さん` も混ざる。メールでは `藤原有澄さま` で統一する。
- 全体に低姿勢で、作業依頼のたびに `お手数`『恐れ入ります』『ありがとうございます』を添える丁寧なトーン。

## メール反映の定型

- `本日は〜いただきありがとうございました`（お礼の切り出し）
- `そしたら、まず〇〇、次に〇〇という形で進めさせていただきます`（工程案内）
- `お手数なんですけれども、〇〇いただけますと助かります`（依頼の着地）
- `〇〇については、私の方からご連絡させていただきます`（巻き取り）
- `〇〇なのでご安心ください`（不安の受け止め。事実とセットにする）
- 締め: `引き続きよろしくお願いいたします` / `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`まあ一番スムーズかと`）→ 1通あたり0〜1回までOK。依頼文の着地を曖昧にしない範囲で。
- `かなと`: あり（`整理しやすいかなとは思います`、`いいんじゃないかなと思いますね`）→ 0〜1回までOK。
- `できればと`: 明確な出現なし → 使わない。ネクストアクションは「いただけますと助かります」「お願いいたします」で着地。
- `見ていただけると`: `ご覧いただけたら`・`〜していただけると`の形は出現 → 依頼の着地が曖昧にならない範囲で可。文を途中で止めない。

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証・審査通過の断定（審査は「ローンが組めなければ白紙になる」という手続き説明にとどめ、「必ず通る」等は書かない）
- システム稼働・補償の断定（過去対応例として柔らかく触れる程度にする）
- 過度な美文、顧客感情の断定
