# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。一区切りごとに必ず入る）
- `かしこまりました`（承り・進行の受けで頻出）
- `〜させていただきます` / `〜させていただいております`（案内・依頼の定番着地）
- `そしたら` / `じゃあ`（次の手順への切り替え）
- `お手数なんですが` / `お手数ですが`（依頼の前置き。低姿勢）
- `ご安心ください`（不安の受け止め・締め）
- `〜という形になります` / `〜という形です`（説明の着地）
- `ちなみに` / `一応`（補足の接続）
- `遠慮なく聞いていただけたらと思います`（質問導線を開く）
- `ご不明点はありますか` / `〜で大丈夫ですか`（小まめな理解・同意確認）

## 一人称・距離感

- 一人称: 私（`私の方で`、`私まで`）、弊社
- 顧客への呼び方: `吉竹さん` / `吉竹様`（さん・様を併用）
- 引き継ぎ・サポート担当として、契約・納品・今後の流れを一歩ずつ確認しながら丁寧に進めるスタイル
- 手順が多い場面でも `お手数なんですが` と一言添えてから依頼する

## メール反映の定型

- `そしたら、〜させていただきます`
- `お手数なんですが、〜していただけますでしょうか`
- `〜という形になりますので、よろしくお願いいたします`
- `ご不明点があれば、私までおっしゃっていただけたらと思います`
- `〜いただけましたら、こちらで〜させていただきます`
- 締め: `本日は貴重なお時間をいただきありがとうございました` / `今後ともよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`わかりやすいかと思います`）→ 1通0〜1回までOK
- `かなと` / `かな`: 明確な確認なし → 使わない
- `できればと`: 明確な確認なし → 使わない
- `見ていただけると`: `全文読んでいただけるとわかりやすいかと思います` の形 → `ご覧いただけますと〜` の着地ならOK

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証・断定（サポート面談では事実確認と手順案内が中心。メールでも成果を保証しない）
- 過度な美文
- 顧客の感情の断定・煽り
