# 荒木さん

## 商談内で見えた特徴

- `〜という形です` / `〜という形になります`（締め・着地で非常に頻出。仕組み説明のまとめに多用）
- `ありがとうございます`（相槌・お礼として極めて頻出。顧客の一言ごとに返す）
- `かしこまりました` / `よかったです` / `素晴らしいです`（受け止めの定番）
- `なるほど、なるほど`（傾聴の相槌）
- `ちょっと`（柔らかい前置き。`ちょっとお伺いさせていただく`、`ちょっとご案内`）
- `結構` / `やっぱり`（強調・共感のつなぎ）
- `正直`（デメリットや本音を伝えるときの前置き。`正直そんなに高くない`、`正直すぐにお金が欲しい方には向いてない`）
- `まず` / `じゃあ` / `一旦`（説明の区切り）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちの方から`、`弊社のシステム`、`私も毎月30社40社ほど`）
- 顧客への呼び方: `〇〇さん` / `御社`（法人顧客には `御社` を多用）

## メール反映の定型

- `〇〇という形です` / `〇〇という形になります`（仕組み・条件の着地）
- `ご案内させていただきます` / `ご案内させていただければと思います`
- `〇〇させていただければと思います`（依頼・提案の柔らかい着地）
- `正直、〇〇です`（デメリット・本音を誠実に開示するときの前置き）
- お礼: `本日はお忙しいなかありがとうございました`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`7月末の引き落としになるかと思います`、`難しいだろうという方もいる`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`買ってくれたのかなと思います`、`一番の近道のような`）→ 1通あたり0〜1回までOK。`かと`と合わせて1通1回までに抑える
- `できればと`: 明確な出現なし → ネクストアクションは「いただけますと助かります」「ご返信いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益断定（荒木さんは商談で `正直そんなに高くない`、`即日換金性はない`、`初回売上は3ヶ月目の方がほとんど` とデメリットも誠実に開示している。メールでも他社事例は `〜という方もいらっしゃいます` 程度に留め、今回顧客の成果として保証しない）
- 過度な美文
- 顧客感情の断定（千葉さまは `疑心暗鬼`、`本当にこれで収入に` と半信半疑を口にしている。これを `不安が解消されました` などと断定しない）
