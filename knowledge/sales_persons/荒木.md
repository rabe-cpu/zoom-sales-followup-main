# 荒木さん

福祉事業（就労支援A型・B型）専任で個別相談会を担当。物販業界歴13年、システム説明歴が長い。

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として極めて頻出。顧客の一言ごとに挟む）
- `一旦`（`一旦ただいろいろとお伺いするよりは`、`一旦どんな仕組みなのか`）
- `ちなみに`（深掘り質問の切り出し。`ちなみに今回は`、`ちなみにアマゾンは`）
- `その上で`（話題転換のつなぎ。`その上で一点お伺いしたいんですけれども`）
- `逆に`（`逆に費用以外になんかネックなところは`）
- `結論`（`結論ネットショップにはなっちゃう`）
- `〜という形です` / `〜という形になります`（説明の締め）
- `〜と思っております` / `〜と思います`（所感・提案の着地）
- `全然大丈夫ですよ`（相手が待たせる・迷う場面での安心の受け）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私自身も`、`私たちのシステム`、`弊社の`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。`鬼頭さん`）

## メール反映の定型

- 冒頭お礼を厚めに置く（`貴重なお時間をいただきありがとうございました`）
- `その上で〇〇`（話題を進めるつなぎ）
- `〇〇という形になります`（仕組み・条件の締め）
- `〇〇と思っております`（提案・所感の着地）
- 確認は `いかがですか` / `〜ありますか` / `〜てもよろしいですか` で相手に返す
- 締め: `よろしくお願いいたします` / `失礼いたします`

## 余白表現の出現

- `かと`: あり（`ご挨拶が先かと思いますので`、`お話がいろいろできるかと思います`、`成功法かと私も常々思っております`）→ 発話準拠。1通あたり0〜1回までOK
- `かなと`: 荒木さん本人の発話では単独の明確な出現なし（`理想かなと`は顧客側発話）→ 使わない
- `できればと`: 出現なし → ネクストアクションは「いただけますと助かります」「ご連絡いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない
- `いただけたら` / `いただければと思います`: あり（`五時までいただけたら`、`また近いなれればと思いますので`）→ 温度感の軽い提案で少量OK

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず成果が出ます` `安心して稼げます` などにしない。商談では返金保証や平均月商330,000円などを語るが、メールでは資料に基づく判断材料の範囲に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
