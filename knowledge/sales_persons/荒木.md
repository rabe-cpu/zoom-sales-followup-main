# 荒木さん

福祉事業者（就労継続支援B型事業所）向けの特別オファー説明会を担当。1件の商談から自動抽出した初回登録版。既存担当と違い、福祉事業所の「生産活動」「利用者さんが取り組めるか」を軸に話す傾向がある。

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として極めて頻出。質問を受けるたびに置く）
- `かしこまりました` / `承知いたしました`（受け止めの締め）
- `おっしゃる通りですね`（顧客の指摘を正面から受け止める。反論せず一度肯定してから補足する）
- `〜という形になります` / `〜という形`（説明の着地）
- `〜というところですね` / `〜というところで`（論点の締め）
- `〜させていただく`（謙譲を厚めに使う）
- `まあ` / `ちょっと` / `結構` / `正直`（口語クッション。硬くなりすぎない）
- `〜と思いますので、よろしくお願いします`（依頼の締め）
- `佐藤さんが知りたい情報を優先して`（顧客主導で進める姿勢を明言する）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちのシステム`、`弊社としては`）
- 顧客への呼び方: `佐藤さん`（商談中はさん付け。メールでは「佐藤保さま」）

## メール反映の定型

- `本日はお忙しい中、お時間をいただきありがとうございました`（お礼の起点）
- `おっしゃる通り、〇〇ですね`（顧客の懸念をまず受け止める）
- `〇〇という形になります`（仕組みの着地）
- `必ず今週中には〇〇できるようにしておきます`（期限を切った約束。実際に商談で使用）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`強みになってるのかなと思いますね`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: `お答えできたらと思います` / `回答できればと思います` の着地形で出現あり → `できれば〜と思います` の形は使ってよい。`できればと。`で止める形はNG
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益断定（商談では「20%の利益が取れています」など事例を語るが、`必ず`『稼げます』の断定はしていない。メールでは `〜という方が多いです`『導入いただいている方が多いです』程度に留める）
- 過度な美文
- 顧客感情の断定（利用者さんの状態を営業側が断定しない）
