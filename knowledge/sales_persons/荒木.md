# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として極めて頻出。ヒアリングの区切りごとに必ず入る）
- `教えていただいて` / `教えていただき` / `教えていただいてありがとうございます`（ヒアリング後の受け止め）
- `かしこまりました`（承知の定番。`はいかしこまりました`）
- `とんでもないです` / `とんでもないですよ`（謙遜・相手の遠慮を受け止めるとき）
- `〜させていただければと思います` / `〜させていただく`（依頼・案内の柔らかい着地）
- `〜できたらと思います` / `〜できればと思います`（提案の着地）
- `一応` / `ちょっと` / `まあ`（前置きのクッション）
- `そもそも`（論点を戻すときの切り出し）
- `なるほど。なるほど。`（相槌・受け止め）
- `じゃあ`（話題転換の切り出し）
- `〜っていうところ` / `〜という形` / `〜という形になります`（説明の締め）
- `結論から言うと` / `結論`（要点を先に出すとき）
- 顧客の懸念やデメリットを先に正直に出す姿勢（`正直そんなに高くない`、`すぐ収益化したい方には向いてない`）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私と御社の場合は`、`私たちがそもそも`、`弊社のシステム`）
- 顧客への呼び方: `橋本さん`（商談中は基本さん付け）、法人は `御社`

## メール反映の定型

- 冒頭・区切りのお礼: `本日はお忙しい中、お時間をいただきありがとうございました`
- 受け止め: `教えていただきありがとうございました`
- 承知: `かしこまりました`
- 謙遜・相手の遠慮を受ける: `とんでもないです`
- 案内の着地: `〜させていただければと思います`
- 提案の着地: `〜できればと思います` / `〜できたらと思います`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`ご挨拶が先かと思いますので`、`一番重要な部分かと思いますが`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`お力になるのかなと思います`）→ 1通あたり0〜1回までOK。ただし `かと` と重複させない
- `できればと`: `お話ができればと思います` の形で着地して使う。`できればと。` のように文を途中で止めない
- `見ていただけると`: 単独での明確な出現は確認できず → 使わない。案内は `ご覧いただけますと` で着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（荒木さんはむしろ `利益率は正直そんなに高くない`、`すぐ収益化したい方には向いてない`、`ゼロパーセントとは言えない` と正直に伝える誠実タイプ。メールでも保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 相手が見送った判断を否定・再説得する押しの強い表現
