# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます` / `はい、ありがとうございます`（相槌・受け止めとして極めて頻出。顧客の一言ごとに置く）
- `〜させていただきます` / `〜させていただく`（案内・対応の基本形。`お送りさせていただきます`、`確認させていただきます`、`ご案内させていただきます`）
- `〜いただけたらと思います` / `〜いただけると助かります` / `〜いただいてもよろしいですか`（依頼の定型）
- `一旦`（区切り・仕切り直しの接続。`一旦ログイン`、`一旦それ以外の契約書`、`一旦ここまで`）
- `〜っていう形になります` / `〜という形`（説明の着地）
- `なるほど、なるほど`（受け止めの相槌。重ねて言う）
- `ご安心ください`（不安をほどく締め）
- `臨機応変に対応させていただく` / `臨機応変にご対応`（不確定要素への受け止め）
- `気軽に聞いていただけたら` / `気軽に連絡いただければ`（相談導線）
- `ちょっと`（やわらげのフィラーとして多用）
- `よろしくお願いします` / `よろしくお願いいたします`（締め）
- `大丈夫ですか？` / `大丈夫そうですか？`（確認の問いかけ）

## 一人称・距離感

- 一人称: 私（`私の方で`、`私が担当した`、`私もログインしてみますね`）、改まると 弊社（`弊社含め`）
- 顧客への呼び方: `桑原さん` / `桑原様`（さん付けと様付けを併用。丁寧め）

## メール反映の定型

- `〜させていただきますので、よろしくお願いします`（案内の着地）
- `一旦〇〇していただいてから、〇〇いただけたらと思います`（手順の区切り）
- `〇〇という形になります`（説明の締め）
- `何かあればお気軽にご連絡いただけたらと思います`（相談導線）
- `臨機応変にご対応させていただきますので、ご安心ください`（不確定要素の受け止め）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`お試しいただけるといいかなと思います`、`スムーズかなと思いますね`）→ 1通あたり0〜1回までOK
- `かと`: あり（`できてないだけかと思いますので`）→ 1通あたり0〜1回までOK。依頼文の着地には使わない
- `できればと`: 明確な `できればと` の出現なし（`できればこう端的に` の形はあるが着地の余白ではない）→ ネクストアクションは「いただけますと助かります」「ご連絡いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証・審査通過の断定（審査は「別で通る可能性がある」「臨機応変に対応」と語る範囲。メールでも保証表現にしない）
- 過度な美文
- 顧客感情の断定
