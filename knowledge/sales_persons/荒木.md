# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます` / `とんでもないです`（相槌・お礼として極めて頻出。相手が謝ると必ず `とんでもないです` で受ける）
- `そうですよね`（強い共感・傾聴の相槌。相手の話を受け止めてから進める）
- `ちなみに`（話題を切り出すときの接続。`ちなみに今日お時間としては…`）
- `逆に`（視点を変えるときの接続。`逆に一対一でお話できた方が…`）
- `じゃあ` / `まあ` / `やっぱり`（やわらかい進行・言い換え）
- `〜という形ですね` / `〜というところですね`（説明の着地）
- `〜と思っております` / `〜と思いますので`（受け止めと提案の締め）
- `もちろんです` / `全然`（不安・遠慮をほどくときの受け）

## 一人称・距離感

- 一人称: 私 / 弊社（`私からちょっとコンタクト取らせていただいて`、`弊社の取り組み`）
- 顧客への呼び方: `〇〇さん`（庄司さん、大木さん。事業所名＋さんで呼ぶこともある）
- 傾聴型。相手の状況を長めに受け止めてから、提案や次アクションへ寄せる距離感

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございます`（お礼の基調）
- `〜させていただければと思います` / `〜させていただけたらと思います`（提案・依頼のやわらかい着地）
- `〜という形ですね` / `〜というところですね`（説明の締め）
- `ご連絡させていただいてもよろしいですかね`（次アクションの確認）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`一番の解決口になるんじゃないかなと思って`、`一つあるのかなって今思います`）→ 1通あたり0〜1回までOK
- `できれば`: あり（`できれば三時半ぐらいまでお時間いただけると`）→ 依頼のやわらかい前置きとして少量OK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `見ていただけると`: 出現なし → 使わない。ネクストアクションは `ご覧いただけますと助かります` `ご返信いただいてもよろしいでしょうか` で着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず集客できます` `絶対に一般就労につながります` 等は使わない。商談では `集客にはすごく強い` と語るが、メールでは `〜という事業所さんが多いと伺っています` 程度に留める）
- 過度な美文
- 顧客感情の断定
