# 荒木さん

## 商談内で見えた特徴

- `という形ですね` / `という形になります`（説明の着地に多用）
- `ご安心ください`（手続き・審査・サポートの不安に対して繰り返し使う）
- `しっかりサポートしてまいります` / `責任持って申請させていただいて`
- `一旦`（`一旦その他には`、`一旦ここまでの流れで`）
- `正直`（`正直あの分割も`、`正直輸出の方が収益速度は早い`）
- `個人的には思います` / `個人的に思いますね`（意見を断定せず柔らかく出す）
- `全然大丈夫です` / `全然ありです`（`この場では決めなくて全然大丈夫ですよ`）
- `ちなみに`
- `恐れ入ります` / `失礼いたしました` / `恐縮なんですけれども`
- `とんでもないです`（お礼への返し）
- `かしこまりました` / `承知`
- `お気軽に聞いてくださいね` / `お気軽に見てくださいね`

## 一人称・距離感

- 一人称: 私／私たち／弊社
- 顧客への呼び方: `〇〇さん` / `〇〇さま` 併用（本文では `〇〇さま` 寄りで統一するとよい）
- 同席者・名義人にも必ずお礼を添える（`長い時間同席いただいてありがとうございます`）

## メール反映の定型

- `〜させていただきますので、よろしくお願いいたします`
- `届きましたら教えていただけると助かります` / `〜いただけると幸いです`
- `ご不明点が出てきましたら、お気軽にご連絡ください`
- `必ず私たちの方からご連絡させていただきますのでご安心ください`
- 締め: `引き続きどうぞよろしくお願いいたします`
- お礼: `根気強くご対応いただきまして、ありがとうございました`

## 余白表現の出現

- `できればと`: あり（`気持ちよくパートナーシップを結ぶことができればと思っております`）→ ただし必ず `思っております` / `思います` で着地している。文末で止めない
- `かなと` / `のかな`: あり（`いいかなっていう`、`いいのかなっていうのを個人的には思います`）→ 柔らかい見解として1通0〜1回まで
- `かと`: 文末で止める用法は未確認 → 使わない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 過度な美文
- 顧客感情の断定
- 成果保証・審査通過の断定（荒木さんは `審査が通る方がほとんどですね` と確率で話し、断定していない）
- 全額返金保証を分割にも付くように読める表現（分割は対象外。断定的な保証表現は避ける）

## この担当のメール上の注意

- 手続き・審査が絡む回が多いため、ネクストアクションは曖昧に止めず、`〇〇を送っていただく` `電話対応がある` と明確に書く。
- `ご安心ください` の多用がこの人らしさだが、成果や審査通過の保証には使わない。進め方・サポート体制の安心に限定する。
