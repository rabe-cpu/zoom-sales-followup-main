# 荒木さん

## 商談内で見えた特徴

- `はい、ありがとうございます`（受け止めと感謝を非常に高頻度で挟む）
- `ちなみに`（質問・補足を切り出すときの定番）
- `ま` / `まあ`（やわらかい前置き）
- `一旦`（区切り・確認のとき）
- `ご安心ください`（不安への受け止め。実発話にあり）
- `遠慮なく聞いてください` / `何か困ったことがあれば聞きながら進めてください`
- `恐れ入ります` / `恐縮なんですけれども` / `すいません`（依頼・お願いの前置き）
- `〜させていただきます` / `〜させていただく`（手続き案内）
- `〜していただければと思います` / `〜していただけたらと思います`（やわらかい依頼着地）
- `続いて` / `では`（段取りのつなぎ）

## 一人称・距離感

- 一人称: 私（`私の方で`、`私が`）／弊社
- 顧客への呼び方: `高井さん`（`〇〇さん`）

## メール反映の定型

- `本日はお忙しいなか、お時間をいただきありがとうございました`
- `〜についてご案内させていただきます`
- `〜していただければと思います`
- `ご不明な点が出てきましたら、遠慮なくご連絡ください`
- `明日、〇〇のメールをお送りさせていただきます`
- `ご安心ください`（不安の受け止めとして少量）
- 締め: `今後ともどうぞよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`増やしていただけるかと思います`）→ 1通あたり0〜1回までOK、着地形で使う
- `かな`: あり（`楽かなと思い`）→ 限定的に使用可
- `かなと`: 直接の確認は限定的 → 多用しない
- `できればと`: 発話に明確な出現なし → ネクストアクションは「お願いいたします」「ご確認いただければと思います」で着地
- `見ていただけると`: 直接出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証・審査保証の断定
- 過度な美文
- 顧客感情の断定
