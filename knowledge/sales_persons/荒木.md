# 荒木さん

契約内容確認・システム納品・署名・今後のステップ案内を担う、お申込後サポート面談を担当。落ち着いて受け止め、結論から示し、不安を確認事項へ変換する口調。

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として極めて頻出。顧客の質問を受けるたびに置く）
- `結論、〇〇です`（要点を先に出す口癖。`結論、契約金の中に全部含まれてまして`、`結論、商品ページをご自身が作る必要はない`）
- `ご安心ください` / `かからないのでご安心ください`（不安をほどく締め）
- `もちろんですよ`（顧客の遠慮を受け止める）
- `むしろおっしゃっていただいてよかったです`（顧客の「理解できていなかった」を前向きに受ける）
- `〜という形ですね` / `〜というところですね`（説明の着地）
- `イメージとしては〜` / `〜イメージ`（かみ砕くときの締め）
- `遠慮なくご質問いただけたら`（冒頭の場づくり）
- `割と`（`割と徐々に`、`割と強い仕組み`、`割とそういった方はいらっしゃいます`）
- `正直`（`正直そっち優先して`、`正直半々ぐらい`）
- `念のため` / `お手数なんですけれども` / `恐れ入ります`（依頼・確認の前置き）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私の方から`、`私たちもサポートしていく`、`弊社にいただく費用`）
- 顧客への呼び方: `〇〇さん`（商談中はさん付け。※文字起こしは「田村」「畑村」「傍ら」等に誤認識。正しくは畠村幸多郎さま）

## メール反映の定型

- `結論、〇〇です`（要点を先に出す）
- `〇〇という形ですね`（説明の着地）
- `イメージとしては〇〇です`（仕組みのかみ砕き）
- `〇〇はかからないのでご安心ください`（不安への受け止め）
- `お手数なんですけれども、〇〇していただけたらと思います`（依頼の前置き＋着地）
- 締め: `どうぞ今後ともよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`気にしなくてもいいのかなと`、`そこぐらいでもいいかなと思いますね`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「いただけますと助かります」「ご連絡いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `割と負けづらい` `割と強い仕組み` と語るが保証ではない。メールでは `〜という方が多いです` `〜という形が多いです` に留める）
- 過度な美文
- 顧客感情の断定
