# NEXT 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。顧客の発話・操作のたびに挟む）
- `よかったです` / `良かったです`（動作確認・ログインなどが通ったときの安堵の受け）
- `〜させていただきます` / `〜させていただけたらと思います`（自分側の動作をやわらかく案内）
- `〜していただいてもよろしいですか` / `〜いただいてもいいですか`（依頼のときの丁寧な確認）
- `ご安心ください`（不安をほどく定番。`ガチガチに変えられないとかじゃないのでご安心ください`、`ちゃんとご返金しますのでご安心ください`）
- `かしこまりました`（了承の締め）
- `一応`（前置き・保険的な説明で多用）
- `ちょっと`（依頼や確認の前置きソフナー）
- `すいません` / `失礼いたしました`（手続き・設定の不備を素直に詫びる）
- `素晴らしいですね` / `すごいですね`（顧客の行動力・取り組みへの率直な称賛）
- `〜という形` / `〜という流れになるので`（説明の着地）

## 一人称・距離感

- 一人称: 私（`私の方で`）、改まると 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 距離感: 丁寧だが硬すぎず、相槌と称賛で場をほぐすタイプ。手続き系の案内でも「お手数なんですが」「お待ちくださいね」とこまめに気遣いを挟む。

## メール反映の定型

- `〇〇していただけたらと思います`（依頼の着地）
- `〇〇させていただきますね`（自分側の動作案内）
- `ご安心ください`（不安への受け止め。根拠とセットで使う）
- `かしこまりました` / `ありがとうございます`（受け・お礼）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`三四十分ぐらいかなと思うんですけれども`、`考えていかなくていいかなと思い`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「いただけますと助かります」「ご返信いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず儲かる` 等は使わない。事例・ダッシュボードは `目標にしていただける` 程度に留める）
- 過度な美文
- 顧客感情の断定
