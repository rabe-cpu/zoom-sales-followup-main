# 荒木さん

## 商談内で見えた特徴

- `かしこまりました`（依頼を受けるときの定番）
- `〜させていただきます` / `〜させていただく`（丁寧・頻出）
- `ご提供させていただきます` / `お渡しさせていただきます`
- `よろしいですかね` / `〜ですかね`（確認）
- `結論、重要なのが〜`（要点整理の入り）
- `正直〜`（`正直ノウハウは必要ない`、`正直三店舗運営されている方いる`）
- `ご安心ください`
- `〜になりますね` / `〜なんですね`
- `ありがとうございます`（相手の発言を受けての相槌）
- `〜と思いますので、よろしくお願いします`（締め）

## 一人称・距離感

- 一人称: 私／弊社
- 顧客への呼び方: `〇〇さん` / `御社`（法人相手では `御社` を多用）

## メール反映の定型

- `後ほど資料はお渡しさせていただくのでご安心ください`
- `わかりやすくご案内させていただきますね`
- `結論、重要なのが〇〇です`
- `〇〇をまとめてお渡しさせていただきます`
- `ズバリこれですというのをご回答させていただきます`
- 締め: `よろしくお願いします`

## 余白表現の出現

- `かと`: 直接出現は確認できず → 使わない
- `かなと`: 直接出現は確認できず → 使わない
- `できればと`: 直接出現は確認できず → 使わない
- `見ていただけると`: 直接出現は確認できず → 使わない

（荒木さんの実発話では余白表現が確認できないため、メールでは余白表現ゼロで、依頼文は言い切って着地させる）

## 禁止候補

- 過度な謝罪の連発（商談では電波不良で `すいません` を多用したが、メールでは繰り返さない）
- 説明を二転三転させる書き方（商談で顧客から「説明がわかりづらい」と複数回指摘あり → メールでは数字と条件を最初に整理し、順番を崩さない）
- 成果保証・収益断定（`必ず』`確実に儲かります` は使わない。売上・利益は商談で話した試算・目安として書く）
- 顧客感情の断定
