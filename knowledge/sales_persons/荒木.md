# NEXT 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。一区切りごとに必ず置く）
- `全然大丈夫ですよ` / `大丈夫ですよ`（不安・操作ミスをほどく定番）
- `とんでもないです`（顧客の恐縮に対して）
- `素晴らしいですね` / `いいですね`（できた瞬間の承認。多用）
- `ゆっくりで大丈夫ですからね`（操作で焦る顧客への寄り添い）
- `遠慮なく`（`遠慮なくご質問ください`、`遠慮なく弊社のサポート頼って`）
- `一旦`（`一旦ここまでで`、`一旦ご説明させて`）
- `ちなみに`（確認を挟むときの接続）
- `まさに`（`まさにそこですね`。顧客の理解を肯定）
- `〜させていただきます` / `〜させていただいて`（案内・動作の定番）
- `一緒に頑張っていきましょう` / `サポーターとしてついております`（伴走の宣言）

## 一人称・距離感

- 一人称: 私 / 弊社 / 私たち（`私からも確認`、`弊社のサポート`、`私たちもサポーター`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは「さま」に整える）

## メール反映の定型

- `〜していただければと思います` / `〜していただけたらと思います`（依頼・提案の着地。これが荒木さんの基本形）
- `〜で大丈夫です` / `〜大丈夫ですよ`（不安の受け止め）
- `遠慮なくお問い合わせください` / `遠慮なくご相談ください`（相談導線）
- 承認: `素晴らしいですね` `いいですね`（できたことを必ず言葉にする）
- 伴走: `サポーターとしてお手伝いさせていただきます` `一緒に進めていきましょう`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: 単独（文末の余白）としての出現なし（`結ぶか結ばないか`、`間違いがないかとか`は余白ではない）→ 使わない
- `かなと`: 出現なし → 使わない
- `できればと`: 出現なし → ネクストアクションは「〜していただければと思います」「ご相談ください」で着地させる
- `見ていただけると`: 出現なし → 使わない

結論：荒木さんの依頼・提案は「〜していただければと思います」「〜していただけたらと思います」と最後まで言い切る着地形。文末を途中で止める余白表現は使わない（1通あたりゼロ）。

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証・審査保証の断定（面談では費用の発生条件を明確に線引きしている。メールでも保証表現にしない）
- 過度な美文
- 顧客感情の断定（`印象的でした`『伝わってきました』の多用を避ける）
