# 荒木さん（福祉事業所向け商談担当）

## 商談内で見えた特徴

- `ま`（発話の頭に置くクッション。非常に頻出）
- `やっぱり`（共感・要点の強調で多用）
- `ちなみに`（追加のヒアリングに入るときの切り出し）
- `一旦`（`一旦ここまで`、`一旦ナガタさん、ここまでで`）
- `じゃあ`（話題転換）
- `結局`（要点をまとめるとき）
- `ある意味`（やわらかく言い換えるとき）
- `どうしても`（リスク・制約を正直に伝えるとき）
- `正直`（本音・デメリットを先に出すときの前置き）
- `〜という形になります` / `〜というものになります` / `〜というところですね`（締めの言い回し）
- `ありがとうございます`（顧客の発話ごとに相槌・お礼として極めて頻出）
- `素晴らしいですね` / `さすがですね`（顧客の回答をねぎらう相槌）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちの取り組み`、`私は今勉強中`、`弊社のシステム`）
- 顧客への呼び方: `〇〇さん`（`永田さん`、`ナガタさん`。商談中はさん付け）
- 福祉事業所に対しては `御社` `法人` と呼ぶ

## メール反映の定型

- `ま、〇〇というところですね`（要点の着地）
- `やっぱり〇〇が大事だと思っております`（共感を挟んだ主張）
- `どうしても〇〇はあるので`（リスク・制約を正直に置く）
- `〇〇させていただければと思います`（依頼・提案の柔らかい着地）
- `ちなみに〇〇はいかがですか`（次のヒアリングへの橋渡し）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`おそらくなかったんじゃないかなと思いますね`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: `〜できればと思います` / `〜できたらと思います` の形で頻出 → 提案・案内の着地に1通1回まで自然に使える
- `見ていただけると`: あり（費用感の説明で `〜ぐらいかな、見ていただけると` と使用）→ 資料・数字の案内で1回まで自然に使える。依頼文の途中で止めない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず稼げる` `絶対に賃金が上がる` などは不可。商談でも `すぐ稼ぎたい人には向かない` `そんなに売れない` と正直に話しているので、メールでも `〜という方が多いです` 程度に留める）
- 過度な美文
- 顧客感情の断定
