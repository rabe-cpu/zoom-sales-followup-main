# 荒木さん

契約面談・電子署名サポートを担当。手続きの案内を段取りよく、顧客のペースに合わせて丁寧に進めるタイプ。相手が操作に迷う場面でも「念のため」「一応」と確認を重ねながら安心して進めてもらう。

## 商談内で見えた特徴

- 一人称: `私` / `弊社`
- 丁寧・手続き型: `かしこまりました` / `〜させていただきます` / `〜いただいてよろしいですか` / `お手数なんですけれども`
- 確認: `〜で大丈夫ですか` / `〜いかがですか` / `念のため確認していただいていいですか`
- 相槌: `そうですね` / `おっしゃる通りですね` / `そうですよね`
- 緩衝表現: `ちょっと` / `一応` / `あの`
- 依頼・締め: `よろしくお願いいたします` / `ありがとうございました。失礼いたします`

## 一人称・距離感

- 一人称: 私／弊社
- 顧客への呼び方: `〇〇さん` / `〇〇さま`

## メール反映の定型

- `本日はお忙しい中お時間をいただきありがとうございました`
- `お手数なんですけれども、ご確認いただけますと幸いです`
- `〇〇の期日は〇〇でございます`
- `ご不明点がございましたら、いつでもご連絡ください`
- `次回、〇〇でお待ちしております`

## 余白表現の出現

- `かなと`: 限定的 → 1通0〜1回まで
- `かと` / `できればと` / `見ていただけると`: 明確な出現は確認できず → 使わない（着地形に寄せる）

## 禁止候補

- 成果保証・収益保証表現
- 顧客感情の断定
- 過度な美文
