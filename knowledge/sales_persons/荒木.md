# NEXT 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。相手の話を受けるたびに置く）
- `ま` / `まあ`（やわらげる時のフィラー。多用）
- `ちょっと`（依頼・確認をやわらげる時に前置き）
- `じゃあ` / `では` / `とで`（話題転換・進行の合図）
- `〜させていただく`（`お話務めさせていただく`、`ヒアリングをさせていただく`、`お渡しできるかと`）
- `なので` / `という形になります`（説明の着地）
- `大切にさせていただきながら`（相手の理念・ビジョンを受け止める言い回し）
- `いかがですか` / `〜してもよろしいですか`（確認・許可取り）
- `恐縮なんですが` / `すいませんね`（時間や依頼への配慮）
- `かしこまりました`（了承の返し）

## 一人称・距離感

- 一人称: 私 / 私の方で / 私たち / 弊社（`私の方で』、『私たちの取り組み`、`弊社自体は`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 相手の事業理念・利用者への思いを受け止め、`一緒に大切にさせていただきながら` と伴走する姿勢を言葉にする

## メール反映の定型

- 冒頭は御礼から入る（`ご参加いただきありがとうございます`）
- `〜させていただければと思います`（依頼・提案の着地）
- `〜という形になります` / `〜になります`（仕組みの説明の締め）
- 相手の目的を受け止める：`やりがいの提供`、`新しい収入源の確保`、`作業内容` のように相手が話した論点を言い直して整理する
- 依頼・確認は許可取りの形：`〜してもよろしいですか`、`〜いかがですか`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`検討材料であのお渡しできるかと思いますので`）→ 1通あたり0〜1回までOK
- `かなと`: 単独での明確な出現は確認できず → 無理に足さない
- `できればと`: 荒木さんの発話としては未確認 → ネクストアクションは `〜させていただければと思います`、`ご返信いただけますと助かります` で着地させる
- `見ていただけると`: 出現なし → 使わない
- `〜ればと`（言いさし）: あり（`務めさせていただければと。`）→ 冒頭の温度感や軽い提案でのみ、1通に1回まで

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず収益が出る`、`絶対に工賃が上がる` などは使わない。商談では収益に天井がある点・出品数で規模が決まる点も率直に説明しているため、メールでも保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 福祉制度・報酬改定・審査などを断定で書くこと（`確認前提` `〜と伺いました` で留める）
