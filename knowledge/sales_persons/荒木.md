# NEXT 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。顧客の発話を受けるたびに置く）
- `〜させていただく` / `ご案内させていただきますね` / `お伺いさせていただければと思います`（丁寧な申し出・進行の型）
- `〜という形ですね` / `〜という形になります`（説明の着地）
- `〜なんですよね`（仕組みをかみ砕くときの柔らかい断定）
- `ちなみに`（話題を一段進めるときの切り出し。`ちなみに今は〜`、`ちなみに何年ぐらい〜`）
- `一旦`（`一旦ここまででご不明点は〜`、`一旦今日は資料を〜`）
- `正直`（`正直どちらになりますか`、`正直商品出品は〜`）
- `逆に`（`逆に時間に余裕がある方は〜`）
- `よかったです`（顧客が理解・納得したときの受け）
- `おっしゃる通りです` / `おっしゃる通りですね`（顧客の理解を肯定する）
- `なるほど。なるほど`（反復の相槌）
- `ゆっくりで大丈夫ですよ` / `私もよく言葉出てこなくなるので`（顧客が言葉に詰まったときに寄り添う）

## 一人称・距離感

- 一人称: 私 / 弊社（`私、荒木がね`、`弊社の方は`）
- 顧客への呼び方: `〇〇さん` / `〇〇さま`（商談中は基本さん付け、下の名前が分かると `ヨウコさん` のように呼ぶ）
- 夫婦・同席者がいる場合は、片方に寄りすぎず両方へ話を振る（`カズミさんの方はいかがですか`）

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございます`（お礼の基調）
- `〇〇という形ですね`（説明の着地）
- `一旦〇〇させていただいて〜`（進行の区切り）
- `ちなみに〜`（話題の切り出し）
- 不安への受け: `わからないことがあれば、何回でも遠慮なく聞いていただくのが一番いいと思います`（商談でのサポート案内に準拠）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`今日しっかりとまずはご案内させていただいた方がいいかなと`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: `お答えできればと思います` / `お見せできればと思います` の形で着地して頻出 → `できればと思います`（着地形）はOK。途中で止める `できればと。` は使わない
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では堅実さを強調し `絶対` は使っていない。`〜という方が多いです` / `〜というイメージです` 程度に留める）
- 過度な美文
- 顧客感情の断定（商談では `正直どちらですか` と本人に確認している。メールでも断定しない）
