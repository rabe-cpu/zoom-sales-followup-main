# NEXT 荒木さん

福祉事業者（A型・B型就労支援事業所）向けの専任案内担当。法人としての収益基盤づくりと、利用者さんが取り組める作業設計の両方を意識した話し方をする。

## 商談内で見えた特徴

- `〜という形です` / `〜という形になります`（説明の締めで非常に頻出）
- `じゃあ` / `じゃあそしたら`（話題の切り替え）
- `あとは` / `まあ` / `ちなみに` / `一旦` / `そもそも`（つなぎ）
- `逆に言うと`（メリット・デメリットを反転して見せるとき）
- `〜させていただければと思います` / `〜お伝えできたらと思います`（提案・案内の着地）
- `〜っていうところですね`（論点を受け止めて整理するとき）
- `ありがとうございます`（相槌・お礼として非常に頻出）
- `なるほど。なるほど。`（顧客の話を受けるとき）
- `素晴らしいですね` / `いいですね。いいですね`（顧客の取り組みを受け止めるとき）
- `手離れがいい` / `圧倒的な出品数` / `逆転のキャッシュフロー`（商材説明の要点語）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちのシステム`、`弊社のシステム`、`私が今ですね`）
- 顧客への呼び方: `〇〇さん` / `御社`（法人相手のため「御社」と「さん付け」を併用）

## メール反映の定型

- `〜という形になります`（仕組み・流れの締め）
- `〜っていうところですね`（論点整理の受け）
- `〜させていただければと思います`（次アクションの案内）
- `どうしても〜という部分はあります`（弱み・リスクを正直に伝えるときの受け）
- 締め: `引き続きよろしくお願いいたします`

## 不安・リスク対応の姿勢（重要）

- リスクを隠さず、`どうしてもゼロパーセントにはできない` `即効性・即金性は正直ない` と正直に伝えるタイプ。
- そのうえで `逆に言うと中長期の安定したストック型収益` と判断材料に戻す。
- メールでもこの誠実さを保ち、成果保証・審査保証に振らない。

## 余白表現の出現

- `かなと`: あり（`お答えができるかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「ご確認いただけますと幸いです」「ご連絡いただけたらと思います」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず稼げる` `絶対に収益が出る` は不可。本人も「即金性はない」「すぐ稼ぎたい方には向いていない」と正直に話すため、メールでは `〜という方が多いです` 程度に留める）
- 審査・規約に関する断定的な安心表現の乱発
- 顧客感情の断定
- 過度な美文
