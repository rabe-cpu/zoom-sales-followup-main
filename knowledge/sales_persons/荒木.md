# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（受け止め・ねぎらいで多用）
- `かしこまりました` / `恐れ入ります` / `左様ですか`
- `おっしゃる通りです`
- `もちろんですよ` / `もちろんできますよ`（即応の肯定）
- `ご安心ください`
- `お気軽に` / `気軽にまた聞いてください`（相談導線）
- `一応` / `基本` / `割と` / `結構`
- `お手数なんですが` / `お手数ですが`（依頼のクッション）
- `素晴らしいですね` / `嬉しい`（顧客の行動を承認する）
- `ま、` / `えっと`（会話のフィラー。メールでは落とす）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社
- 顧客への呼び方: `〇〇さん`（さん付け中心）
- ねぎらいを先に置く傾向（例：「お仕事終わりのお疲れのところ」「貴重なお時間」）

## メール反映の定型

- `〜させていただきます` / `〜いただけたらと思います`
- `お手数なんですが、〜いただけますでしょうか`
- `何かあれば、お気軽にお問い合わせください`
- `ご安心ください`（根拠とセットで。単独の空安心は避ける）
- 承認：`しっかりご確認いただき、ありがとうございます`
- 締め: `今後ともぜひよろしくお願いいたします` / `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`〜かなっていうところですね`、`〜かなと思います`）→ 1通あたり0〜1回までOK
- `かと`: 直接の多用は確認できず → 文末で多用しない
- `できればと`: 直接出現は確認できず → 使わない
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（発話に確認なし）
- 過度な美文
- 顧客感情の断定
- 空の安心表現（`大丈夫です` だけで根拠を示さない）

- 今回の抽出元は契約・納品（お申込後サポート面談）であり、検討を促す商談ではない。
- サポート寄りの温かい口調が強く出ている。個別相談会（新規商談）での依頼・クロージング表現は別途サンプルが必要。
