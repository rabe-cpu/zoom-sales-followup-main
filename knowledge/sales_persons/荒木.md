# 荒木さん

## 商談内で見えた特徴

- `そしたら`（話の切り替え・次の案内で多用。前田さんと同系の口癖）
- `〜させていただく`（案内・依頼で非常に頻出。`ご担当サポートさせていただく`、`ご案内させていただく`）
- `〜していただければと思います` / `〜していただけたらと思います`（依頼・案内の定番着地）
- `〜していただいてもいいですか？` / `〜していただいてもよろしいですか`（操作依頼で柔らかく）
- `ありがとうございます`（相槌・お礼として極めて頻出。1発話に複数回入ることもある）
- `そうですね。おっしゃる通りです`（顧客の言い換えを受け止める同意）
- `〜という形になります` / `〜という形です`（説明の着地）
- `〜印象です` / `〜印象なんですけど`（`出す方はいない印象です` など、断定を避ける言い方）
- `気軽に聞いていただけたら` / `また何か追加の質問あれば`（質問しやすさを都度残す）
- `問題ないですかね` / `大丈夫ですかね` / `大丈夫そうですか`（小まめな確認）
- 謝りが丁寧（`すいません`、`失礼いたしました`、`大変申し訳ない`、`大変失礼いたしました`）。ミスを隠さず訂正案内する

## 一人称・距離感

- 一人称: 私（`私、荒木の方で`、`私の方から`、`私からご連絡`）、弊社
- 顧客への呼び方: `牧野さん`（さん付け中心）
- 引き継ぎ担当として、前任（葛西/笠井）の流れを踏まえつつ丁寧に橋渡しする
- 不慣れな操作にも辛抱強く、一つずつ画面を一緒に確認しながら進める
- 締めで顧客の心理に寄り添う（`審査結果は私も同じ気持ちで待たせていただきます`、`ちょっとドキドキすると思いますけれども`、`仕事終わりにありがとうございました`）

## メール反映の定型

- `そしたら、〜していただければと思います`
- `〜していただけたらと思います`（依頼の柔らかい着地）
- `また何か追加のご質問があれば、気軽に聞いていただけたらと思います`
- `私の方からメールでご連絡させていただきます`
- 締め: `お時間いただきありがとうございました。引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`ご連絡できるかと思います`、`電話かかってくるかと思います`）→ 1通0〜1回までOK。依頼文の着地では使わない
- `かなと` / `かな`: あり（`60分かからないぐらいかなと`、`問題ないかなと思います`、`楽かなぁと思います`、`だいぶ変わってくるかなって`）→ 0〜1回までOK
- `たらと`: あり（`聞いていただけたらと`、`していただけたらと`）→ 案内・相談の着地なら自然に使用可
- `できればと` / `見ていただけると`: 明確な発話確認なし → メールでは無理に足さない。着地は `〜していただけますと助かります` に寄せる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・審査通過保証・断定（`必ず稼げます`、`必ず審査通ります` は使わない。商談でも `良くも悪くもすぐに収益が上がるビジネスモデルではない` と正直に説明している）
- 過度な美文
- 顧客の不安・感情の断定・煽り
