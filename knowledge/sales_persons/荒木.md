# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。顧客の発話を受けるたびに置く）
- `〜という形ですね` / `〜という形になります`（説明の締めで多用）
- `おっしゃる通りです` / `素晴らしいですね` / `いいですね、いいですね`（顧客の理解・発言を受け止める）
- `ちなみに`（質問・話題の切り出し）
- `一旦`（`一旦お電話を`、`一旦ここまでの`）
- `改めて`（`改めて、先日はね`）
- `教えていただきありがとうございます`（顧客が状況を話してくれたときのお礼）
- `ご安心ください`（`後でも見返せますのでご安心ください`。不安をほどく定番）
- `〜させていただきます` / `〜させていただければと思います`（丁寧な申し出・提案）
- `まあ`（フィラー。メールには持ち込まない）

## 一人称・距離感

- 一人称: 私 / 私達 / 弊社（`私、物販システムアクセス案内担当の荒木`、`私達の方で`、`弊社のシステム`）
- 顧客への呼び方: `安井さん` / 改まると `〇〇さま`（商談中は基本さん付け）

## メール反映の定型

- `〇〇という形ですね` / `〇〇という形になります`（説明の着地）
- `教えていただきありがとうございます`（状況共有へのお礼）
- `後でも見返せますのでご安心ください`（資料案内と安心導線）
- `ちなみに〇〇`（話題転換・追加確認）
- 申し出: `〜させていただきます` / `〜させていただければと思います`
- 依頼: `〜していただいてもよろしいですか` / `〜いただけますか`
- 締め: `よろしくお願いいたします` / `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`根掘り葉掘りお伺いするのも失礼かと思いますので`）→ 1通あたり0〜1回までOK
- `かなと`: 荒木さんの発話では確認できず（商談内の `かなと` は顧客発話）→ 使わない
- `できればと`: 単独での明確な出現なし（`できれば一本に絞っていけたら` はあるが `できればと` の形ではない）→ ネクストアクションは `いただけますと助かります` `いただいてもよろしいでしょうか` で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `成果がすごく出やすい` と語る場面があるが、メールでは `取り組まれている方が多いです` 程度に留め、収益・成果の保証表現にしない）
- 過度な美文
- 顧客感情の断定
