# 荒木さん

## 商談内で見えた特徴

- `〜させていただく`（提案・確認で多用）
- `ありがとうございます` / `かしこまりました`
- `〜と思うのでよろしくお願いいたします`
- `一旦`（`一旦失礼いたしますね`）
- `ま` / `なんか` / `こう`（やわらかいフィラー、傾聴時に多い）
- `嬉しいな` / `参考にお伺いできたら`（共感・関心の表現）
- 相手（特に福祉事業者）の事業実情を深く傾聴してから提案する進め方

## 一人称・距離感

- 一人称: 私／私たち
- 顧客への呼び方: `〇〇さん` / `〇〇さま`
- 福祉事業（A型/B型・就労支援）専任。相手の事業ビジョンと制約を尊重し、共感で信頼を作るスタイル

## メール反映の定型

- `お時間をいただきまして、誠にありがとうございました`
- `〜かと思います`
- `一旦こちらのメールにご返信いただいても問題ございません`
- `一つずつ確認させてください`
- `資料一式は改めてお送りいたします`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かと`: `〜かと思います` の形で自然に出現 → メールでも使用可（多用はしない）
- `かなと`: 限定的 → 1通あたり0〜1回まで
- `できればと`: `お伺いできたら` の形で出現 → ネクストアクションでは「〜と思います」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 過度な美文
- 顧客感情の断定
- 成果・収益・審査の保証表現
