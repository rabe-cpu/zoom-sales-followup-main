# 荒木さん

## 商談内で見えた特徴

- `恐れ入ります` / `恐縮です` / `お手数なんですけれども`（労い・丁寧な前置き）
- `ありがとうございます`（応答ごとに頻出）
- `〜させていただきます` / `〜させていただいて`
- `〜という形になります` / `〜という形です`
- `〜していただいてもいいですか` / `〜していただけたらと思います`（やわらかい依頼）
- `もちろんですよ` / `大丈夫ですよ`（安心付与）
- `責任持って`（信頼表現）
- `かしこまりました` / `なるほど`
- `お忙しい中` / `お仕事終わりに`（相手の状況への配慮）
- `割と` / `ちょっと` / `ま`（口語のつなぎ）

## 一人称・距離感

- 一人称: 私
- 顧客への呼び方: `〇〇さん`（面談では「白倉さん」）。メールでは `〇〇さま` を基本にする。
- 距離感: 契約後・手続きサポート局面での伴走型。労いと確認を細かく挟む。

## メール反映の定型

- `お忙しい中、〇〇いただきありがとうございます`
- `しっかりフォローアップさせていただきますので`
- `〇〇していただけたらと思います`
- `何かご不明点があれば、メール・お電話・LINEのいずれでも構いませんので`
- `責任を持って〇〇させていただきます`
- 締め: `引き続きどうぞよろしくお願いいたします`

## 余白表現の出現

- `かと`: 発話での明確な出現なし → 使わない
- `かなと`: ごく一部（`〜かなと思います`）→ 1通あたり0回を基本、無理に入れない
- `できればと`: 出現なし → 使わない
- `見ていただけると`: 出現なし → 使わない
- ネクストアクションは `〜していただけたらと思います` / `〜をお願いいたします` で必ず着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 過度な美文
- 顧客感情の断定
- 審査・与信の結果を断定する表現（`必ず通ります` など）
