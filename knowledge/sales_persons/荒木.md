# 荒木さん

> 注意: 初回登録時の参照商談は「輸出マスター（無在庫輸出）」の法人向け相談会。
> アクセス物販（副業・個人）とは商材・顧客層が異なる。口調は共通で使えるが、
> 作業時間・家族相談・副業前提の言い回しはそのまま流用しない。

## 商談内で見えた特徴

- `〜という形になります` / `〜という形です`（締めの言い回し。非常に頻出）
- `ちなみに`（話題を足す／確認を挟むときの接続。多用）
- `一旦`（`一旦、じゃあここまでで`。区切りの接続）
- `逆に`（`逆に今回は在庫を抱えない`）
- `〜させていただく`（`ご案内させていただく`、`お見せさせていただく`、`確認してご連絡させていただいて`）
- `ありがとうございます` / `教えていただきありがとうございます`（相槌・お礼として非常に頻出）
- `素晴らしいですね` / `さすがですね` / `流石ですね` / `話が早くて助かります`（顧客を立てる相槌）
- `かしこまりました` / `承知いたしました`（依頼を受けるときの定番）
- `全然〇〇できます` / `大丈夫です`（不安をほどくときの受け止め。`発送しなくて大丈夫ですよ`）
- `できるだけ早めに` / `できるだけ本日中に`（約束のスピード感）

## 一人称・距離感

- 一人称: 弊社 / 私 / 私たち / 私自身
- 顧客への呼び方: `〇〇さま` / `〇〇様`（丁寧側に寄せる）

## メール反映の定型

- `〇〇という形になります`（説明の着地）
- `ちなみに〇〇`（確認や補足の切り出し）
- `確認のうえ、改めてメールでご連絡させていただきます`（宿題の返し方）
- `できるだけ早めにお送りします`（スピード感のある約束）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`ご挨拶が先かと思いますので`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`しっかりとお伝えできればと思いますけれども`、`ご用意できればと思います`）→ 1通あたり0〜1回までOK
- `かなと`: 荒木さんの発話での明確な確認は薄い（`かな` は顧客側に多い）→ 使わない
- `見ていただけると`: 出現なし → 使わない

> 注意: 1通の中で `かと`・`できればと` を合わせて2回以上続けない。片方1回までに抑える。

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益断定（荒木さん自身が商談中に「絶対売り上げ上がりますとは法律的にお伝えできない」と明言。メールでも `必ず`／`絶対儲かる` は使わず、`やっていただければ〜という方が多い` 程度に留める）
- 過度な美文
- 顧客感情の断定
