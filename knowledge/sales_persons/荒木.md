# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（受け止めのたびに多用）
- `結論、〜`（先に結論を出してから説明する）
- `おっしゃる通りですね`
- `ご安心ください`
- `〜させていただきます` / `〜させていただく`
- `〜かなと思います` / `〜と思いますので`
- `気軽に聞いていただけたら` / `ご相談いただければと思います`
- `ぜひ〜いただけたらと思います`
- `一旦` / `念のため` / `ちなみに`
- `よかったです`（確認が取れたときの相づち）

## 一人称・距離感

- 一人称: 私／弊社／私たち
- 顧客への呼び方: `〇〇さん` / `〇〇さま` 併用（本文宛名は `さま`）

## メール反映の定型

- `ご確認いただきありがとうございます`
- `何か思い浮かんだら気軽に聞いていただけたらと思います`
- `〜についてはご安心ください`
- `ぜひサポートを活用いただけたらと思います`
- `今後ともどうぞよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`楽かなと思います`、`問題ないかなと`）→ 1通あたり0〜1回までOK
- `かと`: 直接の多用は確認できず → 文末で多用しない
- `できればと`: 直接出現は確認できず → ネクストアクションは「お待ちしております」「ご相談ください」で着地
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証に聞こえる断定
- 過度な美文
- 顧客感情の断定
