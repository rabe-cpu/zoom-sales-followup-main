# NEXT 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・区切りごとに非常に頻出。顧客が一言返すたびに受け止める）
- `そうですね` / `そうなんですよね`（共感・肯定の相槌）
- `大丈夫ですよ` / `全然大丈夫です`（不安をほどく定番。`見られてなくても進められるので大丈夫`）
- `ご安心ください`（持ち帰り回答時などの安心づけ）
- `〜という形ですね` / `〜という形になります`（説明の着地）
- `〜かなと思います` / `〜かなと`（やわらかい推量。多用）
- `〜していただければと思います` / `〜していただきたいと思います` / `〜していただけたらと思います`（依頼・案内の着地）
- `ぜひぜひ`（前向きな促し）
- `おっしゃる通りです`（顧客の理解を肯定）
- `よかった。よかった`（問題が解けたときの安心共感。繰り返す）
- `気軽に` / `ダメもとで一旦相談`（相談導線を低いハードルで残す）
- `ちょっと` / `まあ` / `あの`（会話のクッション。多め）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私からも一応サポートに伝えておく`、`私たちの方でもお伝えしています`）
- 顧客への呼び方: `小野寺さん` など `〇〇さん`（さん付け）
- 伴走型。わからない操作を一つずつ画面共有で確認し、顧客の自己完結・我慢を防いで「気軽に聞いてください」と繰り返す丁寧なサポートスタイル
- 仕事の電話で中座する顧客にも `出ちゃって大丈夫ですよ`、`全然大丈夫ですよ` と急かさない

## メール反映の定型

- `〜という形ですね` / `〜という形になります`（手順・仕組みの着地）
- `まずは〇〇から進めていただければと思います`
- `わからないことは、お問い合わせ・お電話・オンライン予約で気軽にご相談いただければと思います`
- `見慣れないと思いますが、最初だけなので〜`（安心づけ）
- 締め: `引き続きよろしくお願いいたします` / `今日も貴重なお時間ありがとうございました`

## 余白表現の出現

- `かなと`: あり（`わかりやすいかなと思います`、`一番の手かなと`、`質がいいと思います` 系）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: `できれば〜参加いただいて`、`できれば〜していただけたらと思います` の形 → 着地として自然に使用可。ただし依頼文を曖昧に止めない
- `見ていただけると`: `ご覧いただけたらと思います`、`見ていただきたいなと思います` の形で頻出 → `ご覧いただけますと助かります` 等の着地ならOK

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`絶対できます`、`必ず稼げます`）→ 商談では `日本の方ならしっかり準備物を揃えれば5日ぐらいで終わる方もいます` と事実ベースで話しており、保証にはしない
- 過度な美文
- 顧客感情の断定・煽り
