# 荒木さん

## 商談内で見えた特徴

- `はい、ありがとうございます`（顧客の発話を受けるたびに挟む）
- `〜っていうところ(ですね)`
- `〜という形です(ね)`
- `しっかり(と)〜させていただく`
- `大事になってくる` / `肝になってくる`
- `ご案内させていただく` / `お伝えできたらと思います`
- `ここまでで何か気になるところとか疑問っていうのはいかがですか`（区切りごとの確認）
- `疑問点` / `懸念点` / `気になるところ`
- `まあ` / `ちょっと` / `一旦`
- `そうですよね`（顧客への共感）
- `〜かなと思います`（`妥当かな`、`望ましいかな`、`ちょうどいいかな`）
- `逆に` / `ちなみに`

## 一人称・距離感

- 一人称: 私
- 顧客への呼び方: `北本さん` / `北本さま` 併用、法人相手では `御社`
- 相手が法人・事業者のため、個人の感情より「御社の判断材料」を優先して話す距離感

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `疑問点や気になるところを一つずつ確認させてください`
- `〜のところをしっかりご案内させていただければと思います`
- `お渡しした資料をご覧いただいたうえで`
- `追加のご質問が出てくることも多いので、次回そのお時間をご用意させていただければと思います`
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと` / `かな`: あり（複数回）→ 1通あたり0〜1回までOK
- `かと`: 限定的に出現（`〜行く方がいいかと`）→ 文末で多用しない
- `できたらと` / `できればと`: あり（`お伝えできたらと思います`）→ ネクストアクションでは「ご用意させていただきます」「お送りいたします」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証に聞こえる断定（`必ず稼げます` 等）
- 過度な美文
- 顧客感情の断定
