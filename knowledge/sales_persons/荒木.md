# 荒木さん

## 商談内で見えた特徴

- `結論からお伝えすると` / `結論、〜`（切り出しの口癖。複数回）
- `ありがとうございます`（顧客の質問・発言への相槌として非常に頻出）
- `〜という形です` / `〜というものになります` / `〜になります`（説明の締め）
- `〜と思っていただければと思います`（説明の着地）
- `〜させていただきます` / `ご案内できればと思います` / `お見せできればと思います`（依頼・提案の言い回し）
- `かしこまりました`（承諾）
- `ま、` `あの` `えっと` `ですね`（つなぎ語、多め）

## 一人称・距離感

- 一人称: 私 / 弊社
- 顧客への呼び方: `〇〇さん`

## メール反映の定型

- `結論からお伝えすると、〇〇です`（要点を先に出す）
- `〇〇という形です` / `〇〇というものになります`（説明の締め）
- `〇〇と思っていただければと思います`
- 依頼・提案: `〇〇をご案内できればと思います` / `〇〇をお見せできればと思います`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: 明確な出現なし → 使わない
- `かなと`: 明確な出現なし → 使わない
- `できればと`: `ご案内できればと思います` `お見せできればと思います` の形で出現 → ネクストアクションの提案で0〜1回までOK。ただし文を途中で止めず `〜できればと思います` と着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- 成果保証・断定（`ノーリスク` `儲けしかない` と受け取られる表現。無在庫でもAmazon手数料・送料・返品はかかる事実を隠さない）
- 送料・費用の断定（商談では送料表を提示できず、具体数字を即答できない場面があった。メールでは概算・条件つきで書き、断定しない）
- 過度な美文
- 顧客感情の断定
