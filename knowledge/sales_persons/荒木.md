# 荒木さん

## 商談内で見えた特徴

- `〜という形です` / `〜という形になります`（説明の着地・締めで非常に頻出）
- `そうです。そうです、おっしゃる通りですね`（顧客の理解を受け止める相槌）
- `そうですね`（クッション・同意）
- `ありがとうございます`（相槌・お礼として頻出。顧客が答えるたびに挟む）
- `かしこまりました`（受け止め・区切り）
- `ご安心ください`（不安への受け止め）
- `割と`（副詞。`割と皆さん`、`割と信頼につながる`、`割と早い`）
- `ま、` / `まあ`（話し始めのクッション）
- `ぶっちゃけ`（砕けた本音を出すときに少量）
- 確認の投げかけ: `気になるところとか懸念事項はありますか？`、`〜で大丈夫ですか？`、`イメージできてますか？`

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちの中で`、`弊社にいただく`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `〇〇という形になります`（仕組み・条件の着地）
- `おっしゃる通りです`（顧客の理解を肯定）
- `〇〇という意味では、安心材料としてお付けしています`（保証・サポートの受け止め）
- `気になる点があれば、ラインでもお送りいただければと思います`（相談導線）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`〜かなと思います`、`〜になってくるかなという形`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 出現なし → ネクストアクションは「いただければと思います」「ご連絡いただけますと助かります」で着地させる
- `見ていただけると`: 明確な出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `成果が出せると思ってます` と語る場面があるが、メールでは `〜という方が多いです` / `安心材料としてお付けしています` 程度に留め、保証表現にしない）
- 過度な美文
- 顧客感情の断定
- 募集期限・キャンペーンで急かす表現（商談では期限に触れるが、メールでは急かしにならないよう「合うタイミングで」の姿勢に寄せる）
