# NEXT 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（最頻出。顧客の発言・質問・相槌のほぼ毎回に置く受けの言葉）
- `おっしゃる通りです` / `おっしゃってくださった`（顧客の理解を肯定して受ける）
- `正直`（誠実に開示する前置き。`正直、即日性・速効性はない`、`正直ちょっと難しい`、`正直〜なんですよね`）
- `〜という形です` / `〜という形になります`（説明の着地）
- `〜かなと思います` / `〜かと思います`（見立て・提案の柔らかい着地）
- `〜できればと思います`（案内・締めの定番。`ご案内できればと思います`、`お話できればと思います`）
- `〜させていただきます` / `ご案内させていただきます`（依頼・案内のへりくだり）
- `かしこまりました` / `承知いたしました`（受けの定番）
- `まあ` / `ま、`（説明をやわらげるフィラー）
- `そうですね` / `そうなんですよね`（共感の相槌）
- `ぜひ` / `引き続きよろしくお願いいたします`（締めの前向き表現）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちのシステム`、`弊社のパートナーさん`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま`）
- 役割: 相談・契約まわりの専任担当（他商談では契約最終確認の担当としても登場）。リスクや条件を隠さず正直に開示する姿勢が強い。

## メール反映の定型

- `〇〇かなと思います`（見立て・提案の着地）
- `〇〇できればと思います`（案内・次回接点の締め）
- `〇〇させていただきます`（案内・送付のへりくだり）
- `おっしゃる通りで〜`（顧客の理解を受けてから補足する）
- `正直に申し上げると〜`（メリットだけでなく条件・注意も誠実に添える）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`現実ラインだと思っております`系・`〜かなと思います`）→ メールでは1通あたり0〜1回までに抑える
- `かと`: あり（`出てこないかと思います`）→ 発話準拠で少量OK
- `できればと`: あり（`ご案内できればと思います`）→ 案内・締めで自然に使える
- `見ていただけると`: 単独の明確な出現は確認できず（`お見せできれば`、`ご覧いただく`は使用）→ 着地は `ご覧いただけますと助かります`／`ご確認いただければと思います` に寄せる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（本人は商談で `絶対に売り上げ上がるとは言えない`、`良くも悪くも現実的`、`正直〜`とリスクを誠実に開示している。メールでも `〜という方が多いです`／`目安として`に留め、`必ず`／`確実に儲かります` のような保証表現にしない）
- 過度な美文
- 顧客感情の断定
- あおり・急かし（期限や特典を圧として使わない。本人も `募集を続けている限りご案内します` と長期目線で対応している）
