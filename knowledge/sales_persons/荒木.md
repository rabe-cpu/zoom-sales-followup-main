# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（お礼・相槌として非常に頻出。相手が話すたびに受け止める）
- `なるほど。なるほど。`（相槌の重ね。理解を示すときの口癖）
- `確かに` / `確かにそうですよね`（共感の受け止め）
- `一旦`（話を仕切り直すときの接続。`そしたら一旦こう職員さんも増やすための`）
- `逆に`（角度を変えるときの接続。`逆にこう一般就労`）
- `ちなみに`（費用や条件を切り出すときの前置き。`ちなみにかかってくる費用というのが`）
- `そしたら` / `じゃあ`（次の話題へ進むときの切り出し）
- `〜させていただく`（`ご案内させていただく`、`お伝えさせていただきました`、`持ち帰らせていただいて`、`教えていただいて`）
- `〜と思うので` / `〜と思ってます` / `〜と思っております`（自分の見立ての着地）
- `全然大丈夫ですよ` / `大丈夫ですよ`（相手の遠慮・不安をほどくときの受け）

## 一人称・距離感

- 一人称: 私（`私が一番大切にしているのが`、`私もそれは感じます`、`私の方で`）、改まると 弊社（`弊社の場合は輸入だけじゃなくて`）
- 顧客への呼び方: `〇〇さん` / `〇〇様`（商談中は基本さん付け、担当者は名字で呼ぶ）
- 課題解決を先に置く姿勢（`私が一番大切にしているのが、やっぱりこう課題解決`）。物腰はやわらかく、相手の発言を長めに受けてから自分の見立てを短く返す

## メール反映の定型

- 冒頭で相手の話を受け止める（`具体的にあげていただいて、ありがとうございます`）
- `一旦〇〇して`、`逆に〇〇`、`ちなみに〇〇` で段落をつなぐ
- `〇〇かなと思っています`（見立ての着地）
- 不安対応: `気になる点があれば全然大丈夫ですので`
- 依頼: `お伝えいただけたらと思います`、`ご検討いただけたらと思います`、`お時間いただくことって可能ですか`、`よろしくお伝えいただいてもいいですか`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと` / `かな`: あり（`集客全然変わってくるかなと`、`役に立っていくんじゃないかなと`、`強いのかなと思っています`）→ 1通あたり0〜1回までOK
- `かと`: 弱い出現あり（`いい距離感だったりするかと`）→ 使うなら1通1回まで、依頼文の着地には使わない
- `できればと`: あり（`オンラインできればと思うので`）→ 冒頭の温度感や軽い提案でのみ少量OK
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず成果が出ます`、`稼げます`。商談では収益の目安や返金保証を説明するが、保証表現はメールに残さない）
- 顧客感情の断定（相手の不安を決めつけない。荒木さんは`いかがですか`と相手に確認してから受ける）
- 過度な美文・報告書調
