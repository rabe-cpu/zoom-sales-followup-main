# NEXT 荒木さん

## 商談内で見えた特徴

- `結論、〇〇です`（要点を先に出す口癖。`結論、スマホ、タブレット、パソコン全部使えます`、`結論あるんですけれども`）
- `ちなみに`（質問の切り出しで多用。`ちなみに一つの収益の柱としては`、`ちなみにアマゾンでお買い物とかされますか`）
- `ありがとうございます`（相槌・お礼として非常に頻出。ヒアリングの受けで多用）
- `なるほど、ありがとうございます`（顧客の話を受け止める定番）
- `〜していきませんか`（提案の誘い方。`新しい収益性をネットショップで作っていきませんか`、`一つの収益の柱にしていきませんか`）
- `〜というものになります` / `〜という形です` / `〜になりますね`（説明の締め）
- `かつ`（利点を重ねる接続。`かつ利益が得やすい`、`かつ物価高なので`）
- `〜させていただければと思います` / `〜させていただいて大丈夫ですか`（丁寧な許可取り・BtoB寄り）
- `めちゃめちゃ共感するんですけど`（顧客の価値観に寄り添う一言）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社 / 本社（`私の方で`、`私たちがどんなご提案`、`弊社自身が`）
- 顧客への呼び方: `〇〇さん`（法人担当者へさん付け）。※本商談では相手の姓を複数回言い間違えている（深澤→荒川/中沢/福田等）。メールでは正しい宛名（深澤さま）を固定し、社名・担当名は送付前に必ず確認する。

## メール反映の定型

- `結論、〇〇です`（要点を先に出す）
- `〇〇していきませんか`（新しい収益の柱・取り組みの提案）
- `〜というものになります`（説明の締め）
- `ちなみに〇〇はいかがですか`（次の確認への切り出し）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: `〜させていただければなと思います` の「なと」はあり → 1通あたり0〜1回までOK。`かなと` 単独の多用はしない
- `かと`: 明確な出現なし → 使わない
- `できればと`: `できれば` の接続はあるが、依頼文を途中で止める `できればと。` の形はなし → ネクストアクションは「いただけますと助かります」「ご都合いかがでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `絶対に埋まらない` のように強い言い方をする場面があるが、メールでは `〜という形が多いです`、`〜が見込めます` 程度に留め、収益保証にしない）
- `トリック`（キャッシュフロー説明で口頭では使うが、メールでは使わない）
- 顧客が言っていない事実・感情の断定
- 福祉利用者・スタッフの状態を勝手に断定する表現
