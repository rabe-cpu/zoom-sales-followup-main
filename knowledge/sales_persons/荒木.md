# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます` / `教えていただいてありがとうございます`（お礼を丁寧に重ねる）
- `とんでもないです`（顧客の恐縮・質問への謙遜の受け）
- `〜という形です` / `〜という形になります`（説明の着地）
- `ご案内させていただく` / `お伝えさせていただく` / `お送りさせていただく`
- `しっかり` / `一応` / `ちょっと` / `ちなみに` / `逆に`
- `よかったです`（顧客が理解・納得した反応への受け）
- 堅実 / 着実 / コツコツ / 中長期的 を重視する言い回し
- リスク・デメリットも正直に先に伝える（`一応その部分のリスクは皆さんにお伝えしております`）
- `ホワイトなやり方` / `規約に則った` という安心軸

## 一人称・距離感

- 一人称: 私／私たち（弊社）
- 顧客への呼び方: `宮城さん`（会話では「さん」中心）／メールでは `宮城さま`

## メール反映の定型

- `本日はお忙しい中、貴重なお時間をいただきありがとうございました`
- `後ほど改めて資料をお送りさせていただきます`
- `気軽にご連絡ください` / `遠慮なくおっしゃってください`
- `しっかりと検討材料を揃えていただけるようにご案内させていただきます`
- `引き続きよろしくお願いいたします`
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`ご挨拶が先かと思います`、`お話しさせていただきたいかと思います`）→ 1通あたり0〜1回まで
- `かなと`: あり（`まずはいいのかなと`、`聞いていただくといいかな`）→ 1通あたり0〜1回まで
- `できればと`: あり（`ご案内できればと思う`、`お渡しできればと思っております`）→ ネクストアクションでは「お送りさせていただきます」「ご案内させていただきます」で着地させる
- `見ていただけると`: 直接出現は確認できず → 使わない。「ご覧いただけますと助かります」で着地

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証の断定（`必ず戻ってくる`等は資料・制度説明の範囲にとどめる）
- 顧客感情の断定
- 過度な美文
