# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（受け止め・相づちで多用）
- `ご案内させていただきます` / `お伝えさせていただきます`
- `〜という形になります` / `〜という形ですね`
- `ご安心ください`
- `ちなみに`
- `一旦`
- `逆に`
- `さすがですね` / `いい質問ですね` / `素晴らしいですね`（顧客を立てる）
- `私も正直パソコンが得意な方ではなかった`（自己開示でハードルを下げる）

## 一人称・距離感

- 一人称: 私
- 顧客への呼び方: `〇〇さま` / `〇〇さん`（商談では「玉山さん」）
- 物販歴14年・案内担当歴のプロとして、わかりやすさと安心感を前に出す

## メール反映の定型

- `本日は貴重なお時間をいただきありがとうございました`
- `〜をお伝えさせていただきます`
- `ご不明点が出てきましたら、お気軽にご連絡ください`
- `ご安心ください`
- `一旦〜まで、改めて次回ご案内させていただきます`
- `ご都合のよいタイミングで〜いただけますと助かります`

## 余白表現の出現

- `かと`: あり（例: `最初はちょっと失礼かと思うので`）→ 1通あたり0〜1回まで
- `かなと`: あり（例: `メモしていただけるといいかなと` / `横の方が見やすいかなと` / `一番楽かなと思います`）→ 1通あたり0〜1回まで
- `できればと`: 商談では未確認。依頼文は途中で止めず着地させる

## 禁止候補

- `伝わってまいりました`
- 成果保証・収益保証に聞こえる断定
- 顧客が言っていない不安・感情の断定
- 発話にない過度な美文・丁寧語
