# NEXT 荒木さん

## 商談内で見えた特徴

- `そしたら` / `そしたらですね`（話題の切り替え・進行の口癖。非常に頻出）
- `えっと` / `えーと`（話し始めの口癖）
- `一応`（念のための前置き。`一応そこは`、`一応ね`）
- `ちょっと`（依頼・お願いをやわらげるクッション。`ちょっとお待ちくださいね`、`ちょっとお写真撮っていただいて`）
- `まあ` / `まぁ`（断定をやわらげる）
- `ちなみに`（確認質問の切り出し。`ちなみに〜ですかね`）
- `改めて`（`改めてよろしくお願いいたします`）
- `全然`（`全然大丈夫ですよ`、`全然いらっしゃる`。不安をほどくときに多用）
- `ありがとうございます`（相槌・お礼として極めて頻出）
- `助かります`（相手の協力への労い。`教えていただいてありがとうございます`、`事前にご記入いただいてありがとうございます`）

## 一人称・距離感

- 一人称: 私 / 私たち（改まると 弊社）。`私の方で`、`私からも確認してみる`
- 顧客への呼び方: `〇〇さん` / `〇〇さま`（さん付け中心、文面ではさま）
- 姿勢: 低姿勢で `すいません` `申し訳ありません` `恐れ入ります` を多用するが、冷たくならず労いとセット。お疲れ・お忙しさへの気遣いが厚い

## メール反映の定型

- 依頼: `〜していただけたらと思います` / `〜していただいてもいいですか(ね)` / `〜していただけると助かります` / `お願いいたします`
- 確認: `〜で間違いないですかね` / `大丈夫ですかね` / `いかがですか(ね)` / `ご不明点ありますか`
- 安心: `ご安心ください` / `全然大丈夫ですよ` / `とんでもないです` / `気軽に聞いていただけたら` / `遠慮なく` / `ゆっくりで大丈夫ですよ`
- 労い・お礼: `お疲れのところ` / `お忙しい中` / `事前にご準備いただいてありがとうございます` / `恐れ入ります`
- 締め: `よろしくお願いいたします` / `今後ともよろしくお願いいたします`

## 余白表現の出現

- `かなと` / `かなと思います`: あり（`いいタイミングでご参加いただいたかなと思いますね`、`60分ぐらいいただくかなと思います`、`気をつけていただけるといいかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`多分そこは〜かなっていうところ`、`問題ないかと`）→ 着地をぼかさない範囲で0〜1回までOK
- `できればと`: 明確な出現なし → ネクストアクションは `いただけますと助かります` `お願いいたします` で着地させる
- `見ていただけると`: 類似に `振り返っていただけると助かります` `ご覧いただけたら` あり → `ご確認いただけますと助かります` 系で着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定: 本人は「絶対100%稼げる、は逆に詐欺」とはっきり否定し、「天井はある」「やらない人は出てくる」「作業時間（出品数）が収益に直結」と率直に説明するタイプ。メールでも `必ず成果が出ます` `絶対稼げます` は使わず、`コツコツ続けていただいた方は成果を出されている方が多い` 程度の事実ベースに留める
- 過度な美文・情緒の盛りすぎ
- 顧客感情の断定（`不安ですよね` と決めつけず、`気になる点があれば` の形にする）
