# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・受け止めとして非常に頻出。顧客の発話一つひとつに対して置く）
- `かしこまりました` / `とんでもないです`（依頼・謝意への受け止め）
- `ご安心ください` / `〜で大丈夫ですのでご安心ください`（不安をほどく定番）
- `率直に` / `正直に`（`正直に率直にお伝えしていきたい`。自分の姿勢として明言する口癖）
- `しっかりと`（`しっかりとお伝えする` `しっかりと向き合いながら`）
- `一緒に考えていければと思います`（提案を押しつけず伴走する言い回し）
- `〜させていただく`（`お伝えさせていただく` `お送りさせていただく`。丁寧度が高い）
- `いかがですか`（やわらかい確認の投げかけ）
- `むしろ丁寧に理由をお伝えいただいてありがとうございます`（相手の遠慮を受け止め返す）
- メリット・デメリットを両方出すという姿勢を冒頭で宣言する

## 一人称・距離感

- 一人称: 私 / 荒木（`私、荒木の方から`）、弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。メールでは `〇〇さま`）
- 温度感: 丁寧で柔らかい。安心させることを最優先にする

## メール反映の定型

- `本日はありがとうございました`（お礼を厚めに置く）
- `率直に・正直に〇〇をお伝えできればと思います`（姿勢の宣言）
- `〇〇を一緒に考えていければと思います`（伴走姿勢）
- `〜で大丈夫ですのでご安心ください`（不安への受け止め）
- `お気軽にご連絡いただければと思います`（相談導線）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`〜になるんじゃないかなと`）→ 1通あたり0〜1回までOK
- `かと`: 余白としての単独の`〜かと。`は確認できず → 使わない
- `できればと` / `いただければと` / `いければと`: あり（`お伺いできればと思います` `お伝えできればと思います` `一緒に考えていければと思います` `お話しさせていただければと思います`）→ 着地表現として使ってよい。ただし依頼文は途中で止めず `〜と思います` まで言い切る
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず稼げます` `絶対大丈夫` は使わない。`〜という方が多いです` 程度に留める）
- 過度な美文
- 顧客感情の断定
