# 荒木さん

## 商談内で見えた特徴

- `おっしゃる通りですね`（相手の指摘をまず全肯定・口癖級）
- `ちなみに`（話題転換の定番・頻用）
- `一旦`（区切り）
- `逆に`
- `〜させていただく`（高敬語・多用）
- `ありがとうございます`（相槌・受けで多用）
- `〜という形になります`

## 一人称・距離感

- 一人称: `私` / `私たち` / `弊社`、相手法人は `御社`。自分を `荒木` と三人称でも名乗る（`本日は荒木がご案内させていただきます`）。`僕` は不使用
- 顧客への呼び方: `〇〇さま`

## メール反映の定型

- `おっしゃる通りで、〜`
- `ちなみに、〜`
- `〜させていただきます` / `〜させていただければと思います`
- `〜かと思います`
- `教えていただけるのであれば、〜`
- `ありがとうございます`（御礼・受け）

## 余白表現の出現

- `かと`: あり → 1通あたり0〜1回（`自己紹介が先かと思います` 等）
- `かなと`: 単独形は実質なし。`〜じゃないかなと思います` / `〜ないかなと思います` の形で出現。メールでは無理に使わない
- `できればと`: 発話になし → 使わない（`〜させていただければと思います` で着地）
- `見ていただけると`: 発話になし → 使わず `ご覧いただければと思います` / `ご確認いただければと思います` へ寄せる

## 禁止候補

- `改めて`（荒木の発話には出てこない。使わない）
- `できればと` / `見ていただけると`（発話根拠なし）
- 成果保証・収益保証・断定（`必ず利益が出ます` 等）
- 顧客が言っていない事実・金額・成果期待の付加

## 傾聴スタイルの再現メモ

- 相手の指摘をまず `おっしゃる通りですね` / `ありがとうございます` で全肯定してから補足説明する傾聴型
- 断定を避け `〜と思います` / `〜イメージですね` で着地する
- 知識のある顧客には、不利情報（規約・リスク）も正面から答えると信頼が増す
