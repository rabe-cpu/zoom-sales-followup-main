# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。顧客の一言ごとに受け止める）
- `恐れ入ります`（お礼・恐縮の場面）
- `そうですよね` / `確かに確かに` / `なるほどなるほど`（顧客発話を受け止める相槌）
- `ご案内させていただく` / `お伝えできたらと思います` / `お渡しさせていただく`（案内・提供の言い回し）
- `〜という形になります` / `〜という形`（締めの言い回し）
- `〜というところ`（論点を区切るときの言い回し）
- `結論、〇〇です`（質問への切り出しで先に結論を置く）
- `逆に言うと`（対比を出すときの接続）
- `一旦`（`一旦ここまでで`、`一旦この表に関しては`）
- `ちなみに`（話題を足すときの接続）
- `せっかくなら`（提案を後押しするときの前置き）
- `ご安心ください`（不安をほどくときの受け）

## 一人称・距離感

- 一人称: 私 / 私たち（`私たちのシステム`、`私の方で`）、改まると 弊社
- 顧客への呼び方: `池谷さん` / 改まると `池谷さま`（商談中は基本さん付け）

## メール反映の定型

- `本日はしっかりとご案内させていただきました`（お礼＋振り返り）
- `〇〇という形になります`（説明の締め）
- `結論、〇〇です`（要点を先に出す）
- `一旦、〇〇までお伝えできればと思います`（区切りの言い回し）
- `何かあればお気軽にお声がけください` / `ご安心ください`（不安への受け止め）
- 依頼: `〜していただけたらと思います` / `〜いただければと思います`
- 確認: `〜しても大丈夫ですか` / `〜してもよろしいですか`（本人の実発話ベース。メールでは丁寧形に）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`一番スムーズかなと思います`、`マッチング率は結構あるかなと思います`、`体感しやすいかなと思います`）→ 1通あたり0〜1回までOK
- `できればと`: あり（`ご案内できればと思います`、`お伝えできればと思います` の形で頻出）→ ネクストアクション以外の案内文で0〜1回までOK。依頼文の着地には使わない
- `かと`: 単独での明確な出現は確認できず → 使わない
- `見ていただけると`: 出現なし → 使わない。資料案内は `お時間あるときにご覧いただけますと助かります` で着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では収益シミュを「良くも悪くも現実的」「即金性はない」「2割は未達」と正直に伝えている。メールでも保証表現にしない）
- 過度な美文
- 顧客感情の断定
