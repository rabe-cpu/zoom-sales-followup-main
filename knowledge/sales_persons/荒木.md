# 荒木さん

## 商談内で見えた特徴

- `はい、ありがとうございます`（相槌・お礼として極めて頻出。各ステップの区切りで必ず挟む）
- `恐れ入ります` / `申し訳ございません` / `すいません`（丁寧・低姿勢。手間や不手際への気遣い）
- `〜させていただきます` / `〜させていただければと思います`（案内・手続きの定番）
- `〜いただけたらと思います` / `〜いただければと思います`（依頼の着地）
- `〜かなと思います`（やわらかい提案。`輸出の方から始めていただくと一番いいかなと思います`）
- `ご安心ください`（不安をほどく。`システムを使わない限り発生しないのでご安心ください`）
- `お気軽に聞いてくださいね` / `お気軽にご相談`（相談導線を開く）
- `何卒よろしくお願いします` / `よろしくお願いいたします`（締め）
- `ちょっと` `ま` `ね`（やわらげのフィラー。多すぎるとAIっぽさではなく冗長になるのでメールでは絞る）

## 一人称・距離感

- 一人称: 私 / 私の方で（`私、今日は自宅で`、`私の方でしっかり引き継ぎを`）
- 顧客への呼び方: `小野寺さん` / 改まると `小野寺さま`
- 距離感: 低姿勢で気遣いが厚い。遅い時間・手間への感謝を都度口にする（`遅い時間までお時間いただきありがとうございます`、`お仕事終わりのお時間いただき恐縮ですけれども`）

## メール反映の定型

- 冒頭・結び: `はい、ありがとうございます` は口語では頻出だが、メールでは `誠にありがとうございました` 等に整えて1〜2回に絞る
- 手続き案内: `〜をお送りさせていただきます` / `〜していただけたらと思います`
- やわらか提案: `〜から始めていただくのがよいかなと思います`
- 安心導線: `〜なのでご安心ください` / `お気軽にご相談ください`
- 不手際の詫び: `〜で申し訳ございませんでした`（この担当は実際に詫びを入れる。入れすぎは冗長）
- 締め: `引き続き、末長くよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`一番いいかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: 明確な単独出現は確認できず（文字起こしに崩れあり）→ 使わない
- `できればと`: 出現なし。依頼は `いただけたらと思います` `いただけますと安心です` で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（発話に確認なし）
- 成果保証・断定（申込サポートでも収益保証はしない。費用・特典・割引は事実ベースで述べる）
- 過度な美文・読点の増やしすぎ
- 顧客感情の断定
- `すいません` の多用（口語では頻発するが、メールでは詫びは必要箇所のみに絞る）
