# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・受けとして非常に多用）
- `そうですね` / `そうなんですよね`
- `〜じゃないですか`
- `なので、` / `で、` / `ただ、`
- `まあ` / `割と` / `結構` / `正直` / `全然`
- `〜という形` / `〜という形ですね`
- `ご安心ください`
- `いかがですか`

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社
- 顧客への呼び方: `〇〇さま`（本文）、会話中は `〇〇さん`
- 相手を立てる相槌が多い（`素晴らしいじゃないですか`、`すごいですね`）。やや砕けた親しみのある温度感。

## メール反映の定型

- `本日はお時間をいただきありがとうございました`
- `〜させていただきます` / `〜していただけますと`
- `ご安心ください` / `今日この場で決められなくても全然大丈夫です`
- `気軽にご相談いただけますと`
- `また日程を調整させていただけたらと思います`
- `よろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`費用がかかるというのはお分かりかと思います`）→ 1通あたり0〜1回まで
- `〜たらと思います` / `いただけたらと思います`: あり（`日程調整させていただけたらと思います`、`次回お時間いただけたらと思います`）→ 依頼の着地として使える
- `できればと`: あり（`お伝えできればと`）→ 文を途中で止めず着地させる
- `かなと`: 明確な出現なし → 発話にないため使わない
- `見ていただけると`: 明確な出現なし → 使わない

## 禁止候補

- `伝わってまいりました` などAI臭の強い美文
- `必ず成果が出ます` / `安心して稼げます` の成果保証
- 顧客の不安や感情の断定
- 発話にない丁寧語・余白表現
