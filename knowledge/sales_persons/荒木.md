# NEXT 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として極めて頻出。ひと区切りごとに感謝を挟む温かいトーン）
- `一旦`（進め方の切り替えで多用。`一旦今日の進め方から`、`一旦この大きな三つの流れ`）
- `なので`（理由から結論への接続で頻出）
- `ちなみに`（補足・個人的な推奨を足すとき。`ちなみに私個人的なおすすめは`）
- `ちょっと`（依頼の前置き・クッション。`ちょっとお手数なんですが`、`ちょっと確認してもよろしいですか`）
- `まあ` / `ええと・えっと`（話し言葉のつなぎ。メールでは出さない）
- `皆さん〜`（安心づけ。`皆さんも経験してきたこと`、`皆さん無事に立ち上げられています`）

## 一人称・距離感

- 一人称: 私 / 私たち（`私からですね`、`私たちもサポートさせていただく`）、会社は 弊社
- 顧客への呼び方: `〇〇さん`（商談中）。メールは `〇〇さま`
- 温度感: 丁寧で柔らかく、伴走姿勢（`気兼ねなく`、`頼っていただきたい`、`一緒に`）

## メール反映の定型

- 依頼: `〜していただいてよろしいですか` / `〜していただけたらと思います` / `お願いいたします` / `ちょっとお手数なんですが`
- 確認: `お間違いないですかね` / `よろしいですかね` / `いかがですか`
- 安心導線: `皆さんが通ってきた所です` / `サポートを受けながらで大丈夫です` / `気兼ねなくご連絡ください`
- 感謝: `ありがとうございます`（本文・締めで複数回）
- 締め: `引き続きよろしくお願いいたします` / `今後ともよろしくお願いいたします`

## 余白表現の出現

- `かと`: あり（`お振り込みは失礼かと思いますので`）→ 1通あたり0〜1回までOK
- `かなと`: あり（`下から行っていただくのが一番確実かなと思います`、`印象が高いのかなと思います`）→ 1通あたり0〜1回までOK（`かと`と合わせて1通1回程度に抑える）
- `できればと`: 出現なし → 使わない。ネクストアクションは `ご連絡ください` / `いただければと思います` で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `成果を出していただけるように` とサポート表現にとどめ断定なし。メールでも `〜という方が多いです` 程度に留める）
- 過度な美文
- 顧客感情の断定
