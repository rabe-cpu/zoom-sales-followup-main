# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（相槌・お礼として非常に頻出。顧客の発言を受けるたびに置く）
- `おっしゃる通りです` / `バッチリです`（顧客の見立てを肯定する受け）
- `さすがですね` / `素晴らしいですね`（顧客の経験・直感を立てる）
- `なるほど、なるほど`（相槌の重ね）
- `一旦`（`一旦ちょっと確認してみたい`、`一旦募集は締め切ってる`）
- `ちなみに`（質問の切り出し。`ちなみにお時間大丈夫ですか`、`ちなみに今一番興味があるのは`）
- `正直`（率直さを出す前置き。`正直あんまり詳しくないんですけど`、`正直にお答えいただいてありがとうございます`）
- `ある意味`（言い換え・補足の接続）
- `やっぱり`（根拠を押すときの接続）
- `せっかく〇〇いただいたので`（次アクションへつなぐ導入）
- `〜という形ですね` / `〜という形`（説明の着地）
- `〜していただければと思います`（依頼・提案の着地）
- `確認してみたいと思います` / `確認させてください`（持ち帰り・社内確認の着地）

## 一人称・距離感

- 一人称: 私 / 私たち（`私も直感タイプ`、`私たちのシステム`）、改まると 弊社
- 顧客への呼び方: `〇〇さん`（商談中はさん付け。メールでは `〇〇さま`）
- 距離感: 顧客の経験・直感をまず立て、肯定してから情報を足す。自己開示や謙虚な前置き（`社内の人間ですけど`、`無茶ぶりなんですけど`、`詳しくないんですけど`）で押し売り感を下げる

## メール反映の定型

- `おっしゃる通りで、〇〇ですね`（顧客の見立てを肯定して受ける）
- `ちなみに〇〇はいかがでしょうか`（やわらかい確認の切り出し）
- `正直なところ〇〇です`（率直に伝える前置き）
- `せっかく〇〇いただいたので、〇〇させてください`（次アクションへの接続）
- `〇〇という形ですね`（説明の着地）
- `〇〇を確認してみたいと思います` / `〇〇を確認させてください`（社内確認・持ち帰りの着地）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`お勧めするかなと`、`モチベーションが維持しやすいのは輸出かなと思います`、`十年の重みが分かっていただけるかなと思います`）→ 1通あたり0〜1回までOK
- `かと`: あり（`わかりやすいかと思います`）→ 1通あたり0〜1回まで。依頼文の着地では使わない
- `できればと`: 明確な出現なし → ネクストアクションは「ご確認いただけますと助かります」「ご返信いただけますでしょうか」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `成果が出やすい` と語るが、`やることをやっていただければ` と条件を添えている。メールでは `〜という方が多いです` 程度に留め、収益・回収・審査の保証表現にしない）
- 全額返金保証は条件付き（店舗開設・出品数・月1面談の達成が前提）。メールで無条件返金のように書かない
- 過度な美文
- 顧客感情の断定
