# 荒木さん

## 商談内で見えた特徴（実発話ベース）

- `ありがとうございます`（多用。区切りごとに挟む）
- `恐れ入ります` / `お忙しい中で今日はありがとうございます`
- `助かります`（依頼が通ったときのお礼）
- `かしこまりました`
- `一旦送ってみますね` / `ちょっと一旦`（作業の区切り）
- `〜していただけたらと思います`
- `〜という形になります` / `〜という形で`
- `ご安心ください`（`支払日が早まっちゃうとかはないのでご安心ください`）
- `そしたら` / `ええと` / `じゃあ`（口頭のつなぎ。メールでは整える）

## 一人称・距離感

- 一人称: 私（`私の方にも完了通知届きます` / `私から返送依頼があってから`）
- 顧客への呼び方: 田村さん・たむらさん（メールでは「田村嘉唯さま」で統一）
- 距離感: ていねいで腰が低い。相手の作業を待つ姿勢、逐一お礼を挟む。

## メール反映の定型

- 冒頭お礼: `本日はお忙しい中、お時間をいただきありがとうございました`
- 依頼: `〜していただけますと助かります` / `〜をお願いいたします`
- 安心導線: `〜の点はご安心ください`（事実確認できた範囲のみ）
- 締め: `引き続きよろしくお願いいたします`

## 余白表現の出現

- かと: 面談では確認語尾として散発（`大丈夫かと思います`＝顧客側発話）。営業本人の発話にはほぼ無し → メールでは使わない。
- かなと: 荒木本人の発話に明確な根拠なし → 使わない。
- できればと: 発話になし → 使わない。
- 見ていただけると: 発話になし → 使わない。
- 方針: 荒木さんは余白表現より「お礼＋着地した依頼文」で人柄が出るタイプ。着地形（`〜と助かります` / `〜をお願いいたします`）で書く。

## 禁止候補

- `必ず成果が出ます` / `必ず審査が通ります`（審査・信販に関わる断定は特に禁止）
- `誰でも簡単に`
- `伝わってまいりました`
