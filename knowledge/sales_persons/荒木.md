# 荒木さん

## 商談内で見えた特徴

- `まあ` / `ま、`（クッションとして多用。断定を避けて柔らかく置く）
- `あの` / `えっと` / `ちょっと`（考えながら話す間投詞）
- `そうですよね` / `そうですね`（相手の発話を受け止める相槌）
- `参考までに`（事例を出すときの前置き）
- `一旦`（`一旦ここまでの作業の`、区切りを入れるとき）
- `ちなみに`（軽く確認を差し込むとき）
- `逆に`（`逆に法人の方だと`、対比を出すとき）
- `〜という形になります` / `〜という形です`（説明の締め）
- `〜させていただければと思います` / `〜お伝えして大丈夫ですかね？`（依頼・確認をやわらかく置く）
- `ありがとうございます`（相槌・お礼として極めて頻出。相手が答えるたびに挟む）
- `ご安心ください`（不安をほどくときの定番。`この後メールでお渡ししますのでご安心ください`）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社（`私たちのシステム`、`弊社にいただくメンテナンス費`）
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け。`若月さん`）。書面では `〇〇さま`

## メール反映の定型

- `〜させていただければと思います`（依頼の着地）
- `〜お伝えして大丈夫ですかね？`（確認を挟む）→ メールでは `〜お伝えさせていただきます` に整える
- `〜という形になります`（説明の締め）
- `この後メールでお渡ししますのでご安心ください`（安心導線）
- `また追加のご質問があればいつでも、電話でもメールでもオンラインでも対応させていただきます`（相談導線）
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`一番いいかなと思います`、`作業要因にはなるのかなと`、`目指していけるかな`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: あり（`一度お伝えできればと思います`、`お話できたらと思います` の形）→ ネクストアクションの押しつけには使わず、冒頭や案内の柔らかい着地でだけ0〜1回
- `見ていただけると`: 出現なし → 使わない。依頼は `ご覧いただけますと助かります` `ご確認いただけますでしょうか` で着地させる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `やっていただければ成果も出していただけると信じて` と語るが、`信じて` と保証を避けている。メールでも `〜という方が多いです` `〜が目安です` に留め、`必ず稼げます` `確実に回収できます` にしない）
- 過度な美文
- 顧客感情の断定（`〜のが伝わってきました` は使わず、`〜と受け取りました` に留める）
