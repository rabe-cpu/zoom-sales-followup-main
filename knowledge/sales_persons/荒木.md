# 荒木さん

## 商談内で見えた特徴

- `まあ` / `あの` / `えっと`（口頭のつなぎ。メールでは落とす）
- `〜という形ですね` / `〜って形ですね`（確認・整理の締め）
- `おっしゃる通りですね`（同意）
- `一応` / `ちなみに` / `なので`（話題転換・補足）
- `ご留意いただければ`（注意喚起）
- `誠実に` / `長く付き合えるパートナー`（会社姿勢の強調）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社
- 顧客への呼び方: 口頭は `〇〇さん`（メール宛名は `〇〇さま` に整える）

## メール反映の定型

- `また金曜日にお話しさせていただければと思います`
- `契約書と解説動画も一緒にお送りさせていただきますね`
- `気になる点が出てきましたら、LINEでもお電話でも構いませんので`
- `細かくご確認いただいてありがとうございます`
- `引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`一週間以内ぐらいには手元にあるかなと思いますね`、`増やしていく方がいいかなと思います`）→ メール1通あたり0〜1回
- `かと`（単体）: 明確な発話なし → 使わない
- `できればと`: 発話なし → 使わない
- `見ていただけると`: 発話なし → 使わない

## 禁止候補

- `伝わってまいりました`
- 成果保証・断定（`必ず売れます` `絶対稼げます`）
- 顧客が言っていない感情の断定

## 備考（重要・運用上の注意）

- 本商談は **輸出マスター（Amazon輸出）＋輸入特典** 商材で、`総合物販システム_アクセス` とは別ライン。CLAUDE.md の固定件名・固定資料URL・検討結果入力フォームはアクセス専用のため、本担当の顧客にはそのまま適用できない。
- フォローアップ連絡は主に **LINE**（契約書・解説動画もLINE送付）。Gmail下書きは補助。
