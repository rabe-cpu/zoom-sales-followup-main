# 荒木さん

## 商談内で見えた特徴

- `ま、` / `あの` / `なんか`（会話のつなぎ。文字起こしの口癖なのでメールにはそのまま持ち込まない）
- `ちなみに`（話題の切り出し・深掘りで多用）
- `じゃあ` / `そしたら`（次の案内への切り替え）
- `一応` / `改めて` / `実は` / `逆に`（説明の前置き）
- `〜させていただいてもよろしいですか`（案内・画面共有・日程調整の依頼で頻出。押しつけない）
- `〜していただけたらと思います` / `〜いただけると` / `お伺いさせていただけると`（依頼・案内の定番着地）
- `教えていただいてありがとうございます` / `教えていただいて助かります`（顧客の発話を受けてお礼）
- `素晴らしいですね` / `よかったです` / `いいですね`（顧客を立てる相槌）
- `ご安心ください` / `恐れ入ります` / `よろしくお願いいたします`（丁寧な進行）
- `ありがとうございます`（相槌・お礼として非常に頻出）

## 一人称・距離感

- 一人称: 私（`私自身`、`私の方では`、`私も`）、弊社
- 顧客への呼び方: `山田さん`（さん中心。様も可）
- フラットで誠実なスタンス。`焦って決める必要はない`、`メリット・デメリットも正直にお伝えする`、`向いているか向いていないかを一緒に整理する`、`正直、他社さんでもいいと思っている` と、売り込みより相談相手の姿勢を明確に出す
- 顧客の発話を要約して返し、`〜という形ですね` と確認を挟む

## メール反映の定型

- `本日はお休みのところ、お時間をいただきありがとうございました`
- `一緒に整理していければと思います` / `一緒に見ていければと思います`
- `この後、資料をお送りさせていただきますので、ゆっくりご覧いただけますと助かります`
- `焦ってお決めいただく必要はありませんので、まずは〜`
- `ご不明点があれば、メールでも気兼ねなくおっしゃってください`
- 締め: `本日は貴重なお時間をいただきありがとうございました。引き続きよろしくお願いいたします`

## 余白表現の出現

- `かなと` / `かな`: あり（`いかがかなと思いますので`、`整理しやすいかなと思います`、`役に立つのかな`）→ 1通0〜1回までOK
- `かと`: 明確な発話確認は弱い。無理に使わず着地形に寄せる
- `できればと`: あり（`お顔を拝見できればと思って`、`ご案内させていただければと思います`、`解消していただけたらと思います`）→ 着地として自然に使用可。ただし依頼文を曖昧に止めない
- `見ていただけると`: `ご覧ください` / `ご覧いただけますと助かります` の形に寄せる（`見ていただけると。` で止めない）

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談ではパートナー実績の数字を紹介するが、メールでは売上・収益を保証にしない）
- 過度な美文
- 顧客の不安・感情の断定・煽り（山田さまは将来の収入・ご両親への恩返しを口にしており、丁寧に受け止める。盛らない）
