# NEXT 荒木さん

## 商談内で見えた特徴

- `ちなみに`（話題を足す接続。`ちなみに今日もお時間、私は余裕を持って用意してる`）
- `一旦`（`一旦ご案内した方がいいですかね`、`一旦もう松井の方は退席で`）
- `改めて`（`改めてまたオンライン面談のご連絡`、`私の方でも改めてメールでお送りします`）
- `じゃあ` / `そしたら`（場面転換）
- `なので` / `で` / `まあ`（現場口調のつなぎ）
- `どちらかというと`（やわらかく整理するときの前置き）
- `〜で大丈夫ですか？` / `ここまで大丈夫ですかね？`（理解確認の定番）
- `そのご認識で` / `〜という認識`（相手の理解を受け止める確認）
- `はい、ありがとうございます`（相づち・お礼として非常に頻出）

## 一人称・距離感

- 一人称: `私` / `私の方で` / `私たち` / `弊社`（`僕` は顧客側の語なので使わない）
- 顧客への呼び方: `嵯峨井さん`（商談中はさん付け）
- 顧客を立てる相づち: `嬉しいですね`、`素晴らしいですね`、`すごいですね`

## メール反映の定型

- `改めて、本日の内容を私の方でお送りします`（フォロー送付の切り出し）
- `〜させていただいてよろしいですか`（依頼・案内の許可取り）
- `〜していただければと思います` / `〜していただいた方がいいと思います`（依頼の着地）
- `ご連絡いただいてよろしいですかね`（次アクション依頼）
- `そのご認識で問題ございません`（確認の受け止め）
- 締め: `今後ともよろしくお願いいたします`
- お礼: `本日はお時間をいただき、ありがとうございました`

## 余白表現の出現

- `かなと`: あり（荒木の実発話で複数回。`そんなに違和感ないかなと思います`、`今登録していただいたらいいかなと思います`、`連絡いただくといいかなと思い`）→ 1通あたり0〜1回までOK
- `かと`: 文末の余白用法（`〜かと。`）は荒木の発話に確認できず → 使わない
- `できればと`: 荒木は1回のみ（`ご案内ができればと思いますが`）→ 基本は使わず、使うなら必ず `〜できればと思います` と着地させる
- `見ていただけると`: 出現なし → 使わない。荒木は `ご覧いただけたらと思います`、`聞いていただければと思います` と必ず着地させる

## 禁止候補

- `伝わってまいりました` 系のAI臭い敬語（荒木の発話に確認なし）
- 成果保証・収益保証・審査通過の断定（返金保証・売上保証の説明はするが、保証内容は事実ベースで、作業継続が前提である点とセットで伝える）
- 過度な美文
- 顧客感情の断定
