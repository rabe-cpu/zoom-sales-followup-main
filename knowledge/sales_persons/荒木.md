# 荒木さん

## 商談内で見えた特徴

- `ありがとうございます`（顧客の発話を受けるたびに非常に頻出。相槌・お礼として多用）
- `〜という形ですね` / `〜っていう形です` / `〜いう形になります`（説明の締めの定番）
- `あの` / `えっと` / `ちょっと`（説明に入るときのクッション）
- `一応`（控えめに事実を置くときの前置き。`一応これが弊社の`、`一応それが10月末まで`）
- `なので`（理由から結論へつなぐ）
- `正直`（率直に伝えるときの前置き。`正直あまり関係ない`、`正直なところ`）
- `やっぱり` / `やっぱ`（強調・納得の接続）
- `逆に言うと`（見方を裏返して伝える）
- `ちなみに`（話題を自然に足す）
- `ご安心ください`（不安をほどくときに使う）

## 一人称・距離感

- 一人称: 私たち / 弊社（`私たちが今ご提案できるのが`、`弊社の方では`）、`私`（まれ）。`僕` は使わない
- 顧客への呼び方: `〇〇さん` / `〇〇さま`（商談中はさん付けが基本）

## メール反映の定型

- `〇〇という形ですね`（説明の着地）
- `一応〇〇です`（事実を控えめに置く）
- `なので、〇〇`（理由→結論の接続）
- `ご安心ください`（不安への受け止め。ただし成果保証にはしない）
- `ぜひご検討よろしくお願いします`（締めの依頼）
- 締め: `引き続きよろしくお願いいたします` / `よろしくお願いします`

## 余白表現の出現

- `かなと`: あり（`確認していただくといいかなと思います`、`慎重に見ていただくといいかなと`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 明確な出現なし → ネクストアクションは「いただけますと助かります」「お送りいただけましたら」で着地させる
- `見ていただけると`: 近い表現（`見ていただくといいかな`）はあるが単独では確認できず → 多用せず、依頼は着地形に寄せる

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（商談では `どうしても売り上げ上がりますとは言えない` と本人が明言し、代わりに全額返金保証で担保する姿勢。メールでも `〜を目指せる`、`〜という方が多いです` 程度に留め、`必ず`・`稼げます` などの保証表現にしない）
- 過度な美文
- 顧客感情の断定
