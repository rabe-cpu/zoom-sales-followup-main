# 荒木さん

## 商談内で見えた特徴

- `という形になります` / `〜という形ですね` / `という形`（説明の締めで多用）
- `というところ` / `という部分`（論点を指すときの定番）
- `割と`（`割と皆さんに`、`割と即日性`、`割と大きな部分`、`割とこう`）
- `一応`（`一応こちらの方では`、`一応今回`、`一応その部分では`）
- `ちなみに`（話題転換の切り出し）
- `おっしゃる通り` / `おっしゃっていただいて`（顧客の発言の受け止め）
- `なるほど`（相槌。頻出）
- `ありがとうございます`（相槌・お礼として非常に頻出）
- `イコール`（言い換え。`短時間作業で済むイコール`、`無在庫物販イコール受注販売方式`）
- `〜していきませんか？`（提案の誘い。`新しい収益を作っていきませんか？`、`輸出していきませんか？`）
- `すごく大事`（`リスクヘッジってすごく大事`、`すごく大事な`）
- `手離れがいい`（商材説明の言い回し）

## 一人称・距離感

- 一人称: 私 / 私たち（`私自身`、`私たちの`、`私より`）、会社は 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）

## メール反映の定型

- `〇〇という形になります`（説明の着地）
- `おっしゃる通り、〇〇です`（受け止めてから進める）
- `一応〇〇させていただいております`
- `割と〇〇な部分になってきます`
- 依頼・案内: `〇〇させていただきます` / `〇〇していただけたらと思います` / `ぜひよろしくお願いいたします`
- 締め: `よろしくお願いいたします` / `ありがとうございました`

## 余白表現の出現

- `かなと`: あり（`一番いいかなとは思っております`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: 荒木さんの発話に確認なし（顧客側の発話）→ ネクストアクションは「いただけますと幸いです」「ご返信いただけますと」で着地させる
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・断定（`必ず成果が出ます`、`安心して稼げます` などは使わない。商材説明でも `割と皆さんに` `〜という方が多い` 程度に留める）
- 過度な美文
- 顧客感情の断定
