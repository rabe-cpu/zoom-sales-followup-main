# 荒木さん

福祉事業所（就労継続支援A型・B型）向けの説明会を専任で担当。傾聴と共感の相槌が非常に多く、顧客の背景・思いを先に受け止めてから提案へ進むタイプ。

## 商談内で見えた特徴

- `結論からお伝えすると` / `結論、〇〇です`（要点の切り出し）
- `なるほど。なるほど`（相槌の反復。強い共感）
- `ありがとうございます`（相槌・お礼として非常に頻出）
- `素晴らしいですね` / `いいですね` / `素敵ですね`（承認・共感）
- `差し支えなければ`（質問前のクッション）
- `〜っていう形になります` / `〜という形ですね`（説明の締め）
- `〜と思っております` / `〜と思いますので`（締め・意向）
- `お役に立てれば` / `お力になれたら`（貢献の姿勢）
- `まあ`（やわらかく話をつなぐフィラー）
- `ここまでで何かご質問などはありますか`（区切りごとの理解確認）

## 一人称・距離感

- 一人称: 私 / 私たち / 弊社
- 顧客への呼び方: `〇〇さん`（商談中は基本さん付け）
- 相手の事業所・利用者さん・スタッフへの敬意を先に示してから本題へ入る

## メール反映の定型

- `結論からお伝えすると、〇〇です`（要点を先に出す）
- `〇〇できればと思います`（次アクション・提案の着地）
- `〇〇させていただければと思います`
- `〜という形になります`（説明の締め）
- お礼・受け止めを厚めに置いてから、判断材料へ進む
- 締め: `よろしくお願いいたします`

## 余白表現の出現

- `かなと`: あり（`お役に立てたらなと思っております`、`相性がいいのかなと`）→ 1通あたり0〜1回までOK
- `かと`: 単独での明確な出現は確認できず → 使わない
- `できればと`: あり（`お話しできればと思います`）→ ネクストアクションで「〜できればと思います」で着地させてよい
- `見ていただけると`: 出現なし → 使わない

## 禁止候補

- `伝わってまいりました`（荒木さんの発話に確認なし）
- 成果保証・収益保証・最低賃金クリア保証（福祉A型の最低賃金や収益は断定しない）
- 過度な美文
- 顧客・利用者さんの感情の断定
