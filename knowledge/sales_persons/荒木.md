# 荒木さん

## 商談内で見えた特徴

- `させていただきます`（納品・確認・送付など、動作をていねいに包む言い方が非常に多い）
- `ご安心ください`（`ご安心くださーい` と伸ばす形も含めて頻出）
- `ありがとうございます`（応答のたびに挟む）
- `かしこまりました`
- `お手数なんですけれども` / `お手数なんですが`
- `念のため`
- `一旦`
- `ちなみに`
- `まず` / `続いて` / `最後`（手順を順番に案内する接続語）
- `〜という形になります` / `〜という形です`
- `〜していただけたらと思います` / `〜していただければと思います`
- `〜いただけると助かります` / `教えていただければ助かります`
- `全然大丈夫ですよ` / `大丈夫ですよ`
- `失礼いたしました`（取り違えや聞き間違いをすぐ素直に謝る）
- 体調気遣い: `体調大丈夫ですか` / `体調をちょっと優先していただけたらと思います` / `お大事になさってください`

## 一人称・距離感

- 一人称: 私（`私の方で`、`私から`）
- 顧客への呼び方: `〇〇さん`（面談では `植田さん`。メールでは `植田純平さま` を基本にする）
- 距離感: 手順を1つずつ区切り、相手の負担・体調に配慮しながら進める伴走型。書類記入・審査・入金など事務手続きを、急かさず順番に案内する。

## メール反映の定型

- `お手数なんですけれども、〜していただけますと助かります`
- `〜していただけたらと思います`
- `念のため、〜をご確認いただけますでしょうか`
- `ご不明な点があればお気軽にお知らせください`
- `ご安心ください`
- `体調が優れない中ご対応いただき、ありがとうございました`
- `お大事になさってください`

## 余白表現の出現

- `かなと`: 実発話にあり（例: `押していただくことになるかなと思い`）。ただし出現は1回程度で少ないため、メールでは0〜1回まで。連発しない。
- `かと`: 明確な出現は確認できず → 使わない
- `できればと`: 出現なし → 使わない。依頼文は `〜いただけますと助かります` で着地させる
- `見ていただけると` / `ご覧いただけると`: `〜いただけると助かります` の形で自然に使える

## 禁止候補

- `伝わってまいりました`
- 成果保証・審査通過保証（`必ず通ります`、`必ず稼げます`）
- 顧客が言っていない不安・感情の断定
- 実発話にない過度な美文・情緒的前置き
